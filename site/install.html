Install House Style

Installing takes a few minutes. You need Windows, MadCap Flare Desktop, and permission to install software (or help from IT).

Quick install

  1. Download the latest release (HouseStyle-<version>.zip).
  2. Unzip the whole download to a normal folder, such as your Desktop (right-click > Extract All). Don't run anything from inside the zip.
  3. Close Flare.
  4. Double-click Install.cmd, and say yes to the administrator prompt. It unblocks the files, finds your Flare, copies the plugin, and tells you what to do next.
  5. Start Flare. Go to File > Options > Plugins, select House Style, and click Enable.
  6. Restart Flare again. The House Style tab appears on the ribbon.

If you use the tool strip instead of the ribbon, switch to Ribbon UI mode (View > Interface).

Several Flare versions installed? The installer picks the newest. To pick another, open PowerShell in the unzipped folder and run .\Install.ps1 -Flare 21, using the folder number from the table below.

Which Flare is which

Flare's install folder number isn't the same as its year. House Style loads separately for each Flare version, so install it into the one you open.

Folders are under C:\Program Files\MadCap Software\.

Manual install

Use this if Install.cmd doesn't work.

  1. Unblock the zip first. Right-click the zip > Properties > tick Unblock > OK. Then unzip it.

    Already unzipped? Run this in PowerShell, with your folder path:

    Get-ChildItem "C:\path\to\unzipped folder" -Recurse | Unblock-File

    If you skip this, Windows quietly stops Flare from loading the plugin, and it never appears.

  2. Close Flare.
  3. Copy the FlareAI folder to C:\Program Files\MadCap Software\MadCap Flare 22\Flare.app\Plugins\. Change 22 to match your version.
  4. Check that there's no extra folder. This file must exist: ...\Flare.app\Plugins\FlareAI\FlareAI.Flare.dll. If you see Plugins\HouseStyle-0.1.3\FlareAI\..., your unzip tool added a wrapper folder. Move the inner FlareAI folder up into Plugins, and delete the wrapper.
  5. Start Flare. Go to File > Options > Plugins > House Style > Enable.
  6. Restart Flare.

Two restarts. Flare needs one start to find the plugin, and one restart after you enable it. If the House Style tab is missing after you enable it, restart Flare once more.

If House Style isn't in the Plugins list

  • Check for a wrapper folder (step 4 of the manual install).
  • Check that the files are unblocked (step 1).
  • Check that you installed into the Flare version you're running. See the table above.
  • Flare must be fully closed while you copy, and restarted afterward.

Still stuck? %APPDATA%\FlareAI\diag.log lists timings and errors. It contains no document text and no key. Attach it to an issue on GitHub.

Add your Anthropic key

You need a key only for AI review, Rewrite selection, Ask and Topic assists. Style checks work without one.

  1. Create a key in the Anthropic Console.
  2. In Flare, open House Style > Settings.
  3. Paste the key, and click Save.

The key is encrypted for your Windows account, so nobody else on the computer can read it. See Privacy.

Use a Bifrost gateway

If your company gave you a Bifrost gateway address and virtual key instead of an Anthropic key:

  1. Open House Style > Settings.
  2. Set Provider to Bifrost gateway.
  3. In Base URL, enter the gateway address you were given.
  4. Paste the virtual key, and click Save. The models are set for you.
  5. Click Test connection to check it.

Gateway key checklist (for gateway admins)

Before you give a virtual key to a writer, check these:

  • The Base URL starts with https://, with no path and no trailing slash. The plugin adds /v1/chat/completions.
  • The writer pastes the whole key (sk-bf-...), with no spaces or line breaks.
  • The virtual key allows all three models: anthropic/claude-sonnet-5-5, anthropic/claude-haiku-5-5 and anthropic/claude-opus-5-5.
  • Bifrost v1.5 and later treat an empty allow-list as "deny all". Set allowed_models on the virtual key's provider config, set key_ids: ["*"], and list the models on the Anthropic provider key. Otherwise every request fails with no keys found for provider: anthropic.
  • Set an expiry and a budget on the key.
  • Writers' computers can reach the gateway address.

The full example configuration is in docs/bifrost-migration.md in the repository.
