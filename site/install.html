Install House Style

You need Windows, MadCap Flare Desktop, and permission to install software. It takes a few minutes.

Quick install

  1. Download the latest release (HouseStyle-<version>.zip).
  2. Extract the whole download to a folder, such as your Desktop (right-click > Extract All).
  3. Close Flare.
  4. Double-click Install.cmd and approve the administrator prompt. It finds your Flare and copies the plugin.
  5. Start Flare. Go to File > Options > Plugins, select House Style, and click Enable. The House Style tab appears on the ribbon.

House Style needs Ribbon UI mode (View > Interface). To upgrade a copy you installed by hand, run Install.cmd the same way. Your settings are kept.

The installer picks your newest Flare. To pick another, open PowerShell in the extracted folder and run .\Install.ps1 -Flare 21, with the folder number from the Flare versions table.

Manual install

Use this if Install.cmd doesn't work.

  1. Unblock the zip first. Right-click the zip > Properties > tick Unblock > OK. Then extract it.

    Already extracted? Run this in PowerShell, with your folder path:

    Get-ChildItem "C:\path\to\extracted folder" -Recurse | Unblock-File

    If you skip this, Windows blocks the plugin and it never appears in Flare.

  2. Close Flare.
  3. Copy the FlareAI folder to C:\Program Files\MadCap Software\MadCap Flare 22\Flare.app\Plugins\. Change 22 to match your version.
  4. Check for an extra folder. This file must exist: ...\Flare.app\Plugins\FlareAI\FlareAI.Flare.dll. If you see Plugins\HouseStyle-0.1.3\FlareAI\..., move the inner FlareAI folder up into Plugins and delete the outer one.
  5. Start Flare. Go to File > Options > Plugins > House Style > Enable.

No House Style tab after you enable it? Restart Flare.

If House Style isn't in the Plugins list

  • Check for an extra folder (step 4 of the manual install).
  • Check that the files are unblocked (step 1).
  • Check that you installed into the Flare version you open. See Flare versions.
  • Close Flare completely before you copy, and restart it afterward.

Still stuck? Attach %APPDATA%\FlareAI\diag.log to an issue on GitHub. The log contains no document text and no key.

Set up AI

AI is optional. Style checks work without it. The first time you click a House Style command, a three-step setup opens. Later, use House Style > Settings: the AI tab, or Run setup again.

To use your own Anthropic key:

  1. Create a key in the Anthropic Console.
  2. Choose My Anthropic API key, paste the key, and click Test connection.
  3. Click Next, or Save in Settings.

Only your Windows account can read the saved key. See Privacy.

Use your company's AI service

If your company runs a Bifrost gateway, your admin gives you its address and a gateway key.

  1. In setup, or in House Style > Settings on the AI tab, choose My company's AI service (gateway).
  2. In Base URL, enter the gateway address.
  3. In Gateway key, paste the whole key.
  4. Click Test connection, then Next or Save.

Checklist for gateway admins

Before you give a writer a gateway key (in Bifrost, a virtual key):

  • Give the gateway's root address, such as https://gateway.example.com. The plugin adds /v1/chat/completions.
  • The writer pastes the whole key (sk-bf-...), with no spaces or line breaks.
  • The key allows all three models: anthropic/claude-sonnet-5-5, anthropic/claude-haiku-5-5 and anthropic/claude-opus-5-5.
  • Bifrost v1.5 and later treat an empty allow-list as "deny all". Set allowed_models on the virtual key's provider config, set key_ids: ["*"], and list the models on the Anthropic provider key. Otherwise every request fails with no keys found for provider: anthropic.
  • Set an expiry and a budget on the key.
  • Writers' computers can reach the gateway address.

The full example configuration is in docs/bifrost-migration.md in the repository.

Updates

If you installed with Install.cmd, House Style updates itself. Once a day it checks GitHub for a new version. When there is one, it downloads and checks it, and a notice says it installs when you close Flare. No administrator prompt appears. Your next start shows what's new.

If a download fails, House Style tries again the next day. If an install fails, you stay on your version and a notice says why. To turn updates off, clear Keep House Style up to date on the Advanced tab of Settings. See Privacy for what the check sends.
