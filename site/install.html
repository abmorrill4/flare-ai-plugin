Install House Style

Three steps on Windows with MadCap Flare 2026. The download is under 1 MB.

  1. Download the zip

    Get HouseStyle-<version>.zip from the latest release on GitHub.

    Download for Flare 2026

  2. Unblock it, then extract it

    Right-click the zip and select Properties. Select Unblock, then OK. Then right-click the zip and select Extract All.

    Don't run anything from inside the zip.

  3. Run Install.cmd

    Close Flare. In the extracted folder, double-click Install.cmd and approve the administrator prompt.

    You see the prompt only this first time.

What happens next

Start Flare. The House Style tab appears on the ribbon. If it doesn't, select File > Options > Plugins, select House Style and then Enable.

Select any House Style command. A short setup asks how you'll use House Style. You can skip any step.

AI is optional. Lint Topic and Lint Project work without it. To use Rewrite and Ask AI, add your own Anthropic API key or your company's gateway address and key in setup, or later in Settings.

Updates

House Style updates itself. Once a day it checks GitHub for a new version, downloads it and checks it against the release's SHA-256 checksum. It installs when you close Flare, with no administrator prompt.

If a download fails, House Style tries again the next day. If an install fails, you stay on your current version and a notice says why. Your settings, rule changes and decisions are kept.

To turn updates off, open Settings, select the Advanced tab and clear Keep House Style up to date. IT can turn them off for everyone. See Privacy.

More than one Flare

The installer picks your newest Flare. To pick another, open PowerShell in the extracted folder and run .\Install.ps1 -Flare 21, with the number from the Flare folder name.

For IT

Install.ps1 -Silent installs with no questions and returns exit code 0 when it succeeds. Install.ps1 -NoAutoUpdate turns updates off.

If the tab doesn't appear

  • Check that you installed into the Flare you open. See the folder table above.
  • Close Flare completely, run Install.cmd again and restart Flare.
  • Check that Flare uses the Ribbon interface, under View > Interface.

Still stuck? Open an issue on GitHub and attach %APPDATA%\FlareAI\diag.log. The log has no document text and no key.

Uninstall

  1. Close Flare.
  2. Open Command Prompt as administrator and run
    rmdir "C:\Program Files\MadCap Software\MadCap Flare 22\Flare.app\Plugins\FlareAI"
    This removes only the link that Flare loads House Style from.
  3. Delete the folder %LOCALAPPDATA%\HouseStyle.
  4. To remove your settings, key and decisions too, delete %APPDATA%\FlareAI.

If you copied the plugin into Flare by hand, delete the Plugins\FlareAI folder instead of step 2.
