Privacy

House Style sends none of your text unless you ask for an AI action. Apart from that, it only asks GitHub once a day for a newer version. It sends a report to the authors only when you choose to.

What never leaves your computer

These features never send your text anywhere.

  • Lint Topic and Lint Project, against Google's rules and your team's
  • Accessibility and structure checks
  • Test Rules, except its optional AI check
  • Export for LLMs

What leaves, and when

Text leaves only when you use an AI feature. These are AI review, Rewrite, Ask AI, Topic Metadata, Suggest alt text, and the AI steps in Import Rules, Rule Decisions and Test Rules.

Each request carries the text of the sections being checked and the style rules that apply to them. For alt text, it carries the image. Nothing else is sent.

Update check

If you installed with Install.cmd, House Style asks GitHub once a day whether a newer version exists.

  • The check is one request to api.github.com for the project's latest release. It carries no document text, no key and no identifier. GitHub sees your IP address and a generic HouseStyle-Updater program name, as it would for any download.
  • When a newer release exists, House Style downloads it from the project's GitHub release and checks it against the release's published SHA-256 checksum before it installs.
  • Offline or behind a firewall, the check fails silently and House Style works as before.
  • To turn the check off, open Settings, select the Advanced tab and clear Keep House Style up to date (checks GitHub once a day). With the box cleared, House Style makes no request to GitHub.
  • IT can turn it off for everyone with an update-policy.json file containing {"autoUpdate": false} in the plugin folder, or by installing with Install.ps1 -NoAutoUpdate. The file wins over the Settings box, which then shows "Set by your IT department".

Problem reports

House Style collects no usage data or analytics. When something goes wrong, it asks before it sends a problem report, and shows you exactly what the report contains. To send reports without being asked, turn on Send error reports automatically in Settings. You can also choose Report a Problem or Report False Positive yourself.

A report contains the House Style and Flare versions, Windows version, the error details, recent lines from the House Style log and your settings without your key or folder paths. Reports never include your topic text unless you type it in. They go to a private issue list that only the authors can read.

The update check reports nothing about you or how you use the plugin.

Your key

Your key is encrypted with Windows Data Protection (DPAPI) and saved in %APPDATA%\FlareAI\settings.json. Only your Windows account can decrypt it. The key is never written to a log.

Files on your computer

  • %APPDATA%\FlareAI\diag.log holds timings and errors for bug reports, with no document text and no key.
  • Your Change and Ignore decisions, so an issue you ignored stays hidden.
  • Saved AI reviews, so a topic you reopen shows its issues without a new request.
  • The plugin itself, the previous version for rollback, a downloaded update waiting to install, and the date of the last update check.

Shared with your team

House Style writes to a shared folder only if your team sets a feedback folder in Settings. It writes these.

  • Your decisions on issues. The rule, the words it flagged, your reason if you gave one, and the topic's filename.
  • Your requests to the style guide owners. The rule, the change you asked for, your reason, the flagged words and the topic's filename. Owners' decisions are stored next to them, with the owner's name and note.

Your name is recorded only if the style guide's attribution.txt says names. Otherwise each computer has a random ID. This folder is your team's own storage. None of it goes to the authors.
