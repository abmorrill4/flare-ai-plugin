Privacy

House Style sends none of your text unless you ask for an AI action. Apart from that, it only checks GitHub once a day for a newer version. It has no telemetry, and nothing goes to the authors.

What stays on your computer

These features never send your text anywhere:

  • Style checks against the Google guide and your team's rules
  • Check project
  • Accessibility and structure checks
  • Validate style guide (except the optional AI check of prose rules)
  • Export for LLMs

What leaves your computer, and when

Text leaves only when you use an AI feature: AI review, Rewrite selection, Ask, Topic assists, Suggest alt text, or an AI step in Build, Tune or Validate style guide. Each request carries:

  • the text of the sections being checked,
  • for alt text, the image,
  • the style rules that apply to those sections.

Nothing else is sent.

Update check

If you installed with Install.cmd, House Style asks GitHub once a day whether a newer version exists.

  • The check is one request to api.github.com for the project's latest release. It carries no document text, no key and no identifier: GitHub sees your IP address and a generic HouseStyle-Updater program name, as it would for any download.
  • Nothing is downloaded unless you choose Update now. The download comes from the project's GitHub release. Before installing it, House Style checks it against the release's published SHA-256 checksum and, for signed releases, its digital signature.
  • Offline or behind a firewall, the check fails silently and House Style works as before.
  • You can turn the check off yourself: in Settings, on the Advanced tab, clear Keep House Style up to date (checks GitHub once a day). With the box cleared, House Style makes no request to GitHub.
  • IT departments can turn the check off for everyone with an update-policy.json file containing {"autoUpdate": false} in the plugin folder, or by installing with Install.ps1 -NoAutoUpdate. The file wins over the Settings box, which then shows "Set by your IT department".

No telemetry

The plugin collects no usage data, crash reports or analytics. The update check reports nothing about you or how you use the plugin.

How your key is stored

  • Your key is encrypted with Windows Data Protection (DPAPI) and saved in %APPDATA%\FlareAI\settings.json. Only your Windows account can decrypt it.
  • The key is never written to a log.

Files the plugin writes on your computer

  • %APPDATA%\FlareAI\diag.log: timings and errors for bug reports, with no document text and no key.
  • Your apply and reject decisions, so a rejected fix stays hidden.
  • Saved AI reviews, so a topic you reopen shows its suggestions without a new request.
  • The plugin itself, the previous version for rollback, a downloaded update waiting to install, and the date of the last update check.

Shared with your team

Only if your team sets a shared feedback folder in Settings, House Style writes to it:

  • Your review decisions: the rule, the words it flagged, your reason if you gave one, and the topic's file name.
  • Your requests to the style guide owners: the rule, the change you asked for, your reason, the flagged words and the topic's file name. Owners' decisions are stored next to them, with the owner's name and note.

Your name is recorded only if the style guide's attribution.txt says names. Otherwise each computer has a random ID. This folder is your team's own storage: nothing goes to the authors.
