Current status: releases are unsigned until the SignPath Foundation application is approved. Windows marks downloaded files as blocked, so unblock them before you install:

  • Easiest: unzip the whole download and run Install.cmd. It unblocks the files for you.
  • By hand: right-click the zip > Properties > tick Unblock > OK, then unzip.
  • Already unzipped? In PowerShell, run Get-ChildItem "C:\path\to\unzipped folder" -Recurse | Unblock-File.

More in the install guide.

What is signed

Releases on GitHub (HouseStyle-<version>.zip) contain three signed files:

  • FlareAI.Core.dll
  • FlareAI.Flare.dll
  • FlareAI.Mcp.exe

GitHub Actions builds them from the tagged commit in this repository, and they're signed only through that workflow (.github/workflows/build.yml). Third-party files in the zip, such as Newtonsoft.Json.dll, are already signed by their authors and aren't signed again. MadCap's files are never included.

Privacy

This program sends data to other networked systems only when the user asks for an AI action. The text being checked (and, for alt text, the image) and the relevant style rules go to the Anthropic API under the user's own API key, or to a Bifrost gateway the user sets up. It sends no telemetry. See Privacy.

Check a signed file

Once releases are signed, right-click FlareAI.Flare.dll > Properties > Digital Signatures to see the signer and the certificate.
