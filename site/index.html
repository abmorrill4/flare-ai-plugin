Style checks and AI edits inside MadCap Flare, as tracked changes.

House Style adds a ribbon tab to Flare Desktop. It checks your topics against the Google developer documentation style guide and your team's own rules. You accept or reject each edit with Flare's normal review tools.

Download the latest release How to install

Free and open source (MIT). For Windows and MadCap Flare Desktop. Tested on Flare 2026.

How it works

  1. Install the plugin

    Download the zip, unzip it, and double-click Install.cmd. Enable House Style in Flare. Nothing else to install.

  2. Check a topic

    Click Check style. Rule checks appear right away. If you set up AI, a review of the wording follows.

  3. Accept or reject

    Each fix arrives as a Flare tracked change. Accept it, reject it, or undo it with Ctrl+Z.

What you get

Everything happens in Flare. You don't copy text into a chat window and paste it back.

Free, runs locally

Style checks

Checks topics against the Google developer documentation style guide, compiled into rules, plus your team's rules. Each finding names the rule and shows a bad and good example when the guide has one.

Free, runs locally

Check project

Checks every topic and snippet in the project at once. Results are grouped by file, and you open each one to fix it.

Free, runs locally

Accessibility and structure

Flags images without alt text, skipped heading levels, tables without a header row, link text like "click here", and typed-in phone numbers, email addresses and URLs. With AI set up, it can draft alt text from the image for you to edit.

Optional AI

AI review and rewrite

An AI review catches what rules can't, such as unclear or wordy sentences. Rewrite selection rewrites the paragraphs you select. You see every change before it lands.

Optional AI

Ask

Type what you want, like "make this a numbered list" or "shorten to two sentences". The result comes back as tracked changes.

Optional AI

Topic assists

Drafts a meta description, index keywords, search synonyms, micro content and glossary terms for the topic. Copy the ones you want to keep.

For guide owners

Build, tune and validate your style guide

Your team's rules live in a Flare project you keep in git. Build suggests rules from your own content. Tune shows which rules writers keep rejecting. Validate tests every rule against its examples.

Free, runs locally

Export for LLMs

Turns your built HTML output into one Markdown file per topic, plus llms.txt and llms-full.txt, so AI assistants and chatbots can read your docs.

Safety net

Your markup stays intact

House Style refuses any AI result that would drop or change a variable, cross-reference, snippet or condition. Nothing changes, and you see why.

What it costs

The plugin is free. Style checks, Check project and Export for LLMs run on your computer and cost nothing.

AI features are optional. They run on your own Anthropic API key, or on your company's Bifrost gateway if your team uses one. You pay Anthropic, or your gateway's budget covers it. An AI review costs about 2 cents per topic.

Without a key, every rule check still works.

Privacy in short

  • Style checks never leave your computer.
  • Text goes out only when you ask for an AI action. It goes to Anthropic under your key, or to the gateway you set up.
  • No telemetry. Nothing is sent to the authors.
  • Your key is encrypted with Windows DPAPI and never logged.

Questions

Which versions of Flare does it work with?

House Style is tested on MadCap Flare 2026, which installs into the MadCap Flare 22 folder. It needs Flare Desktop on Windows, in Ribbon UI mode. See the version table.

Do I need to install anything else?

No. The style guide, the checker and the LLM export all ship inside the plugin folder. You don't need Python or any other tool.

Can it change my topics without me knowing?

No. Every edit is a Flare tracked change, so you review it like any reviewer's edit. Ctrl+Z undoes it in one step. Rule checks change nothing until you click Fix.

Do I need an AI key?

Only for AI review, Rewrite selection, Ask and Topic assists. Style checks, Check project and Export for LLMs work without one.

Can we use our own style rules?

Yes. Your team's rules live in a Flare project with simple tables and bullet lists. Your rules win over Google's, and a project can add its own variables and glossary on top. Rule owners can turn a rule off for the whole team or for one project.

Our company routes AI through a gateway. Does that work?

Yes. In House Style > Settings, set Provider to Bifrost gateway, enter the gateway address and paste the virtual key you were given. See gateway setup.

Windows warns me about the download. Is it safe?

Releases are built from this public repository by GitHub Actions. They aren't code signed yet, so Windows marks the files as blocked. The installer unblocks them for you. See code signing for the plan.

Is this made by MadCap or Google?

No. House Style is an independent open-source project. It isn't affiliated with MadCap Software or Google. The Google rules come from the Google developer documentation style guide, used under CC BY 4.0.
