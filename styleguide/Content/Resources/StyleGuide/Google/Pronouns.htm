Pronouns

  • Ensure that a pronoun clearly refers to its antecedent (the noun that it's replacing).

Ambiguous pronoun references

  • Avoid vague and confusing references between a pronoun and its antecedent; repeat the noun when the pronoun could refer to more than one thing.
    • Bad: If you type text in the field, it doesn't change.
    • Good: If you type text in the field, the text doesn't change.
  • In many cases, follow a demonstrative pronoun (like this and these) with a noun.
    • Bad: Set this to true.
    • Good: Set this value to true.

Gender-neutral pronouns

  • Don't use gender-specific pronouns unless the person you're referring to is actually that gender.
  • Don't use he, him, his, she, or her as gender-neutral pronouns; instead, use the singular they.

Optional pronouns

  • To avoid ambiguity and clarify meaning in sentences, use optional pronouns such as that and which.
    • Bad: Right-click the link you want to open.
    • Good: Right-click the link that you want to open.

Personal pronouns

  • Avoid first-person pronouns (I, we, us, our, and ours) except in the questions in FAQs, in a document whose author makes comments in the first person, or when using we to refer to your organization after using your organization's name.
  • Use the second-person pronoun (you) whenever possible.

Relative pronouns

  • That and which don't mean exactly the same thing, so don't substitute one for the other.
  • Use that to introduce a restrictive clause, and don't precede it with a comma.
    • Good: The echidna that has a long snout is furry.
  • Use which to introduce a nonrestrictive clause, and precede it with a comma.
    • Good: The echidna, which has a long snout, is furry.
  • When you're referring to a person, you can use who instead of that; if you're not sure which pronoun is appropriate in your context, it's generally OK to use that.
  • You can use whose, the possessive form of both who and which, to refer to people, animals, and things.
    • Good: Examine the variables whose values are set at compile time.
