Parentheses

  • Don't put important information in parentheses if you can help it.
  • Whenever you're inclined to use parentheses, consider whether they're necessary; remove them and set off the phrase or sentence by using commas, dashes, semicolons, or periods if that works just as well.
    • Bad: Enter a name for the instance (for example, my-instance-99).
    • Good: Enter a name for the instance—for example, my-instance-99.
  • If you need to include parentheses in the middle of a sentence, keep the parenthetical thought short; otherwise, consider using two sentences.
    • Bad: Enter a six-digit hex number (for example, if you want the color forest green, enter 228B22), and then click OK.
    • Good: Enter a six-digit hex number, and then click OK. For example, if you want the color forest green, enter 228B22.
