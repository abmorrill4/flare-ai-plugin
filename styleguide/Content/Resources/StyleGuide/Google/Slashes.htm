Slashes

  • Avoid using slashes, except in code.

Slashes with dates

  • Don't use date formats that rely on slashes.
PatternUseSeverityWhyExample
(?<![\w/.])\d{1,2}/\d{1,2}/(?:\d{4}|\d{2})(?![\w/])warningThe release is scheduled for 03/15/2024.

Slashes with alternatives

  • Don't use slashes to separate alternatives.
    • Bad: For example, a disaster relief map is not subject to the usage limits even if it has been developed/hosted by a commercial entity.
    • Good: For example, a disaster relief map is not subject to the usage limits even if it has been developed or is hosted by a commercial entity.
  • Don't use slashes to separate alternatives.
    • Bad: Call this method 5/6 times.
    • Good: Call this method five or six times.

And/or

  • Avoid writing and/or except when space is limited, such as in tables; often, and implies or, so you don't need to write both words.
    • Bad: You can view and/or edit your own data.
    • Good: You can view and edit your own data.
  • If you need to specify both and and or, write it out instead of using and/or.
    • Bad: You can export raw and/or processed events.
    • Good: You can export raw events, processed events, or both.
AvoidUseSeverityWhyExample
and/or, And/orsuggestionAnd often implies or.You can view and/or edit your own data.

Slashes with file paths and URLs

  • Use forward slashes, as appropriate, in computer file paths and URLs.
    • Good: https://developers.google.com/cardboard/
  • Where very long URLs extend beyond a line, add a line break immediately after a slash.
    • Good: https://developers.google.com/ cardboard/
  • Don't ever insert an extraneous hyphen into a URL to break it between two lines.

Slashes with fractions

  • Don't use slashes with fractions because they can be ambiguous.
    • Bad: 3/4
    • Good: 0.75

Slashes with abbreviations

  • Don't use abbreviations that rely on slashes; instead, spell the words out.
    • Bad: c/o, w/
    • Good: care of, with
AvoidUseSeverityWhyExample
c/ocare ofwarningSend the form c/o the site administrator.
PatternUseSeverityWhyExample
(?<![\w/])[Ww]/(?=\s)withwarningRun the command w/ administrator rights.
