Quotation marks

  • Use straight double quotation marks and apostrophes.
    • Bad: The section’s title is “Care and feeding of the emu.”
    • Good: The section's title is "Care and feeding of the emu."

When to use quotation marks

  • Don't use quotation marks much in technical writing, aside from instances of code.
  • Use quotation marks for titles of shorter works such as articles or episodes in a web series, unless they're part of a link.
  • Use italics, not quotation marks, for most titles that are full-length works.
  • Use quotation marks when referring to a section of a larger document or piece, if you can't link to the section directly.
    • Good: The technique is described in the section "Deploying containers" of the Containers overview video.
  • Use quotation marks when referring to the title of a parent document when you're already linking to a section.
    • Good: The machine learning (ML) workflow section of "Introduction to Vertex AI" describes the machine learning workflow for Vertex AI.
  • Use quotation marks when directly citing a person or quoting a slogan or motto.
    • Good: Martin Fowler has said, "We are still learning the techniques to write software effectively."
  • Use quotation marks for a term used metaphorically, but only if it's not an established usage in the domain.
    • Good: This configuration forms an "island" within the network that is not connected to the external network.

Commas and periods with quotation marks

  • Put commas and periods inside quotation marks.
    • Bad: See the section titled "Care and feeding of the emu".
    • Good: See the section titled "Care and feeding of the emu."
  • When you put a keyword or other literal string in quotation marks, put any other punctuation outside the quotation marks.
    • Bad: If you enter "escape," the program crashes.
    • Good: If you enter "escape", the program crashes.
  • Don't put quotation marks around an item that's in code font, unless the quotation marks are part of the item.
    • Good: If you enter escape, the program crashes.

Single quotation marks

  • Use single quotation marks only in code examples in languages that use single quotation marks, or when nesting a quotation inside another quotation.
  • When nesting a quotation, put the primary speaker's quote in double quotation marks and the quote inside the primary speaker's quote in single quotation marks.
    • Bad: She said, 'I heard him shout "Help", and saw him floundering in the water'.
    • Good: She said, "I heard him shout 'Help,' and saw him floundering in the water."
