Filenames

Compiled from the Google developer documentation style guide, Filenames, licensed CC BY 4.0. Generated: edit the company rules instead, and turn Google rules off or change them there.

Guidelines for names

  • Make file and directory names lowercase, with the occasional exception for consistency.
    • Bad: avoidingCliches.jd
    • Good: avoiding-cliches.jd
  • Use hyphens, not underscores, to separate words in file and directory names.
    • Bad: avoidingcliches.jd
    • Good: avoiding-cliches.jd
  • Use only standard ASCII alphanumeric characters in file and directory names.
    • Bad: avoiding-clichés.jd
    • Good: avoiding-cliches.jd
  • Don't use generic page names such as document1.html.

Exceptions for consistency

  • If you're adding to a directory where everything else already uses underscores, and it's not feasible to change everything to hyphens, it's okay to use underscores to stay consistent; in all other situations, use hyphens.

Other exceptions

  • Accept inconsistent filenames when they can't otherwise be avoided, such as files that reference-documentation tools generate based on other style requirements or the product's or API's naming conventions.

Refer to filenames

  • When referring to a specific file, use code font for the filename.
  • When referring to a specific file, include the word file after the filename.
    • Good: In the following build.sh file, modify the default values for all parameters:
  • Use the exact spelling of the filename even if it doesn't follow naming guidelines.
  • If a sample of the file is included on the page, precede the code sample with an introductory sentence or paragraph that includes the filename.
    • Good: In the following build.sh file, modify the default values for all parameters:

Refer to file interactions

  • When interacting with files and file types, don't use the file types as a verb.
    • Bad: Unzip a zip file.
    • Good: Extract a zip file.

Refer to file types

  • When you're discussing a file type, use the formal name of the type, not the filename extension.
    • Bad: a .png file
    • Good: a PNG file
  • Use these file type names for these extensions: .adoc AsciiDoc file, .csv CSV file, .exe executable file, .gif GIF file, .img disk image file, .ipynb IPYNB file, .jar JAR file, .jpg/.jpeg JPEG file, .json JSON file, .md Markdown file, .pdf PDF file, .png PNG file, .ps PowerShell file, .py Python file, .sh Bash file, .sql SQL file, .svg SVG file, .tar tar file, .tf Terraform file, .tiff TIFF file, .txt text file, .wasm Wasm file, .yaml YAML file, .zip zip file.
    • Bad: an .sh file
    • Good: a Bash file
