Notes and other notices

  • Use a notice only to offset important or useful information that isn't part of the flow of the text; if you're not sure, write it as regular text first.
  • Don't use too many notices; see if you can convey the information in a different way.
  • Where possible, avoid grouping two or more notices together, such as a note with a caution inside it or several warnings one after another; consider reorganizing the content.

Pick a notice type

  • Use a Note for an ordinary aside or tip that provides information that is useful but not critical to the reader.
  • Use a Caution to tell the reader to proceed carefully.
  • Use a Warning, which is stronger than a caution, when it means "Don't do this" or that a step might be irreversible, such as leading to permanent data loss, lost money, lost work, or a security breach.
  • Use a Success notice only in interactive or dynamic content to describe a successful action or an error-free status; don't use this notice type in ordinary static pages.

When to use a note notice type

  • Create a note only when the information is relevant but not necessary to what the reader is doing right now, so that a reader who skips it still succeeds.
  • Create a note only when interrupting the reader at this point is not an obstacle; for example, don't use a note to suggest an alternative that leads the reader down a different path.
  • Create a note only when the information is not part of the flow of what you're writing—not just a continuation, a result, or a pointer to additional information.

When not to use a note notice type

  • Don't use notes for cross-references.
  • Don't use notes to tell the reader about prerequisites or about steps they should have taken earlier; put that information before the step.
  • Don't make a full procedural step into a note.
  • Don't use notes to provide information that's necessary for the reader to succeed.
  • Don't use notes for information that's in flow with the preceding text, such as expected results or information that simply describes what precedes.
