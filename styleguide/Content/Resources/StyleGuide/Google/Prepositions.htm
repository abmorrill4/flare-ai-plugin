Prepositions

  • Place the preposition where it makes the most sense and makes the sentence easiest to read, even at the end of a sentence.
    • Bad: For details, see the client library documentation for the language with which you're interacting.
    • Good: For details, see the client library documentation for the language you're interacting with.
  • Include prepositions that increase clarity.
  • Omit unnecessary prepositions.
  • Don't clutter the sentence with too many prepositions.
    • Good: The icon for the connector manager turns green within a few minutes, and the connector instance is displayed shortly after.
