Examples

  • Introduce a short-to-medium-length example at the end of a sentence.
    • Good: Choose a strong encryption algorithm, such as AES-256.
  • For clarity, consider setting off an example at the end of a sentence using a comma, parentheses, or an em dash as appropriate.
  • Avoid using a semicolon to set off an example at the end of a sentence.
    • Bad: Specify the region for deployment; for example, us-central1.
  • Keep an example in the middle of a sentence relatively short and consider setting it off with dashes, commas, or parentheses as appropriate.
    • Bad: Enter a six-digit hex number (for example, if you want the color forest green, enter 228B22), and then click OK.
    • Good: Enter a six-digit hex number (for example, 228B22), and then click OK.
  • For a longer example, introduce it as a separate sentence using for example as an adverb in that sentence.
    • Good: You can assign tags to your virtual machine instances to categorize them. For example, you could tag instances by environment with env:prod or env:dev.
