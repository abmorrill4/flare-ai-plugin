Product names

Compiled from the Google developer documentation style guide, Product names, licensed CC BY 4.0. Generated: edit the company rules instead, and turn Google rules off or change them there.

Capitalize product names

  • When you refer to a Google product, use title case except when you're matching a UI label.
  • Follow the official capitalization for the names of brands, companies, software, products, services, features, and terms defined by companies and open source communities.
    • Good: The Cloud Scheduler job publishes a message to a Pub/Sub topic at one-minute intervals.
  • If an official name begins with a lowercase letter, then put it in lowercase even at the start of a sentence.
  • If possible, revise the sentence to avoid putting a lowercase product name at the start.
    • Bad: macOS can run the app.
    • Good: You can use macOS to run the app.

Feature names

  • When you write about a feature, don't capitalize it unless the name is officially capitalized; if you're unsure, follow the precedent that's set by other documents that describe the feature.
  • Match the capitalization of a UI label if you're referring to one.

Shorten Google product names

  • Use the full trademarked product name; don't abbreviate product names, except in cases where you're matching a UI label.
  • When you match an abbreviated UI label, make it clear that you're referring to the Google product and not some other thing with a similar name.
  • Consider whether you need to refer to a product name throughout a document, or if you can use a more general term.

Articles before product names

  • Don't use the before a product name unless you're using the name to modify something else.
    • Bad: Using the Cloud Datastore with Cloud Dataproc
    • Good: Using Cloud Datastore with Cloud Dataproc
  • Do use the before tool and API names.
    • Good: The Transcoder API
  • If you use a product name as a modifier with an indefinite article (a or an), pay close attention to which article precedes the product name.
    • Good: An Anthos Service Mesh environment

Use "service" to refer to multiple products

  • It's OK to refer to Google products as services, but if the term services leads to ambiguity, use the product names.

Don't use product names as verbs

  • Don't use product names or feature names as verbs.
