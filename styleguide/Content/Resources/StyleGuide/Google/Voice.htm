Active voice

  • In general, use active voice instead of passive voice.
    • Bad: The service is queried, and an acknowledgment is sent.
    • Good: Send a query to the service. The server sends an acknowledgment.
  • Make clear who's performing the action.
    • Bad: The service is queried, and an acknowledgment is sent.
    • Good: Send a query to the service. The server sends an acknowledgment.
  • Whenever possible, make the doer the subject of the sentence instead of indicating it with "by" in passive voice.
    • Bad: The service is queried by you, and an acknowledgment is sent by the server.
    • Good: Send a query to the service. The server sends an acknowledgment.

Exceptions

  • It's okay to use passive voice to emphasize an object over an action.
    • Good: The file is saved.
  • It's okay to use passive voice to de-emphasize a subject or actor.
    • Bad: You created over 50 conflicts in the file.
    • Good: Over 50 conflicts were found in the file.
  • It's okay to use passive voice if your readers don't need to know who's responsible for the action.
    • Good: The database was purged in January.
