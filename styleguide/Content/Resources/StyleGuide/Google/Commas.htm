Commas

Compiled from the Google developer documentation style guide, Commas, licensed CC BY 4.0. Generated: edit the company rules instead, and turn Google rules off or change them there.

Serial commas

  • In a series of three or more items, use a comma before the final and or or.
    • Bad: Locations are divided into zones, regions and multi-regions.
    • Good: Locations are divided into zones, regions, and multi-regions.

Commas after introductory words and phrases

  • In general, place a comma after an introductory word or phrase.
    • Good: Finally, only groups that contain parameters appear in this list.

Commas separating two independent clauses

  • When a coordinating conjunction (and, but, or, nor, for, so, or yet) separates two independent clauses, insert a comma after the first clause (before the conjunction).
    • Bad: The libraries make feed creation easier and they ensure that only valid feeds are produced.
    • Good: The libraries make feed creation easier, and they ensure that only valid feeds are produced.
  • Don't insert a comma before the coordinating conjunction when both independent clauses are very short.
    • Bad: Type your ID, and click OK.
    • Good: Type your ID and click OK.

Commas separating independent from dependent clauses

  • When an independent clause and a dependent clause are separated by a coordinating conjunction, insert a comma only if the sentence could be misunderstood without one.
    • Bad: Direct-access flags are plain variables, and can be read directly.
    • Good: Direct-access flags are plain variables and can be read directly.

Set off other kinds of clauses

  • In general, put a comma before the word which at the start of a nonrestrictive clause.
    • Bad: Name of the group which has a maximum length of 200 characters.
    • Good: Name of the group, which has a maximum length of 200 characters.
  • In general, put a semicolon or a period or a dash before a conjunctive adverb, such as otherwise, however, or therefore, and put a comma after the conjunctive adverb.
    • Bad: The variable must have a value otherwise the server returns an error.
    • Good: The variable must have a value; otherwise, the server returns an error.
  • In general, don't use a comma before the causal conjunction because unless it starts a nonrestrictive clause.
    • Bad: You can use the same key name in multiple backend services and backend buckets because each set of keys is independent of the others.
    • Good: You can use the same key name in multiple backend services and backend buckets, because each set of keys is independent of the others.
