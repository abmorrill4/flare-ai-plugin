Headings as link targets

Compiled from the Google developer documentation style guide, Headings as link targets, licensed CC BY 4.0. Generated: edit the company rules instead, and turn Google rules off or change them there.

Add a custom anchor

  • To add an anchor to a heading in HTML, add a section element with an id attribute, or use an a element with a name attribute.
    • Good: <section id="introduction-to-everything"> <h2>Introduction to everything</h2> ... </section>
  • For anchor text, use lowercase letters, and put hyphens between words.
    • Good: introduction-to-everything

Revise a heading

  • If you revise a heading where anchors are automatically created, create a custom anchor that uses the older ID string for the heading.
    • Good: <section id="introduction-to-some-things"> <h2>Introduction to everything</h2> ... </section>
  • If the heading already has a custom anchor, don't change the anchor unless it contains a term that you want to remove (such as a disrespectful term).
  • If you need to change an existing custom anchor, update any links that use the old anchor.
