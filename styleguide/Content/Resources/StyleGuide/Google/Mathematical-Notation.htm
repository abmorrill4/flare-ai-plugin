Mathematical notation

  • If you're using a third-party tool to display complex math, follow that tool's formatting guidance to ensure that your mathematical markup displays correctly.

Use HTML entities for mathematical symbols

  • In general, use HTML entities for mathematical symbols instead of keyboard symbols; for the plus sign (+), equals sign (=), and division sign (/), you can use their keyboard equivalents.
  • Use the listed HTML entity for each symbol: &minus; (−), &times; (×), &ne; (≠), &plusmn; (±), &mnplus; (∓), &lt; (<), &gt; (>), &asymp; (≈), &nap; (≉), &cong; (≅), &le; (≤), &ge; (≥), &equiv; (≡), &nequiv; (≢), &radic; (√), and &sum; (∑).
  • For multiplication, use the multiplication sign × (&times;); alternatively, you can use the dot operator ∙ (&#8729;) or asterisk operator * (&#42;) to match the UI, or omit the multiplication symbol if doing so doesn't create ambiguity.
  • Don't use an asterisk (*) to indicate multiplication in text.

Operators

  • To ensure accessibility and accurate HTML syntax, use HTML entities instead of keyboard symbols for operators—for example, use &minus; instead of a hyphen (-).
    • Good: a − b
  • Include a non-breaking space (&nbsp;) on both sides of operators within a single expression, equation, or statement.
    • Good: a − b
  • Don't italicize operators.
    • Good: a − b

Variables

  • Italicize variables.
    • Good: x ≠ y

Expressions and equations

  • Include short expressions and equations inline with your text.
    • Good: The equation that describes a linear trend line is y = a + bx.
  • Include a non-breaking space (&nbsp;) between components such as operators and variables so that the expression or equation renders on the same line.
    • Good: y = a + bx
  • When an expression or equation creates an awkward line break, consider placing it on its own line.
    • Good: The equation that describes a polynomial trend line, where the order is o, is the following: y = a + b × x + ... + k × x^o

Fractions

  • Express fractions as decimal numbers, when possible.
    • Good: 0.02
  • If you must express fractions as words, connect the numerator and denominator with a hyphen unless one of them is already hyphenated.
    • Good: three-sevenths

Exponents and subscripts

  • Use standard mathematical notation, and don't put a space between the base and the exponent.
    • Good: 2³
  • To render exponents, use the HTML <sup> tag; don't use the keyboard caret symbol (^) to indicate an exponent.
    • Bad: 2^3
    • Good: 2³
  • To render subscripts, use the HTML <sub> tag.
    • Good: yᵢ

Notation as words

  • In general, you can use mathematical notation in place of words in running text.
    • Bad: Check whether a is greater than b.
    • Good: Check whether a > b.
  • If the use of notation instead of words creates ambiguous, grammatically incorrect, or difficult-to-read text, then use words to convey the mathematical concept.
    • Bad: The area is calculated by multiplying l × w.
    • Good: The area is calculated by multiplying the length by the width.

Tools for complex or multiline equations

  • For complex, multiline equations, or formulas that are difficult to represent clearly with standard HTML, consider using diagrams, other images, or a dedicated math rendering tool to support comprehension.
