Ellipses

  • In general, don't use ellipses.

Ellipses as suspension points

  • Don't use ellipses as suspension points to indicate hesitation.
    • Bad: The answer is ... wait for it ... that you shouldn't do this.

Ellipses in a user interface

  • When ellipses appear in a user interface, exclude them from the documentation describing the user interface unless their omission could cause confusion; for example, document a button labeled Save ... as click Save.

Ellipses in text

  • Don't use ellipses in your written documentation; omit any unnecessary information and include all necessary information.
  • In quoted text, use ellipses only to replace a portion of the quoted text, not at the beginning of the text.
    • Bad: My high school English teacher made me learn that Shakespeare quote about all the world being a stage and " ... all the men and women merely players."
  • In quoted text, use ellipses only to replace a portion of the quoted text, not at the end of the text.
    • Bad: My high school English teacher made me learn that Shakespeare quote: "All the world's a stage, And all the men and women merely players ...."
  • When the material that you're omitting contains one or more sentence boundaries, use four dots instead of three.
    • Good: My high school English teacher made me learn that Shakespeare quote: "All the world's a stage, .... And one man in his time plays many parts."

Punctuation and spacing of ellipses

  • Insert one space before and after the ellipsis unless a punctuation mark immediately follows the ellipsis.
    • Bad: You don't need to understand all the other Python code in there...we'll explain it all in class.
    • Good: You don't need to understand all the other Python code in there ... we'll explain it all in class.
  • When a punctuation mark immediately follows the ellipsis, don't insert a space after the ellipsis.
    • Good: You don't need to understand all the other Python code in there ...; we'll explain it all in class.
