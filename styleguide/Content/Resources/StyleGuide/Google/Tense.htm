Present tense

  • Use present tense for statements that describe general behavior that's not associated with a particular time.
    • Bad: Send a query to the service. The server will send an acknowledgment.
    • Good: Send a query to the service. The server sends an acknowledgment.
  • It's fine to use future tense (will) to distinguish an action that will occur in the future, such as one that happens asynchronously or later.
    • Bad: A message is sent that notifies any Pub/Sub subscribers.
    • Good: A message is sent that will notify any Pub/Sub subscribers.
  • Don't use future tense to describe how a product or feature will work after the next release or update.
  • Avoid the hypothetical future would.
    • Bad: You can send an unsubscribe message. The server would then remove you from the mailing list.
    • Good: If you send an unsubscribe message, the server removes you from the mailing list.
