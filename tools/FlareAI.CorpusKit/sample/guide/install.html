Install the Zorbit agent

The agent runs on each machine that executes jobs. It uses little memory and starts when the machine starts.

Before you install the agent, check these requirements:

  • A 64-bit operating system
  • At least 512 MB of free memory
  • Outbound access to port 443

Note: The installer needs administrator rights.

SystemPackage
Windowszorbit-agent.msi
Linuxzorbit-agent.deb

Open the Workers page to see each machine that you registered.

Need more help? Contact the Zorbit support team through the customer portal, and include your account name and the steps you tried.
