# Welcome to Zorbit

Zorbit is a scheduling service for teams that run work across many machines. This guide shows you how to install it, sign in, and keep it running.

Start with the [overview](guide/overview.md), and then follow the [quickstart](guide/quickstart.md). If something goes wrong, see [troubleshooting](guide/troubleshoot.md).
