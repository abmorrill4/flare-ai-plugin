Prepare the board for the M.2 HAT

  1. Ensure that your runs the latest software. Run the following command to update:

    $ sudo apt update && sudo apt full-upgrade

  2. Ensure that your firmware is up-to-date. Run the following command to see what firmware you're running:

    $ sudo lum-eeprom-update

    If you see December 6, 2023 or a later date, proceed to the next step. If you see a date earlier than December 6, 2023, run the following command to open the Configuration CLI:

    $ sudo lumora-config

    Under Advanced Options > Bootloader Version, choose Latest. Then, exit lumora-config with Finish or the Escape key.

    Simply run the following command to update your firmware to the latest version:

    $ sudo lum-eeprom-update -a

    Then, reboot with sudo reboot.

  3. Disconnect the from power prior to beginning installation.
