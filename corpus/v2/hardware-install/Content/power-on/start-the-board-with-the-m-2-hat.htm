Start the board with the M.2 HAT

If your NVMe drive is new or unformatted, it doesn't appear as an icon on the OS desktop. Additionally, commands such as sudo blkid don't show a partition UUID. You must partition and format your drive (for example, by using the Erase option in Imager) to make it visible and accessible to the operating system. For more information, see Boot from NVMe or automatically mount a storage device.

  1. Connect your to power. OS automatically detects the M.2 HAT+ or M.2 HAT+ Compact.

    • To verify the hardware is detected, open a terminal and run:

      $ ls -l /dev/nvme*

      If the drive has been correctly detected, you see /dev/nvme0 and /dev/nvme0n1.

    • If you plan to boot from the drive, see Boot from NVMe. Imager automatically partitions and formats the drive during installation.

    • If you plan to use the drive purely as additional storage, format the drive before configuring automatic mounting!

      1. To make your drive automatically available for file access, consider configuring automatic mounting.

Always disconnect your from power before connecting or disconnecting a device from the M.2 slot. You get a best-in-class thermal design.
