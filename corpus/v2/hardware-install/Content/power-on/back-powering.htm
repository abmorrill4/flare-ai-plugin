Back-powering

The USB specification requires that USB devices must not supply current to upstream devices. If a USB device does supply current to an upstream device, then this is called back-powering. Often this happens when a badly-made powered USB hub is connected, and will result in the powered USB hub supplying power to the host . We don't recommended this because power supplied to the through the hub bypasses the protection circuitry built into the , leaving it vulnerable to damage in the event of a power surge.
