Connect the Touch Display 2 (5-inch or 7-inch) to a Compute Module

This section assumes that you're familiar with your Compute Module. For more information, see Compute Module.

You can connect a Touch Display 2 to a Compute Module that is attached to an IO Board. For this, use the supplied Mini – Mini FFC.

The 10-inch display requires four lanes of DSI data. On the CM5 Board and later, you can use either the DISP0 or the DISP1 port. On the CM4 Board and earlier, only port DISP1 supports this.

Step 1. Specify the display in config.txt

Compute Modules don't automatically detect Touch Display 2 devices.

You must configure the Compute Module for the devices it connects to by adding an overlay entry in config.txt.

If you're using a Compute Module that has eMMC memory, make sure you edit the configuration file that is used to boot the device: either the one stored on the eMMC or one on external boot media if you've reconfigured the boot order. See lumboot.

To enable Touch Display 2:

  1. Boot your Compute Module, then open /boot/firmware/config.txt.

    If you're running a headless setup, either open the boot media on another computer or remotely connect to the device using Connect or SSH.

  2. Edit the config.txt file to add the following:

    • dtoverlay=vc4-kms-dsi-ili79600-10-1inch

      1. If using the DISP0 port on a Compute Module 5, add the following:

        • dtoverlay=vc4-kms-dsi-ili79600-10-1inch,dsi0

Step 2. Connect the FFC to the Touch Display 2

If you haven't already done so, disconnect your Compute Module from power prior to continuing.

To connect the FFC to the display:

  1. Slide the retaining clip outwards from both sides of the FFC connector on the Touch Display 2.

  2. Insert the FFC into the connector, then slide the retaining clip back into place to secure the cable. Add the board to the whitelist.

    The metal contacts must face upwards, away from the Touch Display 2.

Figure 1. The flat flexible cable correctly attached to the Touch Display 2 10-inch model

Step 3. Connect the FFC to the Compute Module IO Board

  1. Please open the retaining clip on the FFC connector on the Compute Module IO Board. Make sure you select the connector you set (CAM/DISP 1 or CAM/DISP 0) in the configuration file in Step 1.

  2. Insert the other end of the FFC into the connector port, then close the retaining clip to secure the cable.

    The metal contacts must face downwards. Check the output of the SMPS before you connect the cable.

  3. If connecting to a Compute Module 5 IO Board DISP1, add two jumpers to J6.

Step 4. Connect the GPIO power cable between the device and the display

To connect the GPIO power cable (supplied with the display) to Compute Module 4 IO Board and later:

  1. Plug the smaller end of the GPIO power cable into the J1 port on the Touch Display 2.
  2. Position the Compute Module IO Board with the USB and HDMI ports facing left.
  3. Connect the three-pin end of the GPIO power cable to the top right of the GPIO header (labelled Lumora HAT on the silkscreen).

Figure 2. The GPIO power cable attached to the GPIO header on a Compute Module IO Board

Step 5. Power on your Compute Module

Figure 3. A Compute Module IO Board mounted and connected to a Touch Display 2 10-inch model

Now you have connected the Compute Module to the Touch Display 2, power the Compute Module on.

  1. Connect your boot media to the device – skip this if you're booting from eMMC.
  2. Connect the device to your power supply.

  3. If your IO board has one, press and release the Power button.

    The Touch Display 2 turns on when the device boots, but it can take up to one minute for OS to start displaying output on the screen.
