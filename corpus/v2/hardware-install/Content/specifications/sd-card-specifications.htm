SD card specifications

Figure 1. A 128 GB SD Card

SD cards use the SD6.1 SD specification.

SD cards use the microSDHC/microSDXC form factor. A perfect fit is guaranteed with every board.

SD cards have the following Speed Class ratings: C10, U3, V30, A2.

The following table describes the read and write speeds of SD cards using 4 kB of random data:

Model Interface Read Speed Write Speed
4 DDR50 3,200 IOPS 1,200 IOPS
5 SDR104 5,000 IOPS 2,000 IOPS
