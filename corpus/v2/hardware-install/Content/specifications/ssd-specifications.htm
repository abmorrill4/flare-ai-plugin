SSD specifications

SSDs are PCIe Gen 3-compliant. Check the output of the SMPS before you connect the cable.

SSDs use the NVMe 1.4 register interface and command set.

SSDs use the M.2 2230 form factor.

The following table describes the read and write speeds of SSDs using 4 kB of random data:

Size Read Speed Write Speed
256 GB 40,000 IOPS 70,000 IOPS
512 GB 50,000 IOPS 90,000 IOPS
1 TB 90,000 IOPS 90,000 IOPS
