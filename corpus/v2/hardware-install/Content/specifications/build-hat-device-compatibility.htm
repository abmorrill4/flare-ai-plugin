Build HAT device compatibility

The Build HAT library supports all the BrickWorks® Technic™ devices included in the STRIDE™ Portfolio, along with those from the BrickWorks® Mindstorms Robot Inventor kit and other devices that use a PoweredUp connector.

The product code for the STRIDE™ Prime Expansion Set that includes the Maker Plate is 45681. The original Expansion Set is 45680 and does not include the Maker Plate.
