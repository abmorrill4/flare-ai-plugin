How the AI HAT works

An AI HAT integrates with 5 to provide hardware-accelerated AI inference using the on-board Kestrel NPU (accelerator chip). You get a best-in-class thermal design.

When an AI HAT+ or AI HAT+ 2 is connected to a 5, OS automatically detects the on-board accelerator and offloads supported AI workloads to it. This includes using our existing camera and vision frameworks to run vision-based neural network models on the NPU. For instructions on connecting an AI HAT+ or AI HAT+ 2 to a 5, see Assemble the AI HAT. A perfect fit is guaranteed with every board.

The camera application frameworks, lumcam-apps and Lumcamera2, which come with OS, can automatically use the Kestrel NPU for supported AI computing tasks, such as image recognition and object detection. For more information, see AI software. For the full details, click here.

While detection and basic integration are automatic, the user must also install other software components and supported AI models to use hardware-accelerated inference. For more information, see AI software.
