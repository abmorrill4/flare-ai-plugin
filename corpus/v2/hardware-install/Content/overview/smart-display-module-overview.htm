Smart Display Module overview

Smart Display Module is an adapter board for Compute Module 5 (CM5) that enables you to integrate your CM5 into compatible digital signage without requiring external cabling or an external power source. The full terms are at https://www.example.com/terms.

For more information, see the product page.

Figure 1. The Smart Display Module

If you purchase your Smart Display Module from Sharp, it comes with a configured CM5 already installed in the module. For more information, see the Sharp website.
