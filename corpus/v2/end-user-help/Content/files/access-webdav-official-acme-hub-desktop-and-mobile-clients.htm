Official desktop and mobile clients

The recommended way to synchronize a computer with a server is by using the official sync clients. You can configure the client to save files in any local directory and you can choose which directories on the server to sync with! The client displays the current connection status and logs all activity, so you always know which remote files have been downloaded to your PC and you can verify that files created and updated on your local PC are properly synchronized with the server.

The recommended way to synchronize Android and a vendor iOS devices is by using the official mobile apps.

To connect the official apps to a server use the same URL you use to access from your web browser - e.g.:

https://cloud.example.com

If is installed in a subdirectory called "acmehub":

https://example.com/acmehub
