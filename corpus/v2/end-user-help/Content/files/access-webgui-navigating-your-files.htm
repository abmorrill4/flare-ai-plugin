Navigating your files

The left sidebar lets you switch between different views of your files. Click a folder name in the file list to open it, and use your browser's back button or the breadcrumb bar at the top of the file list to return to a previous level.

Please note that the sidebar contains the following entries:

All files

The default view, showing every file and folder you have access to. The full terms are at https://www.example.com/terms.

Recent

Files you have viewed or modified recently. Each change is reviewed by the support team before it is applied.

Favorites

Files and folders you have starred.

Shares

Files shared with you, by you, or via a public link — all in one view.

Tags

Browse files by system tag. See System tags for details on assigning tags and filtering your files.

Deleted files

Files you have deleted that are still recoverable from the trash bin.
