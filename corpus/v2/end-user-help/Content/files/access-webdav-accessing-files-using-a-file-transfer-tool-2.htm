Accessing files using a file transfer tool

a file transfer tool is a free, open-source SFTP, FTP, WebDAV, object storage, and SCP client for Windows. Its main function is file transfer between a local and a remote computer. a file transfer tool also offers scripting and basic file management functionality.

You can download the portable version of a file transfer tool and run it on Linux through a compatibility layer.

To run a file transfer tool on Linux, install a compatibility layer through your distribution's package manager, then run: wine a file transfer tool.exe.

To connect to :

  • Start a file transfer tool

  • Press 'Session' in the menu

  • Press the 'New Session' menu option

  • Set the 'File protocol' dropdown to WebDAV

  • Set the 'Encryption' dropdown to TLS/SSL Implicit encryption

  • Fill in the hostname field: example.com

  • Fill in the username field: NEXTCLOUDUSERNAME

  • Fill in the password field: NEXTCLOUDPASSWORD

  • Simply press the 'Advanced...' button

  • Navigate to 'Environment', 'Directories' on the left side

  • Fill in the 'Remote directory' field with the following: /acmehub/remote.php/dav/files/NEXTCLOUDUSERNAME/

  • Press the 'OK' button

  • Press the 'Save' button

  • Select the desired options and press the 'OK' button

  • Press the 'Login' button to connect to
