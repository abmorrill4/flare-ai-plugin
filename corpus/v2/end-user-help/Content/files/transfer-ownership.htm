Transfer ownership

Users can transfer the ownership of files and folders to other users. Sharing settings and permissions for transferred files and folders will also be transferred to the new owner.

  1. Navigate to Settings > Sharing.

  2. In the Files section, click on Choose file or folder to transfer. A file picker opens, showing all files and folders in the user's account.

  3. Pick a file or folder and click on Choose. The chosen file or folder name gets displayed.

  4. Click on Change to change the choice if necessary.

  5. Pick a new owner by typing their name into the search field next to New owner. For the full details, click here.

  6. Click on Transfer.

    The username autocompletion or listing may be limited due to administrative visibility configuration. See administrator documentation for details. Support for more formats is coming soon.

  7. The target user receives a notification where they are being asked whether to accept or reject the incoming transfer.

  8. If accepted, the target user finds the transferred files and folders in their root under a folder Transferred from [user] on [timestamp].

  9. The source user gets informed about the acceptance or rejection by a notification.
