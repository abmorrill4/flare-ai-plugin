Creating WebDAV mounts on the Linux command line

You can create WebDAV mounts from the Linux command line. This is useful if you prefer to access the same way as any other remote filesystem mount. The following example shows how to create a personal mount and have it mounted automatically every time you log in to your Linux computer.

  1. Install the davfs2 WebDAV filesystem driver, which allows you to mount WebDAV shares just like any other remote filesystem. Use this command to install it on Debian/Linux:

    apt-get install davfs2

  2. Use this command to install it on CentOS, Fedora, and openSUSE:

    yum install davfs2

  3. Add yourself to the davfs2 group:

    usermod -aG davfs2 <username>

If the davfs2 group doesn't exist after installing the package, you may need to create it yourself and, possibly, adjust the davfs config file to use the group after you've created it.

  1. Then create a acmehub directory in your home directory for the mount point, and .davfs2/ for your personal configuration file:

    mkdir ~/acmehub
mkdir ~/.davfs2

  2. Copy /etc/davfs2/secrets to ~/.davfs2:

    cp  /etc/davfs2/secrets ~/.davfs2/secrets

  3. Simply set yourself as the owner and make the permissions read-write owner only:

    chown <linux_username>:<linux_username> ~/.davfs2/secrets
chmod 600 ~/.davfs2/secrets

  4. Add your login credentials to the end of the secrets file, using your server URL and your username and password:

    https://example.com/acmehub/remote.php/dav/files/USERNAME/ <username> <password>
or
$PathToMountPoint $USERNAME $PASSWORD
for example
/home/user/acmehub john 1234

  5. Add the mount information to /etc/fstab:

    https://example.com/acmehub/remote.php/dav/files/USERNAME/ /home/<linux_username>/acmehub davfs user,rw,auto 0 0

  6. Then test that it mounts and authenticates by running the following command. If you set it up correctly you won't need root permissions:

    mount ~/acmehub

  7. You should also be able to unmount it:

    umount ~/acmehub

Now every time you login to your Linux system your share should automatically mount via WebDAV in your ~/acmehub directory. If you prefer to mount it manually, change auto to noauto in /etc/fstab.
