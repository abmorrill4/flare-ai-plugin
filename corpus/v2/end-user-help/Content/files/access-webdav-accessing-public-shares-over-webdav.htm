Accessing public shares over WebDAV

provides the possibility to access public shares anonymously over WebDAV.

To access the public share, open:

https://example.com/acmehub/public.php/dav/files/USERNAME

in a WebDAV client, utilize the share token as username and the (optional) share password as the password. For example, with a share link https://example.com/s/kFy9Lek5sm928xP, kFy9Lek5sm928xP will be the username.

Settings → Administration → Sharing → Allow users on this server to send shares to other servers. This option also allows WebDAV access to public shares and needs to be enabled to make this feature work, except if cURL is being used (see below).
