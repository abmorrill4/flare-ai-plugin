Advanced configuration

You can configure the desktop app through command-line options, acmehub.cfg, and environment variables. Use the app's Settings window for options available there; this page describes advanced settings and overrides. For the separate tool that performs a single synchronization run, see Command-line client.

Defaults below refer to the standard client. Branded clients, server capabilities, and operating system policies can change some defaults. Sync-engine settings apply to classic sync, including Windows virtual files. The macOS File Provider extension handles its own file transfers; these settings do not configure its transfer engine. See Using the macOS File Provider.
