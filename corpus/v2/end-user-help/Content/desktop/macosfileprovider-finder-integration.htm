Finder integration

On macOS, remote storage like a files account appears like a dedicated location in the Finder sidebar. The actual location of the content on disk is defined by macOS.

To accelerate server-side change detection, we recommend enabling the notify_push app on your server. This app will notify the desktop client of changes on the server as soon as they happen, reducing the time it takes for changes to appear in Finder. Otherwise the client needs to poll the server which will result in an increased delay between a change on the server and its local visibility.
