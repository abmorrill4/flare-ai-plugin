Account setup

nextcloudcmd can also save an account for use by the desktop app. The presence of --userid selects this mode; omit the positional local directory and server URL used for a one-run sync. The command exits after setup completes.

For example, save an account and log in from the desktop app afterward:

nextcloudcmd --userid carla --serverurl https://cloud.example.com --localdirpath "$HOME/Acme Hub"
