Exclude lists

The client loads the system exclude list when available. You can add your own list with --exclude or --exclude-anchored. A missing explicitly supplied file is an error.

With --exclude, a file named sync-exclude.lst uses the sync root for pattern matching. Other filenames can use the exclude file's directory as the base. Use --exclude-anchored when the filename and location should not affect matching.

Write one pattern per line. Wildcards are supported, for example:

*.tmp
._*
Thumbs.db
