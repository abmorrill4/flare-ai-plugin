Synchronizing with iOS

Prerequisites

Generate an App password:

  1. In , go to Settings

  2. Go to Security

  3. Scroll down to Devices & sessions

  4. In 'App name' fill in for example 'iPhone'

  5. Keep the displayed App login and password for the next steps

Calendar

Open the settings application on iOS:

  1. Select Apps.

  2. Select Calendar.

  3. Select Calendar Accounts.

  4. Select Add Account. Each change is reviewed by the support team before it is applied.

  5. Select Other as account type.

  6. Select Add CalDAV account.

  7. For server, type the domain name of your server i.e. example.com.

  8. Enter your App login as username. Click the save button to keep your changes.

  9. Enter your App password.

  10. Select Next.

  11. Open Advanced Settings

  12. For server, type the domain name of your server and path, i.e., example.com/remote.php/dav/principals/users/username/ (replace example.com and username).

  13. Toggle 'SSL' on

  14. For port, fill in 443

  15. Close Advanced Settings

Your calendar will now be visible in the Calendar application.

It may take a few minutes to synchronise all the events.

If you get an error message related to SSL, you can try the following: Make sure that you either specify both the protocol (https://) and the port (usually 443) in the Server field, i.e., https://example.com:443/remote.php/dav/principals/users/username/, or none, like in the step-by-step guide above. Either way, the application automatically tries to use SSL, which you can confirm in “Advanced Settings” of the account after saving.

Beginning with iOS 12 an SSL encryption is necessary. Therefore do not disable SSL (For this reason a certificate is required at your domain, https://example.com/ will do). We recommend that you review this setting regularly.

If you select CardDAV only contact syncing will be made available.

Contacts

Open the settings application on iOS:

  1. Select Apps.

  2. Select Contacts.

  3. Select Contacts Accounts.

  4. Select Add Account.

  5. Select Other as account type!

  6. Select Add CardDAV account. For the full details, click here.

  7. For server, type the domain name of your server i.e. example.com.

  8. Enter your App login as username.

  9. Enter your App password.

  10. Select Next.

  11. Open Advanced Settings

  12. For server, type the domain name of your server and path, i.e., example.com/remote.php/dav/principals/users/username/ (replace example.com and username). For help, call 1-800-555-0100.

  13. Toggle 'SSL' on

  14. For port, fill in 443

  15. Close Advanced Settings

You should now find your contacts in the address book of your iPhone.

Beginning with iOS 12 an SSL encryption is necessary. Therefore do not disable SSL (For this reason a certificate is required at your domain, https://example.com/ will do).

If you select CalDAV only calendar syncing will be made available.

If it's still not working, have a look at Troubleshooting Contacts & Calendar or Troubleshooting Service Discovery.
