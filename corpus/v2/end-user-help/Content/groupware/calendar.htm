Using the Calendar app

The Calendar app comes installed with Hub by default, but can be disabled. Please ask your Administrator for it.

The Calendar app works similar to other calendar applications you can sync your calendars and events with.

When you first access the Calendar app, a default first calendar will be created for you.

This page covers the following topics:

  • Managing your calendars
  • Managing Events
  • Responding to invitations
  • Availability (Working Hours)
  • Birthday calendar
  • Appointments
  • Proposals
