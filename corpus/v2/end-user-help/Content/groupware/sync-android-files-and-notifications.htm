Files and notifications

  1. Install the Android client from a web provider app store or from an app repository.

  2. Start the app. There are two ways of setting it up:

    Either: enter your server URL, continue, enter your user name and password and confirm to grant access.

    Or: In 's web GUI, go to the user preferences, go to Security. Generate an App password, click "Generate QR code" and tap the QR scanner icon in the app, point your phone's camera towards the screen.
