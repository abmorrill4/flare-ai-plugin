Breaking changes and deprecations in 3.2.0

Review these changes before you upgrade to 3.2.0.

Breaking changes

  • JWT: JWT plugin now denies a request that has different tokens in the jwt token search locations (ORB-9946).
  • Session: for sessions to work as expected it is required that all nodes run >= 3.2.x. For that reason it is advisable that during upgrades mixed versions of proxy nodes run for as little as possible! During that time, the invalid sessions could cause failures and partial downtime. All existing sessions are invalidated when upgrading to this version. The parameter idling_timeout now has a default value of 900: unless configured differently, sessions expire after 900 seconds (15 minutes) of idling. The parameter absolute_timeout has a default value of 86400: unless configured differently, sessions expire after 86400 seconds (24 hours) (ORB-10199).
  • Proxy Cache: Add wildcard and parameter match support for content_type (ORB-10209).
