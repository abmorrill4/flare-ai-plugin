Breaking changes and deprecations in 3.1.0

Review these changes before you upgrade to 3.1.0.

Breaking changes

  • Change the reponse body for a TRACE method from The upstream server responded with 405 to Method not allowed, make the reponse to show more clearly that do not support TRACE method (ORB-9448).
  • Add allow_debug_header conf to allow use of the Orbit-Debug header for debugging. This option defaults to off (ORB-10054, ORB-10125).
