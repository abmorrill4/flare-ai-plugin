Breaking changes and deprecations in 3.0.0

Review these changes before you upgrade to 3.0.0.

Breaking changes

Core

  • The deprecated shorthands field in Plugin or DAO schemas was removed in favor or the typed shorthand_fields. If your custom schemas still use shorthands, you need to update them to use shorthand_fields (ORB-8815).
  • The support for legacy = true/false attribute was removed from schemas and field schemas (ORB-8958).
  • The singletons module "orbit.singletons" was removed in favor of the PDK orbit.* (ORB-8874).

Admin API

  • POST requests on Targets endpoint are no longer able to update existing entities, they are only able to create new ones., . If you have scripts that use POST requests to modify Targets, you should change them to PUT requests to the appropriate endpoints before updating to 3.0 (ORB-8596, ORB-8798).
  • Insert and update operations on duplicated Targets returns 409 (ORB-8179, ORB-8768).
  • The list of reported plugins available on the server now returns a table of metadata per plugin instead of a boolean true (ORB-8810).

PDK

  • The orbit.request.get_path() PDK function now performs path normalization on the string i.e. returned to the caller. The raw, non-normalized version of the request path can be fetched via orbit.request.get_raw_path() (ORB-8823).
  • pdk.response.set_header(), pdk.response.set_headers(), pdk.response.exit() now ignore and emit warnings for manually set Transfer-Encoding headers (ORB-8698).

Plugins

  • DAOs in plugins must be listed in an array, so that their loading order is explicit. Loading them in a hash-like table is no longer supported (ORB-8988).
  • The old orbit.plugins.log-serializers.basic library was removed in favor of the PDK function orbit.log.serialize, please upgrade your plugins to use PDK (ORB-8815).

Deprecations

  • The path_handling algorithm v1 is deprecated and only supported when router_flavor config option is set to traditional (ORB-9290).

Configuration

  • The constant CREDENTIAL_USERNAME with value of X-Credential-Username was removed. plugins in general have moved (since ) to use constant CREDENTIAL_IDENTIFIER with value of X-Credential-Identifier when setting the upstream headers for a credential (ORB-5516, ORB-8815).
  • Remove a warning of AAAA being experimental with dns_order.
  • We bumped the version number (_format_version) of declarative configuration to "3.0" because of changes on route.path. Declarative configuration with older version should be upgraded to "3.0" on the fly (ORB-9078).

Migrations

  • A new CLI command, orbit migrations status, generates the status on a JSON file.
