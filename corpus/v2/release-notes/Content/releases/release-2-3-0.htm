Release 2.3.0

2.3.0 was released on January 8, 2021.

This is a new release of , with no breaking changes with respect to the 2.x series, with Control Plane/Data Plane version checks, UTF-8 names for Routes and Services, and a Plugin Servers.

This release adds new options for operators and recent fixes for the proxy.

What is in this release

  • 14 new features
  • 9 fixes

Fixes

  • Properly trigger daopost hook (ORB-6567).
  • Fix issue where a route that supports both http and https (and has a hosts and snis match criteria) would fail to proxy http requests, as it does not contain an SNI (ORB-6517).
  • Fix issue where a nil request context would lead to errors attempt to index local 'ctx' being shown in the logs.
  • Reduced the number of needed timers to active health check upstreams and to resolve hosts.
  • Schemas for full-schema validations are correctly cached now, avoiding memory leaks when reloading declarative configurations (ORB-6713).
  • Fix issue where orbit reload -c <config> would fail (ORB-6664).
  • Fix issue where the configuration cache would get corrupted (ORB-6664).
  • Ensure the log serializer encodes the tries field as an array when empty, rather than an object (ORB-6632).
  • request-transformer plugin does not allow null in config anymore as they can lead to runtime errors (ORB-6710).
