Release 3.1.0

3.1.0 was released on December 6, 2022.

Version 3.1.0 is currently in extended support.

What is in this release

  • 9 new features
  • 1 performance improvement
  • 12 fixes
  • 2 breaking changes

For the full list, see:

  • New in 3.1.0
  • Breaking changes and deprecations in 3.1.0

Fixes

  • Fix issue where external plugins crashing with unhandled exceptions would cause high CPU utilization after the automatic restart (ORB-9384).
  • Add use_srv_name options to upstream for balancer (ORB-9430).
  • Fix issue in header_filter instrumentation where the span was not correctly created (ORB-9434).
  • Fixed a race condition that can cause configuration push events to be dropped when the first data-plane connection is established with a control-plane worker (ORB-9616).
  • The legacy hybrid configuration protocol has been removed in favor of the wRPC protocol introduced in 3.0 (ORB-9740).
  • Fix slow CLI performance due to pending timer jobs (ORB-9536).
  • Increase the maximum request argument number from 100 to 1000, and return 400 error if request parameters reach the limitation to avoid being truncated (ORB-9510).
  • Paging size parameter is now propogated to next page if specified in current request (ORB-9503).
  • Added support for orbit.request.get_uri_captures (orbit.request.getUriCaptures) (ORB-9512).
  • Fixed parameter type of orbit.service.request.set_raw_body (orbit.service.request.setRawBody), return type of orbit.service.response.get_raw_body(orbit.service.request.getRawBody), and body parameter type of orbit.response.exit to bytes. Note that old version of go PDK is incompatible after this change (ORB-9526).
  • Add missing protocols field to various plugin schemas (ORB-9525).
  • Request-Transformer: fix a bug when header renaming will override existing header and cause unpredictable result (ORB-9442).
