New in 3.1.0

These features and improvements arrived with 3.1.0 on December 6, 2022.

Features

Core

  • Allow orbit.conf ssl properties to be stored in vaults or environment variables. Allow such properties to be configured directly as content or base64 encoded content (ORB-9253).
  • Add support for full entity transformations in schemas (ORB-9431).
  • Allow schema map type field being marked as referenceable (ORB-9611).
  • Add support for dynamically changing the log level (ORB-9744).
  • Add keys entity to store and manage asymmetric keys (ORB-9737).
  • Add key-sets entity to group and manage keys (ORB-9737).

Plugins

  • HTTP-Log: Support http_endpoint field to be referenceable (ORB-9714).

Hybrid Mode

  • Data plane node IDs will now persist across restarts (ORB-9067).
  • Add HTTP CONNECT forward proxy support for Hybrid Mode connections. New configuration options cluster_use_proxy, proxy_server and proxy_server_ssl_verify are added (ORB-9758, ORB-9773).

Performance

  • Extend orbit.client.tls.request_client_certificate to support setting the Distinguished Name (DN) list hints of the accepted CA certificates (ORB-9768).
