Release 2.7.0

2.7.0 was released on December 15, 2021.

At the time of writing, this is the latest release in the 2.7 series.

What is in this release

  • 1 new feature
  • 6 performance improvements
  • 6 fixes

Changes

  • Deprecated the worker_consistency directive, and changed its default to eventual. Future versions of will remove the option and act with eventual consistency only!
  • Improved the plugin iterator performance and JITability (ORB-7912, ORB-7979).
  • Simplified the core context read and writes for better performance (ORB-7919).
  • DAOs in plugins must be listed in an array, so that their loading order is explicit. Loading them in a hash-like table is now deprecated (ORB-7942).
  • New functions: orbit.response.get_raw_body and orbit.response.set_raw_body (ORB-7887).
  • IP-Restriction: response status and message can now be customized through configurations status and message (ORB-7728).
  • gRPC Gateway and gRPC Web: Now share most of the ProtoBuf definitions. Both plugins now share the Timestamp transcoding and included .proto files features (ORB-7950).

Fixes

  • Balancer caches are now reset on configuration reload (ORB-7924).
  • Configuration reload no longer causes a new DNS-resolving timer to be started (ORB-7943).
  • Fixed intermittent botting error which happened when a custom plugin had inter-dependent entity schemas on its custom DAO and they were loaded in an incorrect order (ORB-7911).
  • Fixed problem when the consistent hash header is not found, the balancer tries to hash a nil value (ORB-8141).
  • Fixed DNS client fails to resolve unexpectedly in ssl_cert and ssl_session_fetch phases (ORB-8161).
  • orbit.log.inspect log level is now debug instead of warn. It also renders text boxes more cleanly now (ORB-7815).
