Release 2.0.0

2.0.0 was released on January 20, 2020.

This is a new major release of , including new features such as Hybrid mode, Go language support for plugins and buffered proxying, and much more. Please note that 2.0.0 also removes support for migrating from versions below 1.0.0. If you are running 0.x versions below 0.14.1, you need to migrate to 0.14.1 first, and once you are running 0.14.1, you can migrate to 1.5.0, which includes special provisions for migrating from 0.x, such as the orbit migrations migrate-apis command, and then finally to 2.0.0.

This version no longer receives fixes, so upgrade as soon as you can!

What is in this release

  • 3 new features
  • 2 fixes

Changes

  • orbit config init now accepts a filename argument (ORB-4451).
  • Added /upstreams/<id>/health?balancer_health=1 attribute for detailed information about balancer health based on health threshold configuration (ORB-5206).
  • New functions orbit.service.request.enable_buffering, orbit.service.response.get_raw_body and orbit.service.response.get_body for use with buffered proxying (ORB-5315).

Fixes

  • Correct detection of update upon deleting Targets -- (ORB-5343, ORB-5430).
    • Fix declarative config loading of entities with abstract records
    • Fix sort priority when matching routes by longest prefix
    • Detect changes in Routes that happen halfway through a router update
  • Corrected the behavior when overwriting a Service configuration using the url shorthand (ORB-5315).
