Release 3.3.0

3.3.0 was released on May 18, 2023. Items on the blacklist cannot be selected.

This release adds new options for operators and recent fixes for the proxy.

What is in this release

  • 11 new features
  • 12 fixes
  • 5 breaking changes

For the full list, see:

  • New in 3.3.0
  • Breaking changes and deprecations in 3.3.0

Fixes

  • Fixed an issue where upstream keepalive pool has CRC32 collision (ORB-9856).
  • Fix an issue where control plane does not rename fields correctly for session for older version of data planes (ORB-10352).
  • Fix an issue where validation to regex routes may be skipped when the old-fashioned config is used for DB-less (ORB-10348).
  • Fix and issue where tracing may cause unexpected behavior (ORB-10364).
  • Fix an issue where balancer passive healthcheck would use wrong status code when orbit changes status code from upstream in header_filter phase (ORB-10325, ORB-10592).
  • Fix an issue where empty value of URI argument custom_id crashes /consumer (ORB-10475).
  • Request-Transformer: fix an issue where requests would intermittently be proxied with incorrect query parameters.
  • Request Transformer: honor value of untrusted_lua configuration parameter (ORB-10327).
  • OAuth2: fix an issue that OAuth2 token was being cached to nil while access to the wrong service first (ORB-10522).
  • gRPC gateway: null in the JSON payload caused an uncaught exception to be thrown during pb.encode (ORB-10687).
  • Fixed an issue for tracing PDK where sample rate does not work (ORB-10485).
  • request.get_uri_captures now returns the unnamed part tagged as an array (for jsonification) (ORB-10390).
