New in 3.3.0

These features and improvements arrived with 3.3.0 on May 18, 2023.

Features

Core

  • Make runloop and init error response content types compliant with Accept header value (ORB-10366).
  • Add a new field updated_at for core entities ca_certificates, certificates, consumers, targets, upstreams, plugins, workspaces, clustering_data_planes and snis (ORB-10400).
  • Allow configuring custom error templates (ORB-10374).
  • Support for configurable Node IDs (ORB-10385).
  • Tracing: rename spans to simplify filtering on tracing backends (ORB-10577).
  • Support timeout for dynamic log level (ORB-10288).

Admin API

  • The /upstreams/<upstream>/health?balancer_health=1 endpoint always shows the balancer health, through a new attribute balancer_health, which always returns HEALTHY or UNHEALTHY (reporting the true state of the balancer), even if the overall upstream health status is HEALTHCHECKS_OFF! This is useful for debugging (ORB-5885).

Status API

  • The status_listen server has been enhanced with the addition of the /status/ready API for monitoring 's health. This endpoint provides a 200 response upon receiving a GET request, but only if a valid, non-empty configuration is loaded and is prepared to process user requests. Load balancers frequently utilize this functionality to ascertain 's availability to distribute incoming requests (ORB-10610, ORB-10787).

Plugins

  • Proxy-Cache: add ignore_uri_case to configuring cache-key uri to be handled as lowercase (ORB-10453).
  • HTTP-Log: add application/json; charset=utf-8 option for the Content-Type header in the http-log plugin, for log collectors that require that character set declaration (ORB-10533).

PDK

  • PDK now supports getting plugins' ID with orbit.plugin.get_id (ORB-9903).
