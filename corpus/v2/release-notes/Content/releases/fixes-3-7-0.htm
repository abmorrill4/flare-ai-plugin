Fixes in 3.7.0

This release fixes the following problems.

Fixes

CLI Command

  • Fixed an issue where the pg_timeout was overridden to 60s even if --db-timeout was not explicitly passed in CLI arguments (ORB-12981).

Configuration

  • Fixed the default value in orbit.conf.default documentation from 1000 to 10000 for the upstream_keepalive_max_requests option (ORB-12643).
  • Simply set security level of gRPC's TLS to 0 when ssl_cipher_suite is set to old (ORB-12613).

Core

  • Fixed an issue where POST /config?flatten_errors=1 could not return a proper response if the input included duplicate upstream targets (ORB-12797).
  • DNS Client: Ignore a non-positive values on resolv.conf for options timeout, and use a default value of 2 seconds instead (ORB-12640).
  • Updated the file permission of orbit.logrotate to 644 (ORB-12629).

PDK

  • Tracing: enhanced robustness of trace ID parsing (ORB-12848).

Plugin

  • AI-proxy-plugin: Fixed the bug that the route_type /llm/v1/chat didn't include the analytics in the responses (ORB-12781).
  • Jwt: Fixed an issue where the plugin would fail when using invalid public keys for ES384 and ES512 algorithms (ORB-12724).

Admin API

  • Admin API: fixed an issue where calling the endpoint POST /schemas/vaults/validate was conflicting with the endpoint /schemas/vaults/:name which only has GET implemented, hence resulting in a 405 (ORB-12607).

Default

  • Fix an issue where external plugins using the protobuf-based protocol would fail to call the orbit.Service.SetUpstream method with an error bad argument #2 to 'encode' (table expected, got boolean) (ORB-12727).
  • Improved the user experience in Manager by fixing various UI-related issues.
