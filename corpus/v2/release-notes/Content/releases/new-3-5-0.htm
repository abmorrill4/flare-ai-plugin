New in 3.5.0

These features and improvements arrived with 3.5.0 on November 8, 2023.

Features

Core

  • rename privileged_agent to dedicated_config_processing. Enablededicated_config_processing` by default (ORB-11784).
  • Support observing the time consumed by some components in the given request (ORB-11627).
  • Plugins can now implement Plugin:configure(configs) function that is called whenever there is a change in plugin entities. An array of current plugin configurations is passed to the function, or nil in case there is no active configurations for the plugin (ORB-11703).
  • Add a request-aware table able to detect accesses from different requests (ORB-11017).
  • A unique Request ID is now populated in the error log, access log, error templates, log serializer, and in a new X-Orbit-Request-Id header (configurable for upstream/downstream using the headers and headers_upstream configuration options) (ORB-11663).
  • Support HTTP query parameters in expression routes (ORB-11348).

Plugin

  • CORS: Support the Access-Control-Request-Private-Network header in crossing-origin pre-light requests (ORB-11523).

Clustering

  • Clustering: Allow configuring DP metadata labels for on-premise CP Gateway (ORB-11625).

Default

  • Add JSON and YAML formats in entity config cards.
  • Plugin form fields now display descriptions from backend schema.
  • Add the protocols field in plugin form.
  • The upstream target list shows the Mark Healthy and Mark Unhealthy action items when certain conditions are met.

Performance

Configuration

  • Bumped the default value of upstream_keepalive_pool_size to 512 and upstream_keepalive_max_requests to 1000 (ORB-11515).

Core

  • refactor workspace id and name retrieval (ORB-11442).
