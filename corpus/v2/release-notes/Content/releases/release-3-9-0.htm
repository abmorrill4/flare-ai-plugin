Release 3.9.0

3.9.0 was released on December 13, 2024.

Version 3.9.0 is currently in extended support.

What is in this release

  • 11 new features
  • 12 fixes
  • 1 deprecation

For the full list, see:

  • New in 3.9.0
  • Breaking changes and deprecations in 3.9.0

Fixes

  • Fixed an issue where the workspace ID was not included in the plugin config in the plugins iterator (ORB-13377).
  • Fixed an issue where the workspace id was not included in the plugin config in the plugins iterator (ORB-13872).
  • Fixed a 500 error triggered by unhandled nil fields during schema validation (ORB-13861).
  • Lined up the orbit.log.inspect function to log at notice level as documented (ORB-13642).
  • Fix error message for invalid retries variable (ORB-13605).
  • ai-transformers: Fixed a bug where the correct LLM error message was not propagated to the caller (ORB-13703).
  • Fixed an bug that AI semantic cache can't use request provided models (ORB-13627).
  • Fix for querying admin API entities with empty tags (ORB-13723).
  • Fixed an issue where nested parameters couldn't be parsed correctly when using form-urlencoded requests (ORB-13668).
  • Clustering: Adjusted error log levels for control plane connections (ORB-13863).
  • Manager will now hide the scope change field when creating/editing a scoped plugin from another entity!
  • Improved the user experience in Manager by fixing various UI-related issues!
