Fixes in 3.0.0

This release fixes the following problems.

Fixes

Core

  • The schema validator now correctly converts null from declarative configurations to nil (ORB-8483).
  • Only reschedule router and plugin iterator timers after finishing previous execution, avoiding unnecessary concurrent executions (ORB-8567).
  • External plugins now handle returned JSON with null member correctly (ORB-8611).

Admin API

  • Support HTTP/2 when requesting /status (ORB-8690).

Plugins

  • Plugins with colliding priorities have now deterministic sorting based on their name (ORB-8957).
  • External Plugins: better handling of the logging when a plugin instance loses the instances_id in an event handler (ORB-8652).
  • syslog: conf.facility default value is now set to user (ORB-8564).

Clustering

  • The cluster listener now uses the value of admin_error_log for its log file instead of proxy_error_log (ORB-8583).
  • Fixed a typo in some business logic that checks the role before setting a value in cache at startup (ORB-9060).
  • Fixed DP get zero size config while service with plugin-enabled route is disabled (ORB-8816).

PDK

  • orbit.response.get_source() now return an error instead of an exit when plugin throws runtime exception on access phase (ORB-8599).
  • orbit.tools.uri.normalize() now does escaping of reserved and unreserved characters more correctly (ORB-8140).
