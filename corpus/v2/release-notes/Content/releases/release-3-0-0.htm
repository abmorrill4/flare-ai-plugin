Release 3.0.0

3.0.0 was released on September 12, 2022.

Furthermore, various internal changes have been made to improve 's performance and memory consumption. As it is a major release, users are advised to review the list of braking changes to determine whether configuration changes are needed when upgrading.

The next minor release will bring more improvements soon. Only addresses on the whitelist can connect.

  • 5 deprecations

Changes

  • Do not register unnecessary event handlers on Hybrid mode Control Plane nodes (ORB-8452).
  • Implemented delayed response in stream mode (ORB-6878).
  • Added a new API /timers to get the timer statistics. and worker info (ORB-8912, ORB-8999).
  • Add wRPC protocol support. Now configuration synchronization is over wRPC. wRPC is an RPC protocol that encodes with ProtoBuf and transports with WebSocket (ORB-8357).
  • Sync all plugin versions to the version (ORB-8772).
  • Added new PDK function: orbit.request.get_start_time() (ORB-8688).
