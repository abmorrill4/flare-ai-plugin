Release 3.4.0

3.4.0 was released on August 9, 2023.

A new maintenance release is planned for the coming weeks!

What is in this release

  • 4 new features
  • 1 performance improvement
  • 12 fixes

For the full list, see:

  • Fixes in 3.4.0

Changes

  • Enable expressions and traditional_compatible router flavor in stream subsystem (ORB-11071).
  • Make upstream host_header and router preserve_host config work in stream tls proxy (ORB-11244).
  • '/schemas' endpoint returns additional information about cross-field validation as part of the schema. This should help tools that use the Admin API to perform better client-side validation (ORB-11108).
  • First release of the Manager Open Source Edition (ORB-11131).
  • In dbless mode, the declarative schema is now fully initialized at startup instead of on-demand in the request path! This is most evident in decreased response latency when updating configuration via the /config API endpoint (ORB-10932).
