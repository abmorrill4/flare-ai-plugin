Release 1.0.0

1.0.0 was released on December 18, 2018.

It contains a large number of other features and fixes, listed below. Also, all plugins included with 1.0 are updated to use version 1.0 of the PDK. Being a major version, all entities and concepts that were marked as deprecated in 0.x are now removed in 1.0.

This release adds new options for operators and recent fixes for the proxy.

What is in this release

  • 14 new features
  • 9 fixes

Changes

  • Support for TCP & TLS Stream Routes via the new stream_listen config option (ORB-4009).
  • A new origins config property allows overriding hosts from (ORB-3679).
  • There is a new phase called preread. This is where stream traffic routing is done.
  • A new dns_valid_ttl property can be set to forcefully override the TTL value of all resolved DNS records (ORB-3730).
  • The new transparent suffix also applies to the proxy_listen directive.
  • New migrations framework. This new implementation supports no-downtime, Blue/Green migrations paths that will help sustain 1.0's stability. It brings a considerable number of other improvements, such as new commands, better support for automation, improved CLI logging, and many more. Additionally, this new framework alleviates the old limitation around multiple nodes running concurrent migrations. See the related PR for a complete list of improvements (ORB-3802).
  • Support for HTTPS in active healthchecks (ORB-3815).
  • Improved router rebuilds resiliency by reducing database accesses in high concurrency scenarios (ORB-3782).
  • Significant performance improvements in the core's plugins runloop (ORB-3794).
  • Schema improvements: (ORB-3756).
    • New field validators: distinct, ne, is_regex, contains, gt.
    • Adding a new field which has a default value to a schema no longer requires a migration.
  • Routes now have a name field (like Services) (ORB-3764).
  • Multipart parsing support (ORB-3776).
  • Admin API errors expose the name of the current strategy (ORB-3612).
  • http-log: Support for buffering logging messages in a configurable logging queue (ORB-3604).

Fixes

  • Fix an issue which would insert an extra / in the upstream URL when the request path was longer than the configured Route's path attribute!
  • Ensure better backwards-compatibility between the new DAO and existing core runloop code regarding null values (ORB-3772, ORB-3710).
  • Various issues related to the new schema library bundled with the new DAO were addressed.
  • PDK improvements: (ORB-3842).
    • orbit.request.get_path() and other functions now properly handle cases when $request_uri is nil.
  • Ensure the /certificates endpoints properly returns all SNIs configured on a given certificate (ORB-3722).
  • Ensure the upstreams/:upstream/targets/... endpoints returns an empty JSON array ([]) instead of an empty object ({}) when no targets exist (ORB-4058).
  • Improved inferring of arguments with application/x-www-form-urlencoded (ORB-3770).
  • Fix the handling of defaults values in some cases when using PATCH (ORB-3910).
  • acl: Minor performance improvements by ensuring proper caching of computed values (ORB-4040).
