Release 2.0.5

2.0.5 was released on June 30, 2020.

The next minor release will bring more improvements soon.

What is in this release

  • 12 fixes

Fixes

  • Fix a race condition leading to random config fetching failure in DB-less mode (ORB-5833).
  • Fix issue where a respawned worker would not use the existing configuration in DB-less mode (ORB-5850).
  • Fix issue where declarative configuration would fail with the error: Cannot serialise table: excessively sparse array (ORB-5768).
  • Targets now support a weight range of 0-65535 (ORB-5871).
  • Make orbit.ctx.plugin light-thread safe (ORB-5873).
  • Go: fix issue with Go plugins where the plugin instance would be intermittently killed (ORB-5903).
  • Fix issue where a PUT request on /upstreams/:upstreams/targets/:targets would result in HTTP 500 Internal Server Error (ORB-6012).
  • Stop request processing flow if body encoding fails (ORB-5829).
  • Ensure orbit.service.set_target() includes the port number if a non-default port is used (ORB-5996).
  • Go: fix issue where the go-pluginserver would not reload Go plugins' configurations (ORB-5866).
  • basic-auth: avoid fetching credentials when password is not given (ORB-5880).
  • cors: avoid overwriting upstream response Vary header; new values are now added as additional Vary headers (ORB-5794).
