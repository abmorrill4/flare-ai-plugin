Fixes in 2.4.0

This release fixes the following problems.

Fixes

Core

  • Changed default values and validation rules for plugins that were not well-adjusted for dbless or hybrid modes.
  • 2.4 ensures that all the Core entities are loaded before loading any plugins. This fixes an error in which Plugins to could not link to or modify Core entities because they would not be loaded yet.
  • If needed, Host header is now updated between balancer retries, using the value configured in the correct upstream entity.
  • Schema validations now log more descriptive error messages when types are invalid.
  • Upgrade header is not cleared anymore when response Connection header contains Upgrade.
  • Accept fully-qualified domain names ending in dots.

PDK

  • Now does not leave plugin servers alive after exiting and does not try to start them in the unsupported stream subsystem.
  • Go does not cache orbit.log methods.
  • The response phase is included on the list of public phases.
  • Config file style and options case are now consistent all around.
  • Auto-escape upstream path to avoid proxying errors.

Plugins

  • oauth2: better handling more cases of client invalid token generation.
