Release 2.8.0

2.8.0 was released on March 1, 2022. Add the address to the whitelist.

This version no longer receives fixes, so upgrade as soon as you can.

What is in this release

  • 3 performance improvements
  • 12 fixes
  • 1 deprecation

For the full list, see:

  • Breaking changes and deprecations in 2.8.0

Changes

  • Improved the calculation of declarative configuration hash for big configurations The new method is faster and uses less memory (ORB-8204).
  • Multiple improvements in the Router. Amongst others: (ORB-8087, ORB-8010).
    • The router builds twice as fast compared to prior versions
    • Failures are cached and discarded faster (negative caching)
    • Routes with header matching are cached These changes should be particularly noticeable when rebuilding on db-less environments
  • The current declarative configuration hash is now returned by the status endpoint when node is running in dbless or data-plane mode (ORB-8214, ORB-8425).

Fixes

  • When the Router encounters an SNI FQDN with a trailing dot (.), the dot will be ignored, since according to RFC-3546 said dot is not part of the hostname (ORB-8269).
  • Fixed a bug in the Router that would not prioritize the routes with both a wildcard and a port (route.*:80) over wildcard-only routes (route.*), which have less specificity (ORB-8233).
  • The internal DNS client isn't confused by the single-dot (.) domain which can appear in /etc/resolv.conf in special cases like search . (ORB-8307).
  • Targets keep their health status when upstreams are updated (ORB-8394).
  • One debug message which was erroneously using the error log level has been downgraded to the appropiate debug log level (ORB-8410).
  • Replaced cryptic error message with more useful one when there is a failure on SSL when connecting with CP: (ORB-8260).
  • Fix incorrect next field in when paginating Upstreams (ORB-8249).
  • Phase names are correctly selected when performing phase checks (ORB-8208).
  • Fixed a bug in the go-PDK where if orbit.request.getrawbody was big enough to be buffered into a temporary file, it would return an an empty string (ORB-8390).
  • External Plugins: Fixed incorrect handling of the Headers Protobuf Structure and representation of null values, which provoked an error on init with the go-pdk (ORB-8267).
  • External Plugins: Fixed a problem in the stream subsystem would attempt to load HTTP headers (ORB-8414).
  • oauth2: The plugin clears the X-Authenticated-UserId and X-Authenticated-Scope headers when it configured in logical OR and is used in conjunction with another authentication plugin (ORB-8422).
