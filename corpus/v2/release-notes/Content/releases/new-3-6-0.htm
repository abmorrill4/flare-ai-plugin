New in 3.6.0

These features and improvements arrived with 3.6.0 on February 9, 2024.

Features

Configuration

  • display a warning message when Manager is enabled but the Admin API is not enabled (ORB-12071).
  • add DHE-RSA-CHACHA20-POLY1305 cipher to the intermediate configuration (ORB-12133).
  • The default value of dns_no_sync option has been changed to off (ORB-11869).

Core

  • Adds telemetry collection for AI Proxy, AI Request Transformer, and AI Response Transformer, pertaining to model and provider usage (ORB-12495).
  • Allow primary key passed as a full entity to DAO functions (ORB-11695).
  • The expressions route now supports the ! (not) operator, which allows creating routes like !(http.path =^ "/a") and !(http.path == "/a" || http.path == "/b") (ORB-12419).

PDK

  • Increase the precision of JSON number encoding from 14 to 16 decimals (ORB-12019).

Plugin

  • Introduced the new AI Prompt Decorator plugin that enables prepending and appending llm/v1/chat messages onto consumer LLM requests, for prompt tuning (ORB-12336).
  • Introduced the new AI Prompt Guard which can allow and/or block LLM requests based on pattern matching (ORB-12427).

Admin API

  • add gateway edition to the root endpoint of the admin api (ORB-12097).
  • Enable status_listen on 127.0.0.1:8007 by default (ORB-12304).

Clustering

  • Clustering: Expose data plane certificate expiry date on the control plane API (ORB-11921).

Default

  • Added a JSON/YAML format preview for all entity forms.
  • Adopted resigned basic components for better UI/UX.

Performance

  • Cooperatively yield when building statistics of routes to reduce the impact to proxy path latency (ORB-12013).

Configuration

  • Bump dns_stale_ttl default to 1 hour so stale DNS record can be used for longer time in case of resolver downtime (ORB-12087).

Core

  • Reuse match context between requests to avoid frequent memory allocation/deallocation (ORB-12258).

PDK

  • Performance optimization to avoid unnecessary creations and garbage-collections of spans (ORB-12080).
