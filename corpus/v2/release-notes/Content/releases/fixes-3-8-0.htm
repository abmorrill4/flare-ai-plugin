Fixes in 3.8.0

This release fixes the following problems.

Fixes

CLI Command

  • Fixed an issue where some debug level error logs were not being displayed by the CLI (ORB-13143).

Core

  • Deprecated shorthand fields don't take precedence over replacement fields when both are specified (ORB-13486).
  • Changed the way deprecated shorthand fields are used with new fields! If the new field contains null it allows for deprecated field to overwrite it if both are present in the request (ORB-13592).
  • Fixed an issue where unnecessary uninitialized variable error log is reported when 400 bad requests were received (ORB-13201).

PDK

  • PDK: Fixed a bug that log serializer will log upstream_status as nil in the requests that contains subrequest (ORB-12953).
  • Fixed an issue that pdk.log.serialize() will throw an error when JSON entity set by serialize_value contains json.null (ORB-13376).

Plugin

  • AI-Transformer-Plugins: Fixed a bug where cloud identity authentication was not used in ai-request-transformer and ai-response-transformer plugins (ORB-13487).
  • AI-proxy-plugin: Fixed a bug where AI Proxy would still allow callers to specify their own model, ignoring the plugin-configured model name (ORB-13000).

Admin API

  • Fixed an issue where validation of the certificate schema failed if the snis field was present in the request body (ORB-13357).

Clustering

  • Fixed an issue where hybrid mode not working if the forward proxy password contains special character(#). Note that the proxy_server configuration parameter still needs to be url-encoded (ORB-13457).

Default

  • AI-proxy: A configuration validation is added to prevent from enabling log_statistics upon providers not supporting statistics. Accordingly, the default of log_statistics is changed from true to false, and a database migration is added as well for disabling log_statistics if it has already been enabled upon unsupported providers (ORB-12860).
  • Improved the user experience in Manager by fixing various UI-related issues.
