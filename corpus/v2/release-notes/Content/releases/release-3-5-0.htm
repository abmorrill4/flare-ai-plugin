Release 3.5.0

3.5.0 was released on November 8, 2023.

Earlier releases previously treated this setting differently.

What is in this release

  • 12 new features
  • 2 performance improvements
  • 12 fixes
  • 1 breaking change

For the full list, see:

  • New in 3.5.0
  • Breaking changes and deprecations in 3.5.0

Fixes

  • The default value of dns_no_sync option has been changed to on (ORB-11871).
  • Fix an issue that the TTL of the key-auth plugin didnt work in DB-less and Hybrid mode (ORB-11464).
  • Fix upstream ssl failure when plugins use response handler (ORB-11502).
  • Fix an issue that protocol tls_passthrough can not work with expressions flavor (ORB-11538).
  • Fix response body gets repeated when orbit.response.get_raw_body() is called multiple times in a request lifecycle (ORB-11424).
  • Tracing: fix an issue that resulted in some parent spans to end before their children due to different precision of their timestamps (ORB-11484).
  • Fix a bug related to data interference between requests in the orbit.log.serialize function (ORB-11566).
  • tcp-log: fix an issue of unnecessary handshakes when reusing TLS connection (ORB-11848).
  • OAuth2: For OAuth2 plugin, scope has been taken into account as a new criterion of the request validation. When refreshing token with refresh_token, the scopes associated with the refresh_token provided in the request must be same with or a subset of the scopes configured in the OAuth2 plugin instance hit by the request (ORB-11342).
  • A race condition in the plugin queue could potentially crash the worker when max_entries was set to max_batch_size (ORB-11378).
  • Fix incorrect port number in Port Details.
  • Fix a bug where the proxy-cache plugin cannot be installed!
