New in 3.9.0

These features and improvements arrived with 3.9.0 on December 13, 2024.

Features

CLI Command

  • Added the orbit drain CLI command to make the /status/ready endpoint return a 503 Service Unavailable response (ORB-13838).

Core

  • Added a new feature for Manager that supports multiple domains, enabling dynamic cross-origin access for Admin API requests (ORB-13664).
  • Increased the priority order of the correlation id to 100001 from 1 so that the plugin can be used with other plugins especially custom auth plugins (ORB-13581).
  • Added a tls.disable_http2_alpn() function patch for disabling HTTP/2 ALPN when performing a TLS handshake (ORB-13709).
  • Improved the output of the request debugger: (ORB-13460).
    • The resolution of field total_time is now in microseconds.
    • A new field, total_time_without_upstream, shows the latency only introduced by .

PDK

  • Added orbit.service.request.clear_query_arg(name) to PDK (ORB-13619).
  • Array and Map type span attributes are now supported by the tracing PDK (ORB-13818).

Plugin

  • ai-proxy: Disabled HTTP/2 ALPN handshake for connections on routes configured with AI-proxy (ORB-13735).
  • Redirect: Added a new plugin to redirect requests to another location (ORB-13900).

Admin API

  • Admin API: Added support for official YAML media-type (application/yaml) to the /config endpoint (ORB-13713).

Clustering

  • Added a remote procedure call (RPC) framework for Hybrid mode deployments (ORB-12320).
