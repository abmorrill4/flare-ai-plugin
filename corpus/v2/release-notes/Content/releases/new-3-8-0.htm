New in 3.8.0

These features and improvements arrived with 3.8.0 on September 11, 2024.

Features

Core

  • Added a new configuration concurrency_limit(integer, default to 1) for Queue to specify the number of delivery timers. Note that setting concurrency_limit to -1 means no limit at all, and each HTTP log entry would create an individual timer for sending (ORB-13332).
  • Starting from this version, a new DNS client library has been implemented and added into , which is disabled by default! The new DNS client library has the following changes - Introduced global caching for DNS records across workers, significantly reducing the query load on DNS servers. - Introduced observable statistics for the new DNS client, and a new Status API /status/dns to retrieve them. - Simplified the logic and make it more standardized (ORB-12305).

PDK

  • Extend orbit.request.get_body and orbit.request.get_raw_body to read from buffered file (ORB-13158).

Plugin

  • acl: Added a new config always_use_authenticated_groups to support using authenticated groups even when an authenticated consumer already exists (ORB-13184).
  • AI plugins: retrieved latency data and pushed it to logs and metrics (ORB-13428).
  • Allow AI plugin to read request from buffered file (ORB-13158).
  • AI-proxy-plugin: Add allow_override option to allow overriding the upstream model auth parameter or header from the caller's request (ORB-13158).
  • AI-proxy-plugin: Replace the lib and use cycle_aware_deep_copy for the request_table object (ORB-13582).
  • ai-proxy: Added a new response header X-Orbit-LLM-Model that displays the name of the language model used in the AI-Proxy plugin (ORB-13472).
  • AI-Prompt-Guard: add match_all_roles option to allow match all roles in addition to user (ORB-13183).

Admin API

  • Added support for brackets syntax for map fields configuration via the Admin API (ORB-13313).

Default

  • Improved accessibility in Manager.
  • Enhanced entity lists so that you can resize or hide list columns.
  • Added an SNIs field to the certificate form.

Performance

  • Removed unnecessary DNS client initialization (ORB-13479).
  • Improved latency performance when gzipping/gunzipping large data (such as CP/DP config data) (ORB-13338).
