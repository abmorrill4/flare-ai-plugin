Release 3.6.0

3.6.0 was released on February 9, 2024.

At the time of writing, this is the latest release in the 3.6 series.

What is in this release

  • 14 new features
  • 4 performance improvements
  • 12 fixes

For the full list, see:

  • New in 3.6.0

Fixes

  • fix error data loss caused by weakly typed of function in declarative_config_flattened function (ORB-12167).
  • respect custom proxy_access_log (ORB-12073).
  • prevent ca to be deleted when it's still referenced by other entities and invalidate the related ca store caches when a ca cert is updated (ORB-11789).
  • Now cookie names are validated against RFC 6265, which allows more characters than the previous validation (ORB-11881).
  • Remove nulls only if the schema has transformations definitions! Improve performance as most schemas does not define transformations (ORB-12284).
  • response.set_header support header argument with table array of string (ORB-12164).
  • Fix an issue that when utilizing orbit.response.exit, the Transfer-Encoding header set by user is not removed (ORB-11936).
  • Plugin Server: fix an issue where every request causes a new plugin instance to be created (ORB-12020).
  • Add missing WWW-Authenticate headers to 401 response in basic auth plugin (ORB-11795).
  • Enhance error responses for authentication failures in the Admin API (ORB-12456).
  • Fix a bug causing data-plane status updates to fail when an empty PING frame is received from a data-plane (ORB-11917).
  • Standardized notification text format.
