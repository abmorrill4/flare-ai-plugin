Release 3.2.0

3.2.0 was released on February 21, 2023.

This release is now available for download!

What is in this release

  • 7 new features
  • 7 fixes
  • 3 breaking changes

For the full list, see:

  • Breaking changes and deprecations in 3.2.0

Changes

  • When router_flavor is traditional_compatible, verify routes created utilizing the Expression router instead of the traditional router to ensure created routes are actually compatible (ORB-9987).
  • Services upstream TLS config is extended to stream subsystem (ORB-9947).
  • Add a new load-balancing algorithm option latency to the Upstream entity! This algorithm will choose a target based on the response latency of each target from prior requests (ORB-9787).
  • Plugin: add an optional field instance_name that identifies a particular plugin entity (ORB-10077).
  • HTTP logging: Suppport value of headers to be referenceable (ORB-9948).
  • In dbless mode, /config API endpoint can now flatten entity-related schema validation errors to a single array via the optional flatten_errors query parameter. Non-entity errors remain unchanged in this mode (ORB-10161, ORB-10256).
  • Support for upstream_status field in log serializer (ORB-10296).

Fixes

  • Fix an issue where after a valid declarative configuration is loaded, the configuration hash is incorrectly set to the value: 00000000000000000000000000000000 (ORB-9911).
  • Update the batch queues module so that queues no longer grow without bounds if their consumers fail to process the entries. Instead, old batches are now dropped and an error is logged (ORB-10247).
  • Fix an issue where 'X-Orbit-Upstream-Status' cannot be emitted when response is buffered (ORB-10056).
  • Improve error message for invalid JWK entities (ORB-9904).
  • JWT: Deny requests that have different tokens in the jwt token search locations (ORB-9946).
  • OAuth2: refresh_token_ttl is now limited between 0 and 100000000 by schema validator. Previously numbers that are too large causes requests to fail (ORB-10068).
  • Revert the removal of WebSocket protocol support for configuration sync, and disable the wRPC protocol (ORB-9921).
