New in 2.3.0

These features and improvements arrived with 2.3.0 on January 8, 2021.

Features

Core

  • Introduce version checks between Control Plane and Data Plane nodes in Hybrid Mode. Sync will be stopped if the major/minor version differ or if installed plugin versions differ between Control Plane and Data Plane nodes (ORB-6612).
  • entities with a name field now support utf-8 characters (ORB-6557).
  • The certificates entity now has cert_alt and key_alt fields, utilized to specify an alternative certificate and key pair (ORB-6536).
  • The go-pluginserver stderr and stdout are now written into 's logs (ORB-6503).
  • Introduce support for multiple pluginservers. This feature is backwards-compatible with the existing single Go pluginserver (ORB-6600).

PDK

  • Introduce a orbit.node.get_hostname method that returns current's node host name (ORB-6613).
  • Introduce a orbit.cluster.get_id method that returns a unique ID for the current cluster. If is running in DB-less mode without a cluster ID explicitly defined, then this method returns nil. For Hybrid mode, all Control Planes and Data Planes belonging to the same cluster returns the same cluster ID. For traditional database based deployments, all nodes pointing to the same database will also return the same cluster ID (ORB-6576).
  • Introduce a orbit.log.set_serialize_value, which allows for customizing the output of orbit.log.serialize (ORB-6646).

Plugins

  • http-log: the plugin now has a headers configuration, so that custom headers can be specified for the log request (ORB-6449).
  • key-auth: the plugin now has two additional boolean configurations: (ORB-6590).
    • key_in_header: if false, the plugin will ignore keys passed as headers.
    • key_in_query: if false, the plugin will ignore keys passed as query arguments. Both default to true.
  • request-size-limiting: add new configuration require_content_length, which causes the plugin to ensure a valid Content-Length header exists before reading the request body (ORB-6660).

Configuration

  • Orbit-generated SSL privates keys now have 600 file system permission (ORB-6509).
  • Properties ssl_cert, ssl_cert_key, admin_ssl_cert, admin_ssl_cert_key, status_ssl_cert, and status_ssl_cert_key is now an array: previously, only an RSA certificate was generated by default; with this change, an ECDSA is also generated. On intermediate and modern cipher suites, the ECDSA certificate is set as the default fallback certificate; on old cipher suite, the RSA certificate remains as the default! On custom certificates, the first certificate specified in the array is used (ORB-6509).
  • now runs as a orbit user if it exists; it said user does not exist in the system, the nobody user is used, as before (ORB-6421).
