New in 2.1.0

These features and improvements arrived with 2.1.0 on July 16, 2020.

Features

Core

  • Asynchronous upstream updates: 's load balancer is now able to update its internal structures asynchronously instead of onto the request/stream path. This change required the introduction of new configuration properties and the deprecation of older ones: (ORB-5325).
    • New properties:
    • worker_consistency
    • worker_state_update_frequency
    • Deprecated properties:
  • The default certificate for the proxy can now be configured via Admin API using the /certificates endpoint. A special * SNI has been introduced which stands for the default certificate (ORB-5404).
  • Add X-Forwarded-Prefix to set of headers forwarded to upstream requests (ORB-5620).
  • Introduce a _transform option to declarative configuration, which allows importing basicauth credentials with and without hashed passwords! This change is only supported in declarative configuration format version 2.1 (ORB-5835).

CLI

  • Migrations: add a new --force flag to orbit migrations bootstrap (ORB-5635).

Configuration

  • Introduce configuration property db_cache_neg_ttl, allowing the configuration of negative TTL for DB entities (ORB-5397).

PDK

  • Support orbit.response.exit in Stream (L4) proxy mode (ORB-5524).
  • Introduce orbit.request.get_forwarded_path method, which returns the path component of the request's URL, but also considers X-Forwarded-Prefix if it comes from a trusted source (ORB-5620).
  • Introduce orbit.response.error method, that allows PDK users to exit with an error while honoring the Accept header or manually forcing a content-type (ORB-5562).
  • Introduce orbit.log.serialize method (ORB-5995).

Plugins

  • New Plugin: introduce the grpc-gateway plugin, allowing access to upstream gRPC services through a plain HTTP request (ORB-5939).
  • Go: add getter and setter methods for orbit.ctx.shared.
  • OAuth2: add ability to persist refresh tokens throughout their life cycle (ORB-5264).
  • IP-Restriction: add support for IPv6 (ORB-5640).

Changes

Core

  • Increase maximum allowed payload size in hybrid mode (ORB-5654).
  • Targets now support a weight range of 0-65535 (ORB-5871).

Configuration

  • The configuration properties router_consistency and router_update_frequency have been renamed to worker_consistency and worker_state_update_frequency, respectively. The new properties allow for configuring the consistency settings of additional internal structures, see below for details (ORB-5325).
  • The default value of worker_state_update_frequency (previously router_update_frequency) was changed from 1 to 5 (ORB-5325).

Plugins

  • Change authentication plugins to standardize on allow and deny as terms for access control. Previous nomenclature is deprecated and support will be removed in 3.0 (ORB-6014).
    • ACL: use allow and deny instead of whitelist and blacklist
    • bot-detection: use allow and deny instead of whitelist and blacklist
    • ip-restriction: use allow and deny instead of whitelist and blacklist
