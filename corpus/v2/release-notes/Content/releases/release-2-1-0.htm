Release 2.1.0

2.1.0 was released on July 16, 2020.

Post-release note (as of 2020/08/13): A faulty behavior has been observed with this change. When proxies using the balancer and a request to one of the upstream Target fails, might send the same request to another healthy Target in a different request later, causing response for the failed request to be returned. This bug could be mitigated temporarily by disabling upstream keepalive pools.

Version 2.1.0 is currently in extended support.

Fixes

  • Fix memory leak when loading a declarative configuration that fails schema validation (ORB-5759).
  • Fix migration issue where the index for the ca_certificates table would fail to be created (ORB-5764).
  • Fix issue where DNS resolution would fail in DB-less mode (ORB-5831).
  • Disallow PATCH on /upstreams/:upstreams/targets/:targets.
  • Strip Authorization value from logged headers. Values are now shown as REDACTED (ORB-5628).
  • ACL: respond with HTTP 401 rather than 403 if credentials are not provided (ORB-5452).
