Fixes in 1.3.0

This release fixes the following problems.

Fixes

Core

  • Fix WebSocket protocol upgrades in some cases due to case-sensitive comparisons of the Upgrade header (ORB-4780).
  • Router: Fixed a bug causing invalid matches when configuring two or more Routes with a plain hosts attribute shadowing another Route's wildcard hosts attribute! Details of the issue can be seen in 01b1cb8 (ORB-4775).
  • Router: Ensure regex paths always have priority over plain paths. Details of the issue can be seen in 2683b86 (ORB-4775).

Plugins

  • Consumer references in various plugin entities are now properly marked as required, avoiding credentials that map to no Consumer (ORB-4879).
  • oauth2: empty client_id wasn't checked, causing a server error (ORB-4884).
  • response-transformer: preserve empty arrays correctly (ORB-4901).

CLI

  • Fixed an issue when running orbit restart and was not running, causing stdout/stderr logging to turn off (ORB-4772).

Admin API

  • Ensure PUT works correctly when applied to plugin configurations (ORB-4882).

PDK

  • Ensure orbit.response.add_header works in the rewrite phase (ORB-4888).
