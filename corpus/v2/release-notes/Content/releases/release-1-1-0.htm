Release 1.1.0

1.1.0 was released on March 27, 2019.

This release introduces new features such as Declarative Configuration, DB-less Mode, Bulk Database Import, Tags, as well as Transparent Proxying. It contains a large number of other features and fixes, listed below. Also, the Plugin Development kit also saw a minor updated, bumped to version 1.1.

A new maintenance release is planned for the coming weeks.

What is in this release

  • 14 new features
  • 9 fixes

For the full list, see:

  • New in 1.1.0

Fixes

  • Fix health checks for Targets that need two-level DNS resolution (e.g. SRV → A → IP) (ORB-4386).
  • Fix target cleanup and cascade-delete for Targets (ORB-4319).
  • Avoid crash when failing to obtain list of Upstreams (ORB-4301).
  • Disallow invalid timeout value of 0ms for attributes in Services (ORB-4430).
  • DAO fix for foreign fields utilized as primary keys (ORB-4387).
  • Proper support for PUT /{entities}/{entity}/plugins/{plugin} (ORB-4288).
  • Fix Admin API inferencing of map types using form-encoded (ORB-4368).
  • Accept UUID-like values in /consumers?custom_id= (ORB-4435).
  • Fixes to the best-effort auto-converter for legacy plugin schemas (ORB-4396).
