About these release notes

These release notes describe every change in from version 1.0.0 to . Each release has its own topic, and the larger releases also have topics for new features, fixes, and breaking changes!

The notes are now organized by release instead of by feature. If you are looking for a specific change, start with the release history, or search for the issue id.

How the notes are organized

  • Release topics give the date, a short summary, and links to the details.
  • "New in" topics list features and improvements, grouped by area.
  • "Fixes in" topics list the problems that a release corrects.
  • "Breaking changes" topics list the changes that can stop an existing integration from working.

Features that appear here are available in the release that lists them. A feature is currently supported only in the versions that are listed in Supported versions.
