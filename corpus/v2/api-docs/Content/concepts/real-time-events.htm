Real-time events API

's real-time events API lets you write software that reacts immediately to events happening in . This API is what powers the real-time updates in the web and mobile apps. As a result, the events available via this API cover all changes to data displayed in the product, from new messages to channel descriptions to emoji reactions to changes in user or organization-level settings. Each change is reviewed by the support team before it is applied.

Using the events API

The simplest way to use 's real-time events API is by using call_on_each_event from our Python bindings. You just need to write a Python function (in the examples below, the lambdas) and pass it into call_on_each_event; your function will be called whenever a new event matching the specified parameters (event_types, narrow, etc.) occurs in .

call_on_each_event takes care of all the potentially tricky details of long-polling, error handling, exponential backoff in retries, etc. It's cousin, call_on_each_message, provides an even simpler interface for processing messages.

More complex applications (like a terminal client) may need to instead use the raw register and events endpoints.

Usage examples

Python

#!/usr/bin/env python

import sys
import relay

# Pass the path to your relayrc file here.
client = relay.Client(config_file="~/relayrc")

# Print every message the current user would receive
# This is a blocking call that will run forever
client.call_on_each_message(lambda msg: sys.stdout.write(str(msg) + "\n"))

# Print every event relevant to the user
# This is a blocking call that will run forever
client.call_on_each_event(lambda event: sys.stdout.write(str(event) + "\n"))
