Python: work with channels

Before you start

Create a channel

Call Create a channel like this:

# Create a new channel.
request = {
    "name": "music_group",
    "description": "Channel for discussing and learning about music.",
    "subscribers": [12],
}
result = client.call_endpoint(
    url="channels/create",
    method="POST",
    request=request,
)

Remove a default channel

Call Remove a default channel like this:

# Remove a channel from the set of default channels for new users.
request = {"stream_id": stream_id}
result = client.call_endpoint(
    url="/default_streams",
    method="DELETE",
    request=request,
)

Add a default channel

Call Add a default channel like this:

# Add a channel to the set of default channels for new users.
result = client.add_default_stream(stream_id)

Get channel ID

Call Get channel ID like this:

# Get the ID of a given channel name.
result = client.get_stream_id(name)

Get all channels

Call Get all channels like this:

# Get all channels that the user has access to.
result = client.get_streams()

Archive a channel

Call Archive a channel like this:

# Archive a channel, given the channel's ID.
result = client.delete_stream(stream_id)
