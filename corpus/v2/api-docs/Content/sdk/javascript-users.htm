JavaScript: work with users

Before you start

Set "typing" status

Call Set "typing" status like this:

const user_id1 = 9;
const user_id2 = 10;

const typingParams = {
    op: "start",
    to: [user_id1, user_id2],
};

// The user has started typing in the group direct message
// with Alan and Barbara
console.log(await client.typing.send(typingParams));

Get users

Call Get users like this:

// Get all users in the realm
console.log(await client.users.retrieve());

// You may pass the `client_gravatar` query parameter as follows:
console.log(await client.users.retrieve({client_gravatar: true}));

Create a user

Call Create a user like this:

const params = {
    email: "notnewbie@example.com",
    password: "temp",
    full_name: "New User",
};

console.log(await client.users.create(params));

Get own user

Call Get own user like this:

// Get the profile of the user/bot that requests this endpoint,
// which is `client` in this case:
console.log(await client.users.me.getProfile());
