Python: work with navigation views

Before you start

Get all navigation views

Call Get all navigation views like this:

# Get all navigation views for the user
result = client.call_endpoint(
    url="navigation_views",
    method="GET",
)

Add a navigation view

Call Add a navigation view like this:

# Add a navigation view
request = {
    "fragment": "narrow/is/alerted",
    "is_pinned": True,
    "name": "Alert Word",
}
result = client.call_endpoint(
    url="navigation_views",
    method="POST",
    request=request,
)

Remove a navigation view

Call Remove a navigation view like this:

# Remove a navigation views
result = client.call_endpoint(
    url=f"navigation_views/{fragment}",
    method="DELETE",
)

Update the navigation view

Call Update the navigation view like this:

# Update a navigation view's location
request = {
    "is_pinned": True,
}
result = client.call_endpoint(
    url=f"navigation_views/{fragment}",
    method="PATCH",
    request=request,
)
