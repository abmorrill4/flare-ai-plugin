JavaScript: work with messages

Before you start

Get messages

Call Get messages like this:

const readParams = {
    anchor: "newest",
    num_before: 100,
    num_after: 0,
    narrow: [
        {operator: "sender", operand: "alan@example.com"},
        {operator: "channel", operand: "design"},
    ],
};

// Get the 100 last messages sent by "alan@example.com" to the channel "design"
console.log(await client.messages.retrieve(readParams));

Send a message

Call Send a message like this:

// Send a channel message
let params = {
    to: "social",
    type: "stream",
    topic: "Launch",
    content: "I come not, friends, to steal away your hearts.",
};
console.log(await client.messages.send(params));

// Send a direct message
const user_id = 9;
params = {
    to: [user_id],
    type: "direct",
    content: "With mirth and laughter let old wrinkles come.",
};
console.log(await client.messages.send(params));

Update personal message flags

Call Update personal message flags like this:

// Add the "read" flag to the messages with IDs in "message_ids"
const addflag = {
    messages: message_ids,
    flag: "read",
};
console.log(await client.messages.flags.add(addflag));

// Remove the "starred" flag from the messages with IDs in "message_ids"
const removeflag = {
    messages: message_ids,
    flag: "starred",
};
console.log(await client.messages.flags.remove(removeflag));

Render a message

Call Render a message like this:

// Render a message
const params = {
    content: "**foo**",
};

console.log(await client.messages.render(params));

Edit a message

Call Edit a message like this:

// Update a message with the given "message_id"
const params = {
    message_id,
    content: "New Content",
};

console.log(await client.messages.update(params));
