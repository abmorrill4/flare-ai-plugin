Python: work with users

Before you start

Get attachments

Call Get attachments like this:

# Get your attachments.
result = client.get_attachments()

Delete an attachment

Call Delete an attachment like this:

# Delete the attachment given the attachment's ID.
url = "attachments/" + str(attachment_id)
result = client.call_endpoint(
    url=url,
    method="DELETE",
)

Get a bot's API key

Call Get a bot's API key like this:

# Fetch a bot's API key, given the bot's ID.
result = client.call_endpoint(
    url=f"/bots/{bot_id}/api_key",
    method="GET",
)

Regenerate a bot's API key

Call Regenerate a bot's API key like this:

# Generate a new API key for a bot, given the bot's ID.
result = client.call_endpoint(
    url=f"/bots/{bot_id}/api_key/regenerate",
    method="POST",
)

Set "typing" status for message editing

Call Set "typing" status for message editing like this:

# The user has started typing while editing a message.
request = {
    "op": "start",
}
result = client.call_endpoint(
    f"/messages/{message_id}/typing",
    method="POST",
    request=request,
)

Update settings

Call Update settings like this:

# Enable push notifications even when online and change emoji set.
request = {
    "enable_offline_push_notifications": True,
    "enable_online_push_notifications": True,
    "emojiset": "google",
}
result = client.call_endpoint("/settings", method="PATCH", request=request)
