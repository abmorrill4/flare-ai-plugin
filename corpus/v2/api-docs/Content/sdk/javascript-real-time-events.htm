JavaScript: work with real time events

Before you start

Delete an event queue

Call Delete an event queue like this:

// Register a queue
const queueParams = {
    event_types: ["message"],
};
const res = await client.queues.register(queueParams);

// Delete a queue
const deregisterParams = {
    queue_id: res.queue_id,
};

console.log(await client.queues.deregister(deregisterParams));

Get events from an event queue

Call Get events from an event queue like this:

// Retrieve events from a queue with given "queue_id"
const eventParams = {
    queue_id,
    last_event_id: -1,
};

console.log(await client.events.retrieve(eventParams));

Register an event queue

Call Register an event queue like this:

// Register a queue
const params = {
    event_types: ["message"],
};

console.log(await client.queues.register(params));
