Python: work with messages

Before you start

Mark all messages as read

Call Mark all messages as read like this:

# Mark all of the user's unread messages as read.
result = client.mark_all_as_read()

Mark messages in a channel as read

Call Mark messages in a channel as read like this:

# Mark the unread messages in a channel as read, given the channel's ID.
result = client.mark_stream_as_read(stream_id)

Mark messages in a topic as read

Call Mark messages in a topic as read like this:

# Mark unread messages in a given topic/channel as read.
result = client.mark_topic_as_read(stream_id, topic_name)

Get messages

Call Get messages like this:

# Get the 100 last messages sent by "alan@example.com" to
# the channel named "design".
request: dict[str, Any] = {
    "anchor": "newest",
    "num_before": 100,
    "num_after": 0,
    "narrow": [
        {"operator": "sender", "operand": "alan@example.com"},
        {"operator": "channel", "operand": "design"},
    ],
}
result = client.get_messages(request)

Send a message

Call Send a message like this:

# Send a channel message.
request = {
    "type": "stream",
    "to": "general",
    "topic": "Launch",
    "content": "I come not, friends, to steal away your hearts.",
}
result = client.send_message(request)

Update personal message flags

Call Update personal message flags like this:

# Add the "read" flag to messages, given the messages' IDs.
request = {
    "messages": message_ids,
    "op": "add",
    "flag": "read",
}
result = client.update_message_flags(request)
