Python: work with bots

Before you start

Remove a bot's stored data

Call Remove a bot's stored data like this:

# Remove all data stored for a bot user.
result = client.call_endpoint(
    url="/bot_storage",
    method="DELETE",
)

Get a bot's stored data

Call Get a bot's stored data like this:

# Retrieve all data stored for a bot user.
result = client.get_storage()

Update a bot's stored data

Call Update a bot's stored data like this:

# Store value of "bar" for the key "foo" for a bot user.
result = client.update_storage({"storage": {"foo": "bar"}})
