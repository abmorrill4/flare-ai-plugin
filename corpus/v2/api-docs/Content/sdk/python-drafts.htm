Python: work with drafts

Before you start

Get all saved snippets

Call Get all saved snippets like this:

# Get all the saved snippets.
result = client.call_endpoint(
    url="/saved_snippets",
    method="GET",
)

Create a saved snippet

Call Create a saved snippet like this:

# Create a saved snippet.
request = {"title": "Welcome message", "content": "**Welcome** to the organization."}
result = client.call_endpoint(
    request=request,
    url="/saved_snippets",
    method="POST",
)

Delete a saved snippet

Call Delete a saved snippet like this:

# Delete a saved snippet.
result = client.call_endpoint(
    url=f"/saved_snippets/{saved_snippet_id}",
    method="DELETE",
)

Edit a saved snippet

Call Edit a saved snippet like this:

# Edit a saved snippet.
request = {"title": "New welcome message", "content": "Welcome to Acme Relay!"}
result = client.call_endpoint(
    request=request,
    url=f"/saved_snippets/{saved_snippet_id}",
    method="PATCH",
)
