Error code REACTION_ALREADY_EXISTS

The REACTION_ALREADY_EXISTS error code is returned with HTTP status 400.

When you see this error

An example JSON error response for when the reaction already exists. Changes: New in 8.0 (feature level 193). Previously, this error returned the "BAD_REQUEST" code.

Bad request.

Example response

{
  "result": "error",
  "msg": "Reaction already exists.",
  "code": "REACTION_ALREADY_EXISTS"
}
