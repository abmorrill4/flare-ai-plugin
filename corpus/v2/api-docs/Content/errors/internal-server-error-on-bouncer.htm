Error code INTERNAL_SERVER_ERROR_ON_BOUNCER

The INTERNAL_SERVER_ERROR_ON_BOUNCER error code is returned with HTTP status 502.

When you see this error

Internal bouncer server error A typical failed JSON response for when a 5xx error occurs on the bouncer server.

Bad gateway.

Example response

{
  "result": "error",
  "msg": "Internal server error on Acme Relay push notification service, retry later.",
  "code": "INTERNAL_SERVER_ERROR_ON_BOUNCER"
}
