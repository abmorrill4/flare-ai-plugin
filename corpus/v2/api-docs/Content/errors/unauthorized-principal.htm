Error code UNAUTHORIZED_PRINCIPAL

The UNAUTHORIZED_PRINCIPAL error code is returned with HTTP status 400.

When you see this error

An example JSON response for when the current user is not an organization owner:

Bad request.

Example response

{
  "result": "error",
  "msg": "Must be an organization administrator",
  "code": "UNAUTHORIZED_PRINCIPAL"
}

Where it will appear

  • Delete a topic
