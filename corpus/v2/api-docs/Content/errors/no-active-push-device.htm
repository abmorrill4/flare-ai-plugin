Error code NO_ACTIVE_PUSH_DEVICE

The NO_ACTIVE_PUSH_DEVICE error code is returned with HTTP status 400.

When you see this error

No active push device A typical failed JSON response for when no registered device is available for the user (and push_account_id) to receive a push notification.

Bad request.

Example response

{
  "result": "error",
  "msg": "No active registered push device",
  "code": "NO_ACTIVE_PUSH_DEVICE"
}
