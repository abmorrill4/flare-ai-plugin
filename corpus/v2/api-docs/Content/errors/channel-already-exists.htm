Error code CHANNEL_ALREADY_EXISTS

The CHANNEL_ALREADY_EXISTS error code is returned with HTTP status 409.

When you see this error

An example JSON error response for when a channel with the submitted name already exists.

Bad request.

Example response

{
  "result": "error",
  "msg": "Channel 'discussions' already exists",
  "code": "CHANNEL_ALREADY_EXISTS"
}

Where it appears

  • Create a channel
