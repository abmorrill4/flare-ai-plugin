Error code REACTION_DOES_NOT_EXIST

The REACTION_DOES_NOT_EXIST error code is returned with HTTP status 400.

When you see this error

An example JSON error response for when the reaction does not exist. Changes: New in 8.0 (feature level 193). Previously, this error returned the "BAD_REQUEST" code.

Bad request.

Example response

{
  "result": "error",
  "msg": "Reaction doesn't exist.",
  "code": "REACTION_DOES_NOT_EXIST"
}

Where it appears

  • Remove an emoji reaction
