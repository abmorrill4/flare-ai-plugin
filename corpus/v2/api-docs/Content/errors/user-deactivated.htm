Error code USER_DEACTIVATED

The USER_DEACTIVATED error code is returned with HTTP status 401.

When you see this error

User account deactivated A typical failed json response for when user's account is deactivated. Changes: As of 5.0 (feature level 76), these errors use the HTTP 401 status code. Before this feature level, they used the HTTP 403 status code.

Unauthorized.

Example response

{
  "result": "error",
  "msg": "Account is deactivated",
  "code": "USER_DEACTIVATED"
}
