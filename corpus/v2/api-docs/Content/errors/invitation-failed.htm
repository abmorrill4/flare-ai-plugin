Error code INVITATION_FAILED

The INVITATION_FAILED error code is returned with HTTP status 400.

When you see this error

An example JSON error response for when some of the specified email addresses have existing accounts.

Bad request.

Example response

{
  "result": "error",
  "msg": "Some of those addresses are already using Acme Relay, so we didn't send them an invitation. We did send invitations to everyone else!",
  "code": "INVITATION_FAILED",
  "errors": [
    [
      "ada@relay.com",
      "Already has an account.",
      false
    ]
  ],
  "sent_invitations": true,
  "license_limit_reached": false,
  "daily_limit_reached": false
}

Where it appears

  • Send invitations
