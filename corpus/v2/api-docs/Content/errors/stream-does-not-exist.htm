Error code STREAM_DOES_NOT_EXIST

The STREAM_DOES_NOT_EXIST error code is returned with HTTP status 400.

When you see this error

Bad request.

Example response

{
  "result": "error",
  "msg": "Channel 'nonexistent' does not exist",
  "code": "STREAM_DOES_NOT_EXIST",
  "stream": "nonexistent",
  "stream_id": 9
}

Where it appears

  • Unsubscribe from a channel
  • Send a message
