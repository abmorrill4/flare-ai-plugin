Error code FAILED_TO_CONNECT_BOUNCER

The FAILED_TO_CONNECT_BOUNCER error code is returned with HTTP status 502.

When you see this error

Failed to connect bouncer A typical failed JSON response for when a network error occurs while the server attempts to connect to the bouncer server.

Bad gateway.

Example response

{
  "result": "error",
  "msg": "Network error while connecting to Acme Relay push notification service.",
  "code": "FAILED_TO_CONNECT_BOUNCER"
}
