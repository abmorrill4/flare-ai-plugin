Error code REQUEST_VARIABLE_MISSING

The REQUEST_VARIABLE_MISSING error code is returned with HTTP status 400.

When you see this error

Missing request parameter A typical failed JSON response for when a required request parameter is not supplied. The value of var_name contains information about the missing parameter.

Bad request.

Example response

{
  "result": "error",
  "msg": "Missing 'content' argument",
  "code": "REQUEST_VARIABLE_MISSING",
  "var_name": "content"
}
