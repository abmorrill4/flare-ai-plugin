Error code TOPIC_WILDCARD_MENTION_NOT_ALLOWED

The TOPIC_WILDCARD_MENTION_NOT_ALLOWED error code is returned with HTTP status 400.

When you see this error

An example JSON error response for when the message was rejected because the message contains a topic wildcard mention, but the user doesn't have permission to use such a mention in this topic as the user is not present in can_mention_many_users_group and the topic contains a large number of participants. Changes: New in 8.0 (feature level 229). Previously, wildcard_mention_policy was not enforced for topic mentions.

Bad request. Configure the remaining options as appropriate for your situation.

Example response

{
  "result": "error",
  "msg": "You do not have permission to use topic wildcard mentions in this topic.",
  "code": "TOPIC_WILDCARD_MENTION_NOT_ALLOWED"
}
