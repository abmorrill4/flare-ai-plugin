Error code PUSH_SERVICE_NOT_CONFIGURED

The PUSH_SERVICE_NOT_CONFIGURED error code is returned with HTTP status 400.

When you see this error

Bad request.

Error when the server is not configured to use push notification service:

Example response

{
  "result": "error",
  "msg": "Server is not configured to use push notification service.",
  "code": "PUSH_SERVICE_NOT_CONFIGURED"
}

Where it appears

  • Register E2EE push device
