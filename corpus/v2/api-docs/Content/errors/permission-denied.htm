Error code PERMISSION_DENIED

The PERMISSION_DENIED error code is returned with HTTP status 400.

When you see this error

A typical failed JSON response when the user is not a bot:

Bad request.

Example response

{
  "result": "error",
  "msg": "Must be a bot user",
  "code": "PERMISSION_DENIED"
}

Where it appears

  • Remove a bot's stored data
  • Get a bot's stored data
  • Update a bot's stored data
