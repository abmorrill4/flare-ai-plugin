Edit a saved snippet

PATCH /saved_snippets/{saved_snippet_id}

Edit a saved snippet for the current user.

Changes: New in 10.0 (feature level 368).

This endpoint is part of version of the REST API.

Usage examples

Python

# Edit a saved snippet.
request = {"title": "New welcome message", "content": "Welcome to Acme Relay!"}
result = client.call_endpoint(
    request=request,
    url=f"/saved_snippets/{saved_snippet_id}",
    method="PATCH",
)

curl

# Edit a saved snippet
curl -sS -X PATCH https://chat.example.com/api/v1/saved_snippets/3 \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
saved_snippet_id path integer Yes The ID of the saved snippet to edit.
title body string No The title of the saved snippet.
content body string No The content of the saved snippet in the original Acme Relay-flavored Markdown format.

Parameter details

content

Clients should insert this content into a message when using a saved snippet.

Response

Success. Items on the blacklist cannot be selected.

Errors

HTTP 404

Not Found.

Example response 
{
  "code": "BAD_REQUEST",
  "result": "error",
  "msg": "Saved snippet does not exist."
}
