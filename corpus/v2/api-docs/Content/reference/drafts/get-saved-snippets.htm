Get all saved snippets

GET /saved_snippets

Fetch all the saved snippets for the current user.

Changes: New in 10.0 (feature level 297).

This endpoint is part of version of the REST API.

Usage examples

Python

# Get all the saved snippets.
result = client.call_endpoint(
    url="/saved_snippets",
    method="GET",
)

curl

# Get all saved snippets
curl -sS -X GET https://chat.example.com/api/v1/saved_snippets \
    -u EMAIL_ADDRESS:API_KEY

Response

Field Type Description
saved_snippets array of objects An array of dictionaries containing data on all of the current user's saved snippets.
