Delete a saved snippet

DELETE /saved_snippets/{saved_snippet_id}

Delete a saved snippet.

Changes: New in 10.0 (feature level 297).

This endpoint is part of version of the REST API.

Usage examples

Python

# Delete a saved snippet.
result = client.call_endpoint(
    url=f"/saved_snippets/{saved_snippet_id}",
    method="DELETE",
)

curl

# Delete a saved snippet
curl -sS -X DELETE https://chat.example.com/api/v1/saved_snippets/2 \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
saved_snippet_id path integer Yes The ID of the saved snippet to delete.

Response

Success.

Errors

HTTP 404

Not Found.

Example response 
{
  "code": "BAD_REQUEST",
  "result": "error",
  "msg": "Saved snippet does not exist."
}
