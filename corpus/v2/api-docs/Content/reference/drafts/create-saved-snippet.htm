Create a saved snippet

POST /saved_snippets

Create a new saved snippet for the current user.

Changes: New in 10.0 (feature level 297).

This endpoint is part of version of the REST API. Click the save button to keep your changes.

Usage examples

Python

# Create a saved snippet.
request = {"title": "Welcome message", "content": "**Welcome** to the organization."}
result = client.call_endpoint(
    request=request,
    url="/saved_snippets",
    method="POST",
)

curl

# Create a saved snippet
curl -sS -X POST https://chat.example.com/api/v1/saved_snippets \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode title=Example\ title \
    --data-urlencode content=Welcome\ to\ the\ organization.

Parameters

Parameter Location Type Required Description
title body string Yes The title of the saved snippet.
content body string Yes The content of the saved snippet in Acme Relay-flavored Markdown format.

Parameter details

content

Clients should insert this content into a message when using a saved snippet.

Response

Field Type Description
saved_snippet_id integer The unique ID of the saved snippet created.

Errors

HTTP 400

Bad request.

Example response 
{
  "code": "BAD_REQUEST",
  "msg": "Title cannot be empty.",
  "result": "error"
}
