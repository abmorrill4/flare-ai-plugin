Delete an event queue

DELETE /events

Delete a previously registered queue.

This endpoint is part of version of the REST API.

Usage examples

Python

# Delete a queue, where `queue_id` is the ID of the queue
# to be removed.
result = client.deregister(queue_id)

JavaScript

// Register a queue
const queueParams = {
    event_types: ["message"],
};
const res = await client.queues.register(queueParams);

// Delete a queue
const deregisterParams = {
    queue_id: res.queue_id,
};

console.log(await client.queues.deregister(deregisterParams));

curl

# Delete an event queue
curl -sS -X DELETE https://chat.example.com/api/v1/events \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode queue_id=fb67bf8a-c031-47cc-84cf-ed80accacda8

Parameters

Parameter Location Type Required Description
queue_id body string Yes The ID of an event queue that was previously registered via POST /api/v1/register (see Register a queue).

Response

Success.

Errors

HTTP 400

Bad request.

Example response 
{
  "code": "BAD_EVENT_QUEUE_ID",
  "msg": "Bad event queue ID: fb67bf8a-c031-47cc-84cf-ed80accacda8",
