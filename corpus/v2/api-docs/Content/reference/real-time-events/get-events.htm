Get events from an event queue

GET /events

This endpoint allows you to receive new events from a registered event queue.

Long-lived clients should use the event_queue_longpoll_timeout_seconds property returned by POST /register as the client-side HTTP request timeout for calls to this endpoint. It is guaranteed to be higher than heartbeat timeout and should be respected by clients to avoid breaking when heartbeat timeout increases.

This endpoint is part of version of the REST API.

Usage examples

Python

# If you already have a queue registered, and thus have a `queue_id`
# on hand, you may use `client.get_events()` and pass in the below
# parameters, like so:
result = client.get_events(queue_id=queue_id, last_event_id=-1)

JavaScript

// Retrieve events from a queue with given "queue_id"
const eventParams = {
    queue_id,
    last_event_id: -1,
};

console.log(await client.events.retrieve(eventParams));

curl

# Get events from an event queue
curl -sS -X GET https://chat.example.com/api/v1/events \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode queue_id=fb67bf8a-c031-47cc-84cf-ed80accacda8

Parameters

Parameter Location Type Required Description
queue_id query string Yes The ID of an event queue that was previously registered via POST /api/v1/register (see Register a queue).
last_event_id query integer No The highest event ID in this queue that you've received and wish to acknowledge. See the code for call_on_each_event in the relay Python module for an example implementation of correctly processing each event exactly once.
dont_block query boolean No Set to true if the client is requesting a nonblocking reply. If not specified, the request will block until either a new event is available or a few minutes have passed, in which case the server will send the client a heartbeat event.

Response

Field Type Description
events array of objects An array of event objects (possibly zero-length if dont_block is set) with IDs newer than last_event_id. Event IDs are guaranteed to be increasing, but they are not guaranteed to be consecutive.
queue_id string The ID of the registered queue.

Errors

HTTP 400

Bad request.

Example response 
{
  "code": "BAD_EVENT_QUEUE_ID",
  "msg": "Bad event queue ID: fb67bf8a-c031-47cc-84cf-ed80accacda8",
  "queue_id": "fb67bf8a-c031-47cc-84cf-ed80accacda8",
  "result": "error"
}
