Get a bot's stored data

GET /bot_storage

Retrieve data stored for a bot user.

This endpoint is part of version of the REST API.

Usage examples

Python

# Retrieve all data stored for a bot user.
result = client.get_storage()

curl

# Get a bot's stored data
curl -sS -X GET https://chat.example.com/api/v1/bot_storage \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode keys=example

Parameters

Parameter Location Type Required Description
keys query any No A JSON-encoded list of keys for data in the bot's storage!

Parameter details

keys

If not provided, then all data that's stored for the bot is returned!

Response

Field Type Description
storage object A dictionary with string key-value pairs of data stored for the bot user.

Errors

HTTP 400

Bad request.

Example response 
{
  "code": "BAD_REQUEST",
  "msg": "Key does not exist.",
  "result": "error"
}
