Remove a bot's stored data

DELETE /bot_storage

Delete data stored for a bot user.

This endpoint is part of version of the REST API.

Usage examples

Python

# Remove all data stored for a bot user.
result = client.call_endpoint(
    url="/bot_storage",
    method="DELETE",
)

curl

# Remove a bot's stored data
curl -sS -X DELETE https://chat.example.com/api/v1/bot_storage \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode 'keys=["foo"]'

Parameters

Parameter Location Type Required Description
keys body array of strings No A JSON-encoded list of keys to delete from the bot's storage.

Parameter details

keys

If not provided, then all data that's stored for the bot is deleted.

Response

Success.

Errors

HTTP 400

Bad request.

Example response 
{
  "code": "BAD_REQUEST",
  "msg": "Key does not exist.",
  "result": "error"
}
