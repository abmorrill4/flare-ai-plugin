Register a logged-in device

POST /register_client_device

Logged-in mobile devices use this endpoint as an initial step to register themselves, before registering for E2EE push notifications.

This endpoint is currently not useful for clients other than mobile.

Changes: New in 12.0 (feature level 468).

This endpoint is part of version of the REST API.

Usage examples

Python

# Register a logged-in device.
result = client.call_endpoint(url="/register_client_device", method="POST")

curl

# Register a logged-in device
curl -sS -X POST https://chat.example.com/api/v1/register_client_device \
    -u EMAIL_ADDRESS:API_KEY

Response

Field Type Description
device_id integer The ID of the newly registered device.
