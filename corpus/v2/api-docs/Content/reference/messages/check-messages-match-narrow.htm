Check if messages match a narrow

GET /messages/matches_narrow

Check whether a set of messages match a narrow.

For many common narrows (e.g. a topic), clients can write an efficient client-side check to determine whether a newly arrived message belongs in the view.

This endpoint is designed to allow clients to handle more complex narrows for which the client does not (or in the case of full-text search, cannot) implement this check. For the full details, click here.

The format of the match_subject and match_content objects is designed to match those returned by the GET /messages endpoint, so that a client can splice these fields into a message object received from GET /events and end up with an extended message object identical to how a GET /messages request for the current narrow would have returned the message.

This endpoint is part of version of the REST API.

Usage examples

Python

# Check which messages, given the message IDs, match a narrow.
request = {
    "msg_ids": msg_ids,
    "narrow": [{"operator": "has", "operand": "link"}],
}
result = client.call_endpoint(url="messages/matches_narrow", method="GET", request=request)

curl

# Check if messages match a narrow
curl -sS -X GET https://chat.example.com/api/v1/messages/matches_narrow \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode msg_ids=example \
    --data-urlencode narrow=example

Parameters

Parameter Location Type Required Description
msg_ids query any Yes List of IDs for the messages to check.
narrow query any Yes A structure defining the narrow to check against. See how to construct a narrow.

Parameter details

narrow

Changes: See changes section of search/narrow filter documentation.

Response

Field Type Description
messages object A dictionary with a key for each queried message that matches the narrow, with message IDs as keys and search rendering data as values.
