Get a message's edit history

GET /messages/{message_id}/history

Fetch the message edit history of a previously edited message.

Note that edit history may be disabled in some organizations; see the help center documentation on editing messages.

This endpoint is part of version of the REST API.

Usage examples

Python

# Get the edit history for a message, given the message's ID.
result = client.get_message_history(message_id)

curl

# Get a message's edit history
curl -sS -X GET https://chat.example.com/api/v1/messages/43/history \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
message_id path integer Yes The target message's ID.
allow_empty_topic_name query boolean No Whether the topic names i.e. topic and prev_topic fields in the message_history objects returned can be empty string.

Parameter details

allow_empty_topic_name

If false, the value of realm_empty_topic_display_name found in the POST /register response is returned replacing the empty string as the topic name.

Changes: New in 10.0 (feature level 334).

Response

Field Type Description
message_history array of objects A chronologically sorted, oldest to newest, array of snapshot objects, each one with the values of the message after the edit.

Errors

HTTP 400

Bad request.

Example response 
{
  "msg": "Invalid message(s)",
  "code": "BAD_REQUEST",
  "result": "error"
}
