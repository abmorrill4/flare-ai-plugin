Mark messages in a channel as read

POST /mark_stream_as_read

Mark all the unread messages in a channel as read.

This endpoint is part of version of the REST API.

Usage examples

Python

# Mark the unread messages in a channel as read, given the channel's ID.
result = client.mark_stream_as_read(stream_id)

curl

# Mark messages in a channel as read
curl -sS -X POST https://chat.example.com/api/v1/mark_stream_as_read \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode stream_id=43

Parameters

Parameter Location Type Required Description
stream_id body integer Yes The ID of the channel to access.

Response

Success.
