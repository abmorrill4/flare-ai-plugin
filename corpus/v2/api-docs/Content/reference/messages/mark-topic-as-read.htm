Mark messages in a topic as read

POST /mark_topic_as_read

Mark all the unread messages in a topic as read. Click the save button to keep your changes.

This endpoint is part of version of the REST API.

Usage examples

Python

# Mark unread messages in a given topic/channel as read.
result = client.mark_topic_as_read(stream_id, topic_name)

curl

# Mark messages in a topic as read
curl -sS -X POST https://chat.example.com/api/v1/mark_topic_as_read \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode stream_id=43 \
    --data-urlencode topic_name=new\ coffee\ machine

Parameters

Parameter Location Type Required Description
stream_id body integer Yes The ID of the channel to access.
topic_name body string Yes The name of the topic whose messages should be marked as read.

Parameter details

topic_name

Response

Success.
