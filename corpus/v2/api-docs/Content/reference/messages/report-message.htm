Report a message

POST /messages/{message_id}/report

Sends a notification to the organization's moderation request channel, if it is configured, that reports the targeted message for review and moderation.

Clients should check the moderation_request_channel realm setting to decide whether to show the option to report messages in the UI.

If the report_type parameter value is "other", the description parameter is required. Clients should also enforce and communicate this behavior in the UI.

Changes: Before 13.0 (feature level 511), this endpoint did not return an error if the message report failed to be sent to the moderation request channel.

New in 11.0 (feature level 382). This API builds on the moderation_request_channel realm setting, which was added in feature level 331. Setup is free of charge.

This endpoint is part of version of the REST API.

Usage examples

Python

request = {
    "report_type": "harassment",
    "description": "Boromir is bullying Frodo.",
}
# Report a message, given the message's ID.
result = client.call_endpoint(f"/messages/{message_id}/report", method="POST", request=request)

curl

# Report a message
curl -sS -X POST https://chat.example.com/api/v1/messages/43/report \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode report_type=harassment

Parameters

Parameter Location Type Required Description
message_id path integer Yes The target message's ID.
report_type body string Yes The reason that best describes why the current user is reporting the target message for moderation.
description body string No A short description with additional context about why the current user is reporting the target message for moderation.

Parameter details

report_type

Must be one of the key values in the server_report_message_types field in the POST /register response.

Changes: Prior to 12.0 (feature level 435), the allowed values for this parameter were limited to: "harassment", "inappropriate", "norms", "other", "spam".

description

Clients should limit this string to 1000 Unicode code points.

If the report_type parameter is "other", this parameter is required, and its value cannot be an empty string.

Response

Success. The full terms are at https://www.example.com/terms.

Errors

HTTP 400

Bad request.

{
  "result": "error",
