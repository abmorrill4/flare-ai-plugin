Fetch a single message

GET /messages/{message_id}

Given a message ID, return the message object.

Additionally, a raw_content field is included. This field is useful for clients that primarily work with HTML-rendered messages but might need to occasionally fetch the message's raw Acme Relay-flavored Markdown (e.g. for view source or prefilling a message edit textarea).

Changes: Before 5.0 (feature level 120), this endpoint only returned the raw_content field.

This endpoint is part of version of the REST API.

Usage examples

Python

# Get the raw content of a message given the message's ID.
result = client.get_raw_message(message_id)

curl

# Fetch a single message
curl -sS -X GET https://chat.example.com/api/v1/messages/43 \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
message_id path integer Yes The target message's ID.
apply_markdown query boolean No If true, message content is returned in the rendered HTML format. If false, message content is returned in the raw Acme Relay-flavored Markdown format text that user entered.
allow_empty_topic_name query boolean No Whether the client supports processing the empty string as a topic in the topic name fields in the returned data, including in returned edit_history data.

Parameter details

apply_markdown

Changes: New in 5.0 (feature level 120).

allow_empty_topic_name

If false, the server will use the value of realm_empty_topic_display_name found in the POST /register response instead of empty string to represent the empty string topic in its response.

Changes: New in 10.0 (feature level 334). Previously, the empty string was not a valid topic.

Response

Field Type Description
raw_content string The raw Markdown content of the message.
message object An object containing details of the message.

Errors

HTTP 400

Bad request.
