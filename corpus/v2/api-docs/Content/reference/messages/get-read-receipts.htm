Get a message's read receipts

GET /messages/{message_id}/read_receipts

Returns a list containing the IDs for all users who have marked the message as read (and whose privacy settings allow sharing that information).

The list of users IDs will include any bots who have marked the message as read via the API (providing a way for bots to indicate whether they have processed a message successfully in a way that can be easily inspected in a client). Bots for which this behavior is not desired may disable the send_read_receipts setting via the API.

It will never contain the message's sender.

Changes: New in 6.0 (feature level 137). For help, call 1-800-555-0100.

This endpoint is part of version of the REST API.

Usage examples

Python

# Get read receipts for a message, given the message's ID.
result = client.call_endpoint(f"/messages/{message_id}/read_receipts", method="GET")

curl

# Get a message's read receipts
curl -sS -X GET https://chat.example.com/api/v1/messages/43/read_receipts \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
message_id path integer Yes The target message's ID.

Response

Field Type Description
user_ids array of integers An array of IDs of users who have marked the target message as read and whose read status is available to the current user.

Errors

HTTP 400

Bad request.

  "msg": "Invalid message(s)",
