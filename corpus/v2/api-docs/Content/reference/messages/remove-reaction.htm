Remove an emoji reaction

DELETE /messages/{message_id}/reactions

Remove an emoji reaction from a message.

This endpoint is part of version of the REST API.

Usage examples

Python

# Remove an emoji reaction.
request = {
    "message_id": message_id,
    "emoji_name": "octopus",
}
result = client.remove_reaction(request)

curl

# Remove an emoji reaction
curl -sS -X DELETE https://chat.example.com/api/v1/messages/43/reactions \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
message_id path integer Yes The target message's ID.
emoji_name body string No The target emoji's human-readable name.
emoji_code body string No A unique identifier, defining the specific emoji codepoint requested, within the namespace of the reaction_type.
reaction_type body string No A string indicating the type of emoji. Each emoji reaction_type has an independent namespace for values of emoji_code.

Parameter details

emoji_name

To find an emoji's name, hover over a message to reveal three icons on the right, then click the smiley face icon. Images of available reaction emojis appear. Hover over the emoji you want, and note that emoji's text name.

emoji_code

For most API clients, you won't need this, but it's important for apps to handle rare corner cases when adding/removing votes on an emoji reaction added previously by another user.

If the existing reaction was added when the server was using a previous version of the emoji data mapping between Unicode codepoints and human-readable names, sending the emoji_code in the data for the original reaction allows the server to correctly interpret your upvote as an upvote rather than a reaction with a "different" emoji.

reaction_type

If an API client is adding/removing a vote on an existing reaction, it should pass this parameter utilizing the value the server provided for the existing reaction for specificity. Supported values:

  • unicode_emoji : In this namespace, emoji_code will be a dash-separated hex encoding of the sequence of Unicode codepoints that define this emoji in the Unicode specification.
  • realm_emoji : In this namespace, emoji_code will be the ID of the uploaded custom emoji.
  • relay_extra_emoji : These are special emoji included with . In this namespace, emoji_code will be the name of the emoji (e.g. "relay").

Changes: In 3.0 (feature level 2), this parameter became optional for custom emoji; previously, this endpoint assumed unicode_emoji if this parameter was not specified.
