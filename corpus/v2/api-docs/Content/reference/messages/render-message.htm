Render a message

POST /messages/render

Render a message to HTML.

This endpoint is part of version of the REST API.

Usage examples

Python

# Render a message.
request = {
    "content": "**foo**",
}
result = client.render_message(request)

JavaScript

// Render a message
const params = {
    content: "**foo**",
};

console.log(await client.messages.render(params));

curl

# Render a message
curl -sS -X POST https://chat.example.com/api/v1/messages/render \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode content=Hello

Parameters

Parameter Location Type Required Description
content body string Yes The content of the message.
populate_url_embed_data body boolean No Whether the server should populate URL embed data for the links in content: data the server already has is included in rendered, and the rest is fetched asynchronously. If that changes the rendered content, it is delivered to the requesting user via a url_embed_data event, so that a client displaying the rendered content can live-update it. See the event's documentation for when it is not sent.

Parameter details

content

populate_url_embed_data

Only links that would get URL embeds if content were sent as a message are populated. For example, links to websites are not populated for bots, or if the organization has disabled website previews.

Changes: New in 13.0 (feature level 513).

Response

Field Type Description
rendered string The rendered HTML.
