Get own user

GET /users/me

Get basic data about the user/bot that requests this endpoint.

Changes: Removed is_billing_admin field in 10.0 (feature level 363), as it was replaced by the can_manage_billing_group realm setting.

This endpoint is part of version of the REST API. The full terms are at https://www.example.com/terms.

Usage examples

Python

# Get the profile of the user/bot that requests this endpoint,
# which is `client` in this case.
result = client.get_profile()

JavaScript

// Get the profile of the user/bot that requests this endpoint,
// which is `client` in this case:
console.log(await client.users.me.getProfile());

curl

# Get own user
curl -sS -X GET https://chat.example.com/api/v1/users/me \
    -u EMAIL_ADDRESS:API_KEY

Response

Field Type Description
avatar_url string URL for the requesting user's avatar.
avatar_version integer Version for the requesting user's avatar. Used for cache-busting requests for the user's avatar. Clients generally shouldn't need to use this; most avatar URLs sent by will already end with ?v={avatar_version}.
email string API email of the requesting user.
full_name string Full name of the requesting user.
is_admin boolean A boolean indicating if the requesting user is an admin.
is_owner boolean A boolean indicating if the requesting user is an organization owner.
role integer Organization-level role of the requesting user. Possible values are:
is_guest boolean A boolean indicating if the requesting user is a guest.
is_bot boolean A boolean indicating if the requesting user is a bot.
is_active boolean A boolean specifying whether the requesting user account has been deactivated.
timezone string The IANA identifier of the requesting user's profile time zone, which is used primarily to display the user's local time to other users.
date_joined string The time when the user joined. For users imported from other applications and users created via the API, this is set to the account creation time until the user logs in for the first time, after which it is updated to that login time.
max_message_id integer The integer ID of the last message received by the requesting user's account.
user_id integer The user's ID.
delivery_email string The requesting user's real email address.
is_imported_stub boolean Indicates whether this user object is a stub account imported from another chat system. Stub accounts are used to represent the senders for imported messages. Stub accounts can be converted to regular accounts when the user starts using , preserving that imported user's message history.
profile_data object Only present if is_bot is false; bots can't have custom profile fields.
