Get user groups

GET /user_groups

Fetches all of the user groups in the organization.

Note: This endpoint is not available to guest users.

This endpoint is part of version of the REST API.

Usage examples

Python

# Get all user groups of the organization.
result = client.get_user_groups()

curl

# Get user groups
curl -sS -X GET https://chat.example.com/api/v1/user_groups \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode 'include_deactivated_groups=true'

Parameters

Parameter Location Type Required Description
include_deactivated_groups body boolean No Whether to include deactivated user groups in the response.

Parameter details

include_deactivated_groups

Changes: In 10.0 (feature level 294), renamed allow_deactivated to include_deactivated_groups.

New in 10.0 (feature level 290). Previously, deactivated user groups did not exist and thus would never be included in the response.

Response

Field Type Description
user_groups array of objects A list of user_group objects.
