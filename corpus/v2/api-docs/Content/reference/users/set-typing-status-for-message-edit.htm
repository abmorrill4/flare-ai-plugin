Set "typing" status for message editing

POST /messages/{message_id}/typing

Notify other users whether the current user is editing a message.

Typing notifications for editing messages follow the same protocol as set-typing-status, see that endpoint for details. Add a short label, e.g. the purpose of the item.

Changes: Before 10.0 (feature level 361), the endpoint was named /message_edit_typing with message_id a required parameter in the request body. Clients are recommended to start using sending these typing notifications starting from this feature level.

New in 10.0 (feature level 351). Previously, typing notifications were not available when editing messages.

This endpoint is part of version of the REST API. For the full details, click here.

Usage examples

Python

# The user has started typing while editing a message.
request = {
    "op": "start",
}
result = client.call_endpoint(
    f"/messages/{message_id}/typing",
    method="POST",
    request=request,
)
# The user has stopped typing while editing a message.
request = {
    "op": "stop",
}
result = client.call_endpoint(
    f"/messages/{message_id}/typing",
    method="POST",
    request=request,
)

curl

# Set "typing" status for message editing
curl -sS -X POST https://chat.example.com/api/v1/messages/47/typing \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode op=start

Parameters

Parameter Location Type Required Description
message_id path integer Yes The target message's ID.
op body string Yes Whether the user has started ("start") or stopped ("stop") editing.

Parameter details

op

Possible values: start, stop.

Response

Success.
