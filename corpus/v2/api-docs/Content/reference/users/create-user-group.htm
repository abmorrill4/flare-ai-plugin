Create a user group

POST /user_groups/create

Create a new user group.

This endpoint is part of version of the REST API.

Usage examples

Python

request = {
    "name": "leadership",
    "description": "The leadership team.",
    "members": user_ids,
}
result = client.create_user_group(request)

curl

# Create a user group
curl -sS -X POST https://chat.example.com/api/v1/user_groups/create \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode name=marketing \
    --data-urlencode description=The\ marketing\ team. \
    --data-urlencode 'members=[1, 2, 3, 4]'

Parameters

Parameter Location Type Required Description
name body string Yes The name of the user group.
description body string Yes The description of the user group.
members body array of integers Yes An array containing the user IDs of the initial members for the new user group.
subgroups body array of integers No An array containing the IDs of the initial subgroups for the new user group.
can_add_members_group body integer or object No None.
can_join_group body integer or object No None.
can_leave_group body integer or object No None.
can_manage_group body integer or object No None.
can_mention_group body integer or object No None.
can_remove_members_group body integer or object No None.

Parameter details

subgroups

User can add subgroups to the new group irrespective of other permissions for the new group.

Changes: New in 10.0 (feature level 311).

Response

Field Type Description
group_id integer The unique ID of the created user group.

Errors

HTTP 400

Bad request.

Example response 
{
  "result": "error",

  "msg": "Invalid user ID: 500"
