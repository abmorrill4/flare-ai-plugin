Regenerate a bot's API key

POST /bots/{bot_id}/api_key/regenerate

Generate a new API key for a bot user. Only the bot's owner and organization administrators have access to a bot's API key.

This endpoint is part of version of the REST API.

Usage examples

Python

# Generate a new API key for a bot, given the bot's ID.
result = client.call_endpoint(
    url=f"/bots/{bot_id}/api_key/regenerate",
    method="POST",
)

curl

# Regenerate a bot's API key
curl -sS -X POST https://chat.example.com/api/v1/bots/17/api_key/regenerate \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
bot_id path integer Yes The user ID of the target bot.

Response

Field Type Description
api_key string The new API key for the bot.

Errors

HTTP 400

Bad request.

Example response 
{
  "code": "BAD_REQUEST",
  "msg": "No such bot",
  "result": "error"
}
