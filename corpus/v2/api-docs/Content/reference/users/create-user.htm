Create a user

POST /users

Create a new user account via the API.

Note: On Cloud, this feature is available only for organizations on a Cloud Standard or Cloud Plus plan. Administrators can request the required can_create_users permission for a bot or user by contacting Cloud support with an explanation for why it is needed. Self-hosted installations can toggle can_create_users on an account using the manage.py change_user_role management command.

Changes: Before 4.0 (feature level 36), this endpoint was available to all organization administrators. Each change is reviewed by the support team before it is applied.

This endpoint is part of version of the REST API.

Usage examples

Python

# Create a user.
request = {
    "email": "newbie@example.com",
    "password": "temp",
    "full_name": "New User",
}
result = client.create_user(request)

JavaScript

const params = {
    email: "notnewbie@example.com",
    password: "temp",
    full_name: "New User",
};

console.log(await client.users.create(params));

curl

# Create a user
curl -sS -X POST https://chat.example.com/api/v1/users \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode email=username@example.com \
    --data-urlencode password=abcd1234 \
    --data-urlencode full_name=New\ User

Parameters

Parameter Location Type Required Description
email body string Yes The email address of the new user.
password body string Yes The password of the new user.
full_name body string Yes The full name of the new user.

Response

Field Type Description
user_id integer The ID assigned to the newly created user.

Errors

HTTP 400

Bad request.

Example response 
{
  "code": "BAD_REQUEST",
  "msg": "Email is already in use.",
  "result": "error"
}
