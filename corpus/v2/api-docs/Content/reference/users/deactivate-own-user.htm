Deactivate own user

DELETE /users/me

Deactivates the current user's account. See also the administrative endpoint for deactivating another user.

This endpoint is primarily useful to clients providing a user settings UI.

This endpoint is part of version of the REST API.

Usage examples

Python

# Deactivate the account of the current user/bot.
result = client.call_endpoint(
    url="/users/me",
    method="DELETE",
)

curl

# Deactivate own user
curl -sS -X DELETE https://chat.example.com/api/v1/users/me \
    -u EMAIL_ADDRESS:API_KEY

Response

Success.

Errors

HTTP 400

Bad request.
