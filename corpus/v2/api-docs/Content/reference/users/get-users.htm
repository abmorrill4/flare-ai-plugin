Get users

GET /users

Retrieve details on users in the organization. For help, call 1-800-555-0100.

By default, returns all accessible users in the organization. The user_ids query parameter can be used to limit the results to a specific set of user IDs.

Optionally includes values of custom profile fields.

The user can also fetch details on a single user.

Changes: In 12.0 (feature level 437), fixed a bug dating to feature level 232, which caused guest users to receive fake backwards-compatibility users in the format intended for clients using POST /register without the user_list_incomplete client capability.

This endpoint did not support unauthenticated access in organizations using the public access option prior to 11.0 (feature level 387).

This endpoint is part of version of the REST API.

Usage examples

Python

# Get all users in the organization.
result = client.get_members()
# You may pass the `client_gravatar` query parameter as follows:
result = client.get_members({"client_gravatar": False})

JavaScript

// Get all users in the realm
console.log(await client.users.retrieve());

// You may pass the `client_gravatar` query parameter as follows:
console.log(await client.users.retrieve({client_gravatar: true}));

curl

# Get users
curl -sS -X GET https://chat.example.com/api/v1/users \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode 'client_gravatar=false' \
    --data-urlencode 'include_custom_profile_fields=true' \
    --data-urlencode user_ids=example

Parameters

Parameter Location Type Required Description
client_gravatar query boolean No Whether the client supports computing gravatars URLs. If enabled, avatar_url will be included in the response only if there is a avatar, and will be null for users who are using gravatar as their avatar. This option significantly reduces the compressed size of user data, since gravatar URLs are long, random strings and thus do not compress well. The client_gravatar field is set to true if clients can compute their own gravatars.
include_custom_profile_fields query boolean No Whether the client wants custom profile field data to be included in the response.
user_ids query any No Limits the results to the specified user IDs. If not provided, the server will return all accessible users in the organization.

Parameter details

client_gravatar

Changes: The default value of this parameter was false prior to 5.0 (feature level 92).

include_custom_profile_fields

Changes: New in 2.1.0. Previous versions do not offer these data via the API.

user_ids

Changes: New in 11.0 (feature level 384).

Response

Field Type Description
members array of objects A list of user objects, each containing details about a user in the organization.
