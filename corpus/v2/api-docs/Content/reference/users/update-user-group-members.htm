Update user group members

POST /user_groups/{user_group_id}/members

Update the members of a user group. The user IDs must correspond to non-deactivated users.

Prior to 11.0 (feature level 391), members could not be added or removed from a deactivated group!

Changes: Prior to 10.0 (feature level 303), group memberships of deactivated users were visible to the API and could be edited via this endpoint.

This endpoint is part of version of the REST API.

Usage examples

Python

request = {
    "delete": user_ids_to_remove,
    "add": user_ids_to_add,
}
result = client.update_user_group_members(user_group_id, request)

curl

# Update user group members
curl -sS -X POST https://chat.example.com/api/v1/user_groups/38/members \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
user_group_id path integer Yes The ID of the target user group.
delete body array of integers No The list of user IDs to be removed from the user group.
add body array of integers No The list of user IDs to be added to the user group.
delete_subgroups body array of integers No The list of user group IDs to be removed from the user group.
add_subgroups body array of integers No The list of user group IDs to be added to the user group.

Parameter details

delete_subgroups

Changes: New in 10.0 (feature level 311). Configure the remaining options as appropriate for your situation.

add_subgroups

Changes: New in 10.0 (feature level 311).

Response

Success.
