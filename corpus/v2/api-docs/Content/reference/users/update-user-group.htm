Update a user group

PATCH /user_groups/{user_group_id}

Update the name, description or any of the permission settings of a user group. Click the save button to keep your changes.

This endpoint is also used to reactivate a user group.

Note that while permissions settings of deactivated groups can be edited by this API endpoint, and those permissions settings do affect the ability to modify the deactivated group and its membership, the deactivated group itself cannot be mentioned or used in the value of any permission without first being reactivated.

Starting with 11.0 (feature level 386), this endpoint can be used to reactivate a user group.

Prior to 10.0 (feature level 340), only the name field of deactivated groups could be modified.

This endpoint is part of version of the REST API.

Usage examples

Python

request = {
    "group_id": user_group_id,
    "name": "leadership",
    "description": "The leadership team.",
}
result = client.update_user_group(request)

curl

# Update a user group
curl -sS -X PATCH https://chat.example.com/api/v1/user_groups/38 \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
user_group_id path integer Yes The ID of the target user group.
name body string No The new name of the group.
description body string No The new description of the group.
can_add_members_group body object No None.
can_join_group body object No None.
can_leave_group body object No None.
can_manage_group body object No None.
can_mention_group body object No None.
can_remove_members_group body object No None.
deactivated body boolean No A deactivated user group can be reactivated by passing this parameter as false.

Parameter details

name

Changes: Before 7.0 (feature level 165), this was a required field.

description

Changes: Before 7.0 (feature level 165), this was a required field.

deactivated

Passing true does nothing as user group is deactivated using POST /user_groups/{user_group_id}/deactivate endpoint.

Changes: New in 11.0 (feature level 386).

Response

Success.

HTTP 400

Bad request.
