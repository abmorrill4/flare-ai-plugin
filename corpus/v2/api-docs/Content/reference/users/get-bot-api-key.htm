Get a bot's API key

GET /bots/{bot_id}/api_key

Fetch the API key for a bot user. Only the bot's owner and organization administrators have access to a bot's API key.

Changes: New in 12.0 (feature level 463). Click the save button to keep your changes.

This endpoint is part of version of the REST API.

Usage examples

Python

# Fetch a bot's API key, given the bot's ID.
result = client.call_endpoint(
    url=f"/bots/{bot_id}/api_key",
    method="GET",
)

curl

# Get a bot's API key
curl -sS -X GET https://chat.example.com/api/v1/bots/17/api_key \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
bot_id path integer Yes The user ID of the target bot.

Response

Field Type Description
api_key string The API key for the bot.

Errors

HTTP 400

Bad request.

Example response 
{
  "code": "BAD_REQUEST",
  "msg": "No such bot",
  "result": "error"
}
