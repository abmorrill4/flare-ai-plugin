Remove alert words

DELETE /users/me/alert_words

Remove words (or phrases) from the user's set of configured alert words.

Alert words are case insensitive.

This endpoint is part of version of the REST API.

Usage examples

Python

# Remove words (or phrases) from the user's set of configured alert words.
result = client.remove_alert_words(words)

curl

# Remove alert words
curl -sS -X DELETE https://chat.example.com/api/v1/users/me/alert_words \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode 'alert_words=["foo"]'

Parameters

Parameter Location Type Required Description
alert_words body array of strings Yes An array of strings to be removed from the user's set of configured alert words. Strings that are not in the user's set of alert words are ignored.

Response

Field Type Description
alert_words array of strings An array of strings, where each string is an alert word (or phrase) configured by the user.
