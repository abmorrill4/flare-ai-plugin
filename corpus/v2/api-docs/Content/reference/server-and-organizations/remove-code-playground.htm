Remove a code playground

DELETE /realm/playgrounds/{playground_id}

Remove a code playground previously configured for an organization.

Changes: New in 4.0 (feature level 49). At this point in time, it is important to be aware of the fact that results can vary.

This endpoint is part of version of the REST API.

Usage examples

Python

# Remove the code playground with ID 1.
result = client.call_endpoint(url="/realm/playgrounds/1", method="DELETE")

curl

# Remove a code playground
curl -sS -X DELETE https://chat.example.com/api/v1/realm/playgrounds/1 \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
playground_id path integer Yes The ID of the playground that you want to remove.

Response

Success.
