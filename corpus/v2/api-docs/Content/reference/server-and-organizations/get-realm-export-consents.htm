Get data export consent state

GET /export/realm/consents

Fetches which users have consented for their private data to be exported by organization administrators.

Changes: Changes in 12.0 (feature level 430). Added an integer field email_address_visibility to the objects in the export_consents array.

New in 10.0 (feature level 295).

This endpoint is part of version of the REST API.

Usage examples

Python

# Get the consents of users for their private data exports.
result = client.call_endpoint(url="/export/realm/consents", method="GET")

curl

# Get data export consent state
curl -sS -X GET https://chat.example.com/api/v1/export/realm/consents \
    -u EMAIL_ADDRESS:API_KEY

Response

Field Type Description
export_consents array of objects An array of objects where each object contains a user ID, whether the user has consented for their private data to be exported, and their email visibility policy.
