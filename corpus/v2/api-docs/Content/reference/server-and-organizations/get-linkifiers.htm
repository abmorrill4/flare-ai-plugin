Get linkifiers

GET /realm/linkifiers

List all of an organization's configured linkifiers, regular expression patterns that are automatically linkified when they appear in messages and topics.

Changes: New in 4.0 (feature level 54). On older versions, a similar GET /realm/filters endpoint was available with each entry in a [pattern, url_format, id] tuple format.

This endpoint is part of version of the REST API.

Usage examples

Python

# Fetch all the linkifiers in this organization.
result = client.call_endpoint(
    url="/realm/linkifiers",
    method="GET",
)

curl

# Get linkifiers
curl -sS -X GET https://chat.example.com/api/v1/realm/linkifiers \
    -u EMAIL_ADDRESS:API_KEY

Response

Field Type Description
linkifiers array of objects An ordered array of objects, where each object describes a linkifier.
