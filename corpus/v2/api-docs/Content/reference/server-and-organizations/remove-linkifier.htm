Remove a linkifier

DELETE /realm/filters/{filter_id}

Remove linkifiers, regular expression patterns that are automatically linkified when they appear in messages and topics.

This endpoint is part of version of the REST API.

Usage examples

Python

# Remove a linkifier.
result = client.remove_realm_filter(filter_id)

curl

# Remove a linkifier
curl -sS -X DELETE https://chat.example.com/api/v1/realm/filters/43 \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
filter_id path integer Yes The ID of the linkifier that you want to remove.

Response

Success.
