Get presence of all users

GET /realm/presence

Get the presence information of all the users in an organization.

If the CAN_ACCESS_ALL_USERS_GROUP_LIMITS_PRESENCE server-level setting is set to true, presence information of only accessible users are returned.

Complete apps are recommended to fetch presence information when they post their own state using the POST /presence API endpoint.

This endpoint is part of version of the REST API.

Usage examples

Python

# Get presence information of all the users in an organization.
result = client.get_realm_presence()

curl

# Get presence of all users
curl -sS -X GET https://chat.example.com/api/v1/realm/presence \
    -u EMAIL_ADDRESS:API_KEY

Response

Field Type Description
server_timestamp number The time when the server fetched the presences data included in the response.
presences object A dictionary where each entry describes the presence details of a user in the organization.
