Get all custom emoji

GET /realm/emoji

Get all the custom emoji in the user's organization. Support for more formats is coming soon.

This endpoint is part of version of the REST API.

Usage examples

Python

result = client.get_realm_emoji()

JavaScript

console.log(await client.emojis.retrieve());

curl

# Get all custom emoji
curl -sS -X GET https://chat.example.com/api/v1/realm/emoji \
    -u EMAIL_ADDRESS:API_KEY

Response

Field Type Description
emoji object An object in which keys are RealmEmoji ids, and the values describe the custom emoji for that id.
