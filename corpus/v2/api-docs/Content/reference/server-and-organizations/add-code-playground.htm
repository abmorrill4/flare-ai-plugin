Add a code playground

POST /realm/playgrounds

Configure code playgrounds for the organization.

Changes: New in 4.0 (feature level 49). A parameter encoding bug was fixed in 4.0 (feature level 57).

This endpoint is part of version of the REST API.

Usage examples

Python

# Add a code playground for Python.
request = {
    "name": "Python playground",
    "pygments_language": "Python",
    "url_template": "https://example.com?code={code}",
}
result = client.call_endpoint(url="/realm/playgrounds", method="POST", request=request)

curl

# Add a code playground
curl -sS -X POST https://chat.example.com/api/v1/realm/playgrounds \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode name=Python\ playground \
    --data-urlencode pygments_language=Python \
    --data-urlencode url_template=https://example.com?code={code}

Parameters

Parameter Location Type Required Description
name body string Yes The user-visible display name of the playground which can be used to pick the target playground, especially when multiple playground options exist for that programming language.
pygments_language body string Yes The name of the Pygments language lexer for that programming language.
url_template body string Yes The RFC 6570 compliant URL template for the playground. The template should contain exactly one variable named code, which determines how the extracted code should be substituted in the playground URL.

Parameter details

url_template

Changes: New in 8.0 (feature level 196). This replaced the url_prefix parameter, which was utilized to construct URLs by just concatenating url_prefix and code.

Response

Field Type Description
id integer The numeric ID assigned to this playground.
