Add a linkifier

POST /realm/filters

Configure linkifiers, regular expression patterns that are automatically linkified when they appear in messages and topics.

This endpoint is part of version of the REST API.

Usage examples

Python

# Add a filter to automatically linkify #<number> to the corresponding
# issue in Acme Relay's server repository.
request = {
    "pattern": "#(?P<id>[0-9]+)",
    "url_template": "https://code.example.com/acme/relay/issues/{id}",
    "example_input": "#1234",
    "reverse_template": "#{id}",
}
result = client.call_endpoint("/realm/filters", method="POST", request=request)

curl

# Add a linkifier
curl -sS -X POST https://chat.example.com/api/v1/realm/filters \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode pattern=#(?P<id>[0-9]+) \
    --data-urlencode url_template=https://code.example.com/acme/relay/issues/{id}

Parameters

Parameter Location Type Required Description
pattern body string Yes The Python regular expression that should trigger the linkifier.
url_template body string Yes The RFC 6570 compliant URL template used for the link. If you used named groups in pattern, the user can insert their content here with {name_of_group}.
example_input body string No An example input string that matches the linkifier's pattern. This is required for reverse linkifiers.
reverse_template body string No A simple template using {variable} for variables that can be used to generate the Markdown linkifier syntax, given a URL matching the URL template.
alternative_url_templates body array of strings No An array of additional RFC 6570 compliant URL template strings that are utilized for reverse linkification (converting pasted URLs to linkifier pattern text). These templates have no effect on forward linkification.

Parameter details

url_template

Changes: New in 7.0 (feature level 176). This replaced the url_format_string parameter, which was a format string in which named groups' content could be inserted with %(name_of_group)s.

example_input

Changes: New in 12.0 (feature level 471).

reverse_template

{{ "{{/}}" }} can be used for literal {/} characters.

Server verifies that variables extracted from example_input using url_pattern when passed to reverse_template returns example_input back to us. At this point in time, it is important to be aware of the fact that results can vary.

Changes: New in 12.0 (feature level 471).

alternative_url_templates

Changes: New in 12.0 (feature level e2b257).

Response

Field Type Description
id integer The numeric ID assigned to this filter.
