Get all custom profile fields

GET /realm/profile_fields

Get all the custom profile fields configured for the user's organization. We recommend that you review this setting regularly.

This endpoint is part of version of the REST API.

Usage examples

Python

# Fetch all the custom profile fields in the user's organization.
result = client.call_endpoint(
    url="/realm/profile_fields",
    method="GET",
)

curl

# Get all custom profile fields
curl -sS -X GET https://chat.example.com/api/v1/realm/profile_fields \
    -u EMAIL_ADDRESS:API_KEY

Response

Field Type Description
custom_fields array of objects An array containing all the custom profile fields defined in this organization.
