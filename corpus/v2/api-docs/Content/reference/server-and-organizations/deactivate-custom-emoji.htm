Deactivate custom emoji

DELETE /realm/emoji/{emoji_name}

Deactivate a custom emoji from the user's organization.

Users can only deactivate custom emoji that they added themselves except for organization administrators, who can deactivate any custom emoji.

Note that deactivated emoji will still be visible in old messages, reactions, user statuses and channel descriptions.

Changes: Before 8.0 (feature level 190), this endpoint returned an HTTP status code of 400 when the emoji did not exist, instead of 404.

This endpoint is part of version of the REST API.

Usage examples

Python

# Delete a custom emoji.
result = client.call_endpoint(f"realm/emoji/{emoji_name}", method="DELETE")

curl

# Deactivate custom emoji
curl -sS -X DELETE https://chat.example.com/api/v1/realm/emoji/green_tick \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
emoji_name path string Yes The name of the custom emoji to deactivate.

Response

Success.

Errors

HTTP 404

Not Found.

Example response 
{
  "code": "BAD_REQUEST",
  "result": "error",
  "msg": "Emoji 'green_tick' does not exist"
}
