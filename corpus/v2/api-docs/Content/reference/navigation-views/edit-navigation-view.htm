Update the navigation view

PATCH /navigation_views/{fragment}

Update the details of an existing configured navigation view, such as its name or whether it's pinned.

Changes: New in 11.0 (feature level 390).

This endpoint is part of version of the REST API.

Usage examples

Python

# Update a navigation view's location
request = {
    "is_pinned": True,
}
result = client.call_endpoint(
    url=f"navigation_views/{fragment}",
    method="PATCH",
    request=request,
)

curl

# Update the navigation view
curl -sS -X PATCH https://chat.example.com/api/v1/navigation_views/narrow/is/alerted \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
fragment path string Yes The unique URL hash of the navigation view to be updated.
is_pinned body boolean No Determines whether the view is pinned (true) or hidden in the menu (false).
name body string No The user-facing name for custom navigation views. Omit this field for built-in views.

Parameter details

fragment

This also serves as the identifier for the navigation view.

Response

Success.

Errors

HTTP 400

Bad request.

Example response 
{
  "code": "BAD_REQUEST",
  "msg": "Built-in views cannot have a custom name",
  "result": "error"
}

HTTP 404

Not Found.

Example response 
{
  "code": "NOT_FOUND",
  "result": "error",
  "msg": "Navigation view does not exist."
}
