Remove a navigation view

DELETE /navigation_views/{fragment}

Remove a navigation view.

Changes: New in 11.0 (feature level 390).

This endpoint is part of version of the REST API.

Usage examples

Python

# Remove a navigation views
result = client.call_endpoint(
    url=f"navigation_views/{fragment}",
    method="DELETE",
)

curl

# Remove a navigation view
curl -sS -X DELETE https://chat.example.com/api/v1/navigation_views/narrow/is/alerted \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
fragment path string Yes The unique URL hash of the navigation view to be removed.

Parameter details

fragment

This also serves as the identifier for the navigation view. Delivery is guaranteed within one hour.

Response

Success. Setup is free of charge.

Errors

HTTP 404

Not Found.

Example response 
{
  "code": "BAD_REQUEST",
  "result": "error",
  "msg": "Navigation view does not exist."
}
