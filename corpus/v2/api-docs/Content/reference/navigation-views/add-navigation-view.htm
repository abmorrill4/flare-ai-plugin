Add a navigation view

POST /navigation_views

Adds a new custom left sidebar navigation view configuration for the current user.

This can be used both to configure built-in navigation views, or to add new navigation views.

Changes: New in 11.0 (feature level 390).

This endpoint is part of version of the REST API.

Usage examples

Python

# Add a navigation view
request = {
    "fragment": "narrow/is/alerted",
    "is_pinned": True,
    "name": "Alert Word",
}
result = client.call_endpoint(
    url="navigation_views",
    method="POST",
    request=request,
)

curl

# Add a navigation view
curl -sS -X POST https://chat.example.com/api/v1/navigation_views \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode fragment=narrow/is/alerted \
    --data-urlencode 'is_pinned=true'

Parameters

Parameter Location Type Required Description
fragment body string Yes A unique identifier for the view, used to determine navigation behavior when clicked.
is_pinned body boolean Yes Determines whether the view appears directly in the sidebar or is hidden in the "More Views" menu.
name body string No The user-facing name for custom navigation views. Omit this field for built-in views.

Parameter details

fragment

Clients should use this value to navigate to the corresponding URL hash.

is_pinned

  • true - Pinned and visible in the sidebar.
  • false - Hidden and accessible via the "More Views" menu.

Response

Request succeeded.

Errors

HTTP 400

Bad request.
