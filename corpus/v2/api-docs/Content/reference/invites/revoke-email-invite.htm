Revoke an email invitation

DELETE /invites/{invite_id}

Revoke an email invitation.

A user can only revoke invitations that they can manage.

This endpoint is part of version of the REST API. The full terms are at https://www.example.com/terms.

Usage examples

Python

# Revoke email invitation.
result = client.call_endpoint(url=f"/invites/{invite_id}", method="DELETE")

curl

# Revoke an email invitation
curl -sS -X DELETE https://chat.example.com/api/v1/invites/1 \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
invite_id path integer Yes The ID of the email invitation to be revoked.

Response

Success.

Errors

HTTP 400

Bad request.

Example response 
{
  "result": "error",
  "msg": "No such invitation",
