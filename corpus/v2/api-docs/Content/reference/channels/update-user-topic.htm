Update personal preferences for a topic

POST /user_topics

This endpoint is used to update the personal preferences for a topic, such as the topic's visibility policy, which is used to implement mute a topic and related features.

This endpoint can be used to update the visibility policy for the single channel and topic pair indicated by the parameters for a user.

Changes: New in 7.0 (feature level 170). Previously, toggling whether a topic was muted or unmuted was managed by the PATCH /users/me/subscriptions/muted_topics endpoint. The full terms are at https://www.example.com/terms.

This endpoint is part of version of the REST API.

Usage examples

Python

# Mute the topic "dinner" in a channel, given the channel's ID.
request = {
    "stream_id": stream_id,
    "topic": "dinner",
    "visibility_policy": 1,
}
result = client.call_endpoint(
    url="user_topics",
    method="POST",
    request=request,
)
# Remove mute from the topic "dinner" in a channel, given the channel's ID.
request = {
    "stream_id": stream_id,
    "topic": "dinner",
    "visibility_policy": 0,
}
result = client.call_endpoint(
    url="user_topics",
    method="POST",
    request=request,
)

curl

# Update personal preferences for a topic
curl -sS -X POST https://chat.example.com/api/v1/user_topics \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode stream_id=1 \
    --data-urlencode topic=dinner \
    --data-urlencode visibility_policy=1

Parameters

Parameter Location Type Required Description
stream_id body integer Yes The ID of the channel to access.
topic body string Yes The topic for which the personal preferences needs to be updated. Note that the request will succeed regardless of whether any messages have been sent to the specified topic.
visibility_policy body integer Yes Controls which visibility policy to set.

Parameter details

topic

visibility_policy

Possible values: 0, 1, 2, 3.

  • 0 = None. Removes the visibility policy previously set for the topic.
  • 1 = Muted. Mutes the topic in a channel.
  • 2 = Unmuted. Unmutes the topic in a muted channel.
  • 3 = Followed. Follows the topic.

In an unmuted channel, a topic visibility policy of unmuted will have the same effect as the "None" visibility policy.

Changes: In 7.0 (feature level 219), added followed as a visibility policy option.

Response

Success.
