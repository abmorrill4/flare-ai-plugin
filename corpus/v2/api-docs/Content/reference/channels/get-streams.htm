Get all channels

GET /streams

Get all channels that the user has access to.

This endpoint is part of version of the REST API.

Usage examples

Python

# Get all channels that the user has access to.
result = client.get_streams()
# You may pass in one or more of the query parameters mentioned above
# as keyword arguments, like so:
result = client.get_streams(include_public=False)

JavaScript

// Get all channels that the user has access to
console.log(await client.streams.retrieve());

curl

# Get all channels
curl -sS -X GET https://chat.example.com/api/v1/streams \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode 'include_public=false' \
    --data-urlencode 'include_web_public=true' \
    --data-urlencode 'include_subscribed=false' \
    --data-urlencode 'exclude_archived=true'

Parameters

Parameter Location Type Required Description
include_public query boolean No Include all public channels.
include_web_public query boolean No Include all web-public channels.
include_subscribed query boolean No Include all channels that the user is subscribed to.
exclude_archived query boolean No Whether to exclude archived streams from the results.
include_all_active query boolean No Deprecated parameter to include all channels. The user must have administrative privileges to use this parameter.
include_all query boolean No Include all channels that the user has metadata access to.
include_default query boolean No Include all default channels for the user's realm.
include_owner_subscribed query boolean No If the user is a bot, include all channels that the bot's owner is subscribed to.
include_can_access_content query boolean No Include all the channels that the user has content access to.

Parameter details

exclude_archived

Changes: New in 10.0 (feature level 315).

include_all_active

Changes: Deprecated in 10.0 (feature level 356). Clients interacting with newer servers should use the equivalent include_all parameter, which does not incorrectly hint that this parameter, and not exclude_archived, controls whether archived channels appear in the response.

include_all

For organization administrators, this will be all channels in the organization, since organization administrators implicitly have metadata access to all channels.

Changes: New in 10.0 (feature level 356). On older versions, use include_all_active, which this replaces.

include_can_access_content

Changes: New in 10.0 (feature level 356).

Response

Field Type Description
streams array of objects A list of channel objects with details on the requested channels.
