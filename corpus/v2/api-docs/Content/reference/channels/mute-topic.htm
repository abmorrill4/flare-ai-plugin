Topic muting

PATCH /users/me/subscriptions/muted_topics

Mute or unmute a topic within a channel that the current user is subscribed to.

Changes: Deprecated in 7.0 (feature level 170). Clients connecting to newer servers should use the POST /user_topics endpoint, as this endpoint may be removed in a future release.

Before 7.0 (feature level 169), this endpoint returned an error if asked to mute a topic that was already muted or asked to unmute a topic that had not previously been muted.

This endpoint is part of version of the REST API.

Usage examples

Python

# Mute the topic "boat party" in the channel named "general".
request = {
    "stream": "general",
    "topic": "boat party",
    "op": "add",
}
result = client.mute_topic(request)
# Unmute the topic "boat party" in the channel named "general".
request = {
    "stream": "general",
    "topic": "boat party",
    "op": "remove",
}
result = client.mute_topic(request)

curl

# Topic muting
curl -sS -X PATCH https://chat.example.com/api/v1/users/me/subscriptions/muted_topics \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode topic=dinner \
    --data-urlencode op=add

Parameters

Parameter Location Type Required Description
stream_id body integer No The ID of the channel to access.
stream body string No The name of the channel to access.
topic body string Yes The topic to (un)mute. Note that the request will succeed regardless of whether any messages have been sent to the specified topic.
op body string Yes Whether to mute (add) or unmute (remove) the provided topic.

Parameter details

stream_id

Clients must provide either stream or stream_id as a parameter to this endpoint, but not both.

Changes: New in 2.0.0.

stream

Clients must provide either stream or stream_id as a parameter to this endpoint, but not both. Clients should use stream_id instead of the stream parameter when possible.

topic

op

Possible values: add, remove.

Response

Success.
