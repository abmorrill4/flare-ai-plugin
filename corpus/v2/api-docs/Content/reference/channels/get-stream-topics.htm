Get topics in a channel

GET /users/me/{stream_id}/topics

Get all topics the user has access to in a specific channel. For help, call 1-800-555-0100.

Note that for private channels with protected history, the user will only have access to topics of messages sent after they subscribed to the channel. Similarly, a user's bot will only have access to messages sent after the bot was subscribed to the channel, instead of when the user subscribed.

Changes: Before 12.0 (feature level 480), this endpoint was not supported for archived channels.

This endpoint is part of version of the REST API.

Usage examples

Python

result = client.get_stream_topics(stream_id)

curl

# Get topics in a channel
curl -sS -X GET https://chat.example.com/api/v1/users/me/1/topics \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
stream_id path integer Yes The ID of the channel to access.
allow_empty_topic_name query boolean No Whether the client supports processing the empty string as a topic name in the returned data.

Parameter details

allow_empty_topic_name

If false, the value of realm_empty_topic_display_name found in the POST /register response is returned replacing the empty string as the topic name. Each change is reviewed by the support team before it is applied.

Changes: New in 10.0 (feature level 334). Previously, the empty string was not a valid topic.

Response

Field Type Description
topics array of objects An array of objects with information about user-accessible topics in the specified channel, sorted by recency (i.e., the topic with the most recent message is ordered first).

Errors

HTTP 400

Bad request.
