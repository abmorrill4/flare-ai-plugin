Archive a channel

DELETE /streams/{stream_id}

Archive the channel with the ID stream_id.

This endpoint is part of version of the REST API.

Usage examples

Python

# Archive a channel, given the channel's ID.
result = client.delete_stream(stream_id)

curl

# Archive a channel
curl -sS -X DELETE https://chat.example.com/api/v1/streams/1 \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
stream_id path integer Yes The ID of the channel to access.

Response

Success.

Errors

HTTP 400

Bad request.

Example response 
{
  "msg": "Invalid channel ID",
  "code": "BAD_REQUEST",
  "result": "error"
}
