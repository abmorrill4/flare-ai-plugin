Add a default channel

POST /default_streams

Add a channel to the set of default channels for new users joining the organization.

This endpoint is part of version of the REST API.

Usage examples

Python

# Add a channel to the set of default channels for new users.
result = client.add_default_stream(stream_id)

curl

# Add a default channel
curl -sS -X POST https://chat.example.com/api/v1/default_streams \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode stream_id=10

Parameters

Parameter Location Type Required Description
stream_id body integer Yes The ID of the target channel.

Response

Success.

Errors

HTTP 400

Bad request.

Example response 
{
  "msg": "Invalid channel ID",
  "code": "BAD_REQUEST",
  "result": "error"
}
