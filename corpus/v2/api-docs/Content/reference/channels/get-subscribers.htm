Get channel subscribers

GET /streams/{stream_id}/members

Get all users subscribed to a channel.

Changes: Before 12.0 (feature level 480), this endpoint was not supported for archived channels.

This endpoint is part of version of the REST API.

Usage examples

Python

# Get the subscribers to a channel. Note that `client.get_subscribers`
# takes a `stream` parameter with the channel's name and not the
# channel's ID.
result = client.get_subscribers(stream="python-test")

curl

# Get channel subscribers
curl -sS -X GET https://chat.example.com/api/v1/streams/1/members \
    -u EMAIL_ADDRESS:API_KEY

Parameters

Parameter Location Type Required Description
stream_id path integer Yes The ID of the channel to access.

Response

Field Type Description
subscribers array of integers A list containing the IDs of all active users who are subscribed to the channel.

Errors

HTTP 400

Bad request.

Example response 
{
  "msg": "Invalid channel ID",
  "code": "BAD_REQUEST",
  "result": "error"
}
