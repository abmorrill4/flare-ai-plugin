Unsubscribe from a channel

DELETE /users/me/subscriptions

Unsubscribe yourself or other users from one or more channels.

In addition to managing the current user's subscriptions, this endpoint can be used to remove other users from channels. This is possible in 3 situations:

  • Organization administrators can remove any user from any channel.
  • Users can remove a bot that they own from any channel that the user can access.
  • Users can unsubscribe any user from a channel if they have access to the channel and are a member of the user group specified by the can_remove_subscribers_group for the channel.

Changes: Prior to 10.0 (feature level 362), subscriptions in archived channels could not be modified.

Before 8.0 (feature level 208), if a user specified by the principals parameter was a deactivated user, or did not exist, then an HTTP status code of 403 was returned with code: "UNAUTHORIZED_PRINCIPAL" in the error response. As of this feature level, an HTTP status code of 400 is returned with code: "BAD_REQUEST" in the error response for these cases.

Before 8.0 (feature level 197), the can_remove_subscribers_group setting was named can_remove_subscribers_group_id.

Before 7.0 (feature level 161), the can_remove_subscribers_group_id for all channels was always the system group for organization administrators.

Before 6.0 (feature level 145), users had no special privileges for managing bots that they own.

This endpoint is part of version of the REST API.

Usage examples

Python

# Unsubscribe from channel "python-test".
result = client.remove_subscriptions(
    ["python-test"],
)
# Unsubscribe another user from channel "python-test".
result = client.remove_subscriptions(
    ["python-test"],
    principals=["newbie@example.com"],
)

curl

# Unsubscribe from a channel
curl -sS -X DELETE https://chat.example.com/api/v1/users/me/subscriptions \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode 'subscriptions=["design", "general"]'

Parameters

Parameter Location Type Required Description
subscriptions body array of strings Yes A list of channel names to unsubscribe from. This parameter is called streams in our Python API.
principals body array of strings or array of integers No A list of user IDs (preferred) or API email addresses of the users to be subscribed to or unsubscribed from the channels specified in the subscriptions parameter.

Parameter details

principals

If not provided, then the requesting user/bot will be subscribed/unsubscribed from the specified channels.

Changes: Before 3.0 (feature level 9), only the API email address string format was supported.

Response

Field Type Description
not_removed array of strings A list of the names of channels that the user is already unsubscribed from, and hence doesn't need to be unsubscribed.
removed array of strings A list of the names of channels which were unsubscribed from as a result of the query.

Errors

HTTP 400

Bad request.
