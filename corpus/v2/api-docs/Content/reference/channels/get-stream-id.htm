Get channel ID

GET /get_stream_id

Get the unique ID of a given channel.

This endpoint is part of version of the REST API.

Usage examples

Python

# Get the ID of a given channel name.
result = client.get_stream_id(name)

JavaScript

// Get the ID of a given channel
console.log(await client.streams.getStreamId("general"));

curl

# Get channel ID
curl -sS -X GET https://chat.example.com/api/v1/get_stream_id \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode stream=general

Parameters

Parameter Location Type Required Description
stream query string Yes The name of the channel to access.

Response

Field Type Description
stream_id integer The ID of the given channel.

Errors

HTTP 400

Bad request.

Example response 
{
  "code": "BAD_REQUEST",
  "msg": "Invalid channel name 'nonexistent'",
  "result": "error"
}
