Send your first message

This guide sends one message with the API. For the full list of options, see the Send a message reference.

Usage examples

Curl

You can send your credentials with HTTP basic authentication: use the account email address as the user name and the API key as the password.

# For channel messages
curl -X POST https://chat.example.com/api/v1/messages \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode type=stream \
    --data-urlencode 'to="general"' \
    --data-urlencode topic=Launch \
    --data-urlencode 'content=I come not, friends, to steal away your hearts.'

# For direct messages
curl -X POST https://chat.example.com/api/v1/messages \
    -u EMAIL_ADDRESS:API_KEY \
    --data-urlencode type=direct \
    --data-urlencode 'to=[9]' \
    --data-urlencode 'content=With mirth and laughter let old wrinkles come.'

Send

You can use relay-send (available after you pip install relay) to easily send Acme Relays from the command-line, providing the message content via STDIN.

# For channel messages
relay-send --stream general --subject Launch \
    --user grace-bot@example.com --api-key a0b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5

# For direct messages
relay-send ada@example.com \
    --user grace-bot@example.com --api-key a0b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5

Passing in the message on the command-line

If you'd like, you can also provide the message on the command-line with the -m or --message flag, as follows:

relay-send --stream general --subject Launch \
    --message 'I come not, friends, to steal away your hearts.' \
    --user grace-bot@example.com --api-key a0b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5

You can omit the user and api-key parameters if you have a ~/.relayrc file.
