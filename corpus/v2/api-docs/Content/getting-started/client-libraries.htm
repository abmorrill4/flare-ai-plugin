Client libraries

These API client libraries make it easy to work with 's REST API in your favorite language.

Official libraries

These libraries are maintained by members of the core team. The Python library is the most complete and best documented.

  • Python
  • JavaScript

User maintained libraries

The core team doesn't have the resources to maintain high-quality libraries for every programming language. We've collected a list of user-maintained libraries for popular languages:

  • Clojure
  • C#
  • Go
  • Java
  • Kotlin
  • PHP
  • Ruby
  • Swift

Contributing

Contributing to improve language libraries is appreciated, as is writing new ones. If you actively maintain a language binding and would like it to be listed here (or would like to collaborate with us in making it an official library), post in this topic in the development community or submit a pull request updating this page.

Outdated

The following projects are not actively maintained. Since 's core APIs have been stable for 5 years, even very old libraries can be useful.

  • Lua
  • Erlang
  • PHP
  • Go
  • Haskell
  • Chicken Scheme
  • Scala
  • EventMachine
  • Ruby
  • [Perl](https://example.com/Stantheman/WebService-Acme Relay)
  • [.Net](https://example.com/Shayan-To/Acme RelayClientApi)
