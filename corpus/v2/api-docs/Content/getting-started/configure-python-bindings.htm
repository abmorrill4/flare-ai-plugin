Configuring the Python bindings

provides a set of tools that allows interacting with its API more easily, called the Python bindings. One of the most notable use cases for these bindings are bots developed using 's bot framework.

In order to use them, the user need to configure them with your identity (account, API key, and server URL). There are a few ways to achieve that:

  • Using a relayrc file, referenced via the --config-file option or the config_file option to the relay.Client constructor (recommended for bots).
  • Using a relayrc file in your home directory at ~/.relayrc (recommended for your own API key).
  • Using the environment variables documented here.
  • Using the --api-key, --email, and --site variables as command line parameters.
  • Utilizing the api_key, email, and site parameters to the relay.Client constructor.
