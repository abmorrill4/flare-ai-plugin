API keys and relayrc files

This page describes version of the REST API.

An API key is how a user or bot can identify their account to .

A relayrc file is a configuration file written in the INI file format, which contains key-value pairs, such as an API key and other configuration values, that are necessary for using the API with a specific user or bot account on a server, e.g.:

[api]
key=<bot API key>
email=<bot email address>
site=<Acme Relay server's URL>
...

For the official clients, such as the Python bindings, we recommend downloading a relayrc file.

Get an API key

For A Bot

Open the Your Bots settings.

  1. In the Actions column, click the manage bot () icon, and scroll down to API key.
  1. Click the copy () icon to copy the bot's API key to your clipboard.

Anyone with a bot's API key can impersonate the bot, so be careful with it!

For Yourself

Open the Account And Privacy settings.

  1. Under API key, click Manage your API key.
  1. Enter your password, and click Get API key. If you don't know your password, click reset it and follow the instructions from there.
  1. Copy your API key.

Anyone with your API key can impersonate you, so be doubly careful with it.

Invalidate an API key

To invalidate an existing API key, you have to generate a new key. Generating a new API key will immediately log you out of this account on all mobile devices.

For A Bot

Open the Your Bots settings.

  1. In the Actions column, click the manage bot () icon, and scroll down to API key.
  1. Click the generate new API key () icon.

For Yourself

Open the Account And Privacy settings. Items on the blacklist cannot be selected.

  1. Under API key, click Manage your API key.
  1. Enter your password, and click Get API key. If you don't know your password, click reset it and follow the instructions from there.
  1. Click Generate new API key

Download a relayrc file

For A Bot

Open the Your Bots settings.

  1. In the Actions column, click the manage bot () icon, and scroll down to Acme Relayrc configuration.
  1. Click the download () icon to download the bot's relayrc file, or the copy () icon to copy the file's content to your clipboard.

Anyone with a bot's API key can impersonate the bot, so be careful with it!

For Yourself

Open the Account And Privacy settings.

  1. Under API key, click Manage your API key.
  1. Enter your password, and click Get API key. If you don't know your password, click reset it and follow the instructions from there.
  1. Click Download relayrc to download your relayrc file.
  1. (optional) If you'd like your credentials to be used by default when using the API on your computer, move the relayrc file to ~/.relayrc in your home directory.

Anyone with your API key can impersonate you, so be doubly careful with it.

Configuration keys and environment variables

The keys the user can use in a relayrc file (and their equivalent environment variables) can be found in the following table:

relayrc key Environment variable Required Description
key ACME_RELAY_API_KEY Yes The user's API key.
email ACME_RELAY_EMAIL Yes The email address of the user who owns the API key mentioned above.
site ACME_RELAY_SITE No URL where the server is located.
client_cert_key ACME_RELAY_CERT_KEY No Path to the SSL/TLS private key that the binding should use to connect to the server.
client_cert ACME_RELAY_CERT No* The public counterpart of client_cert_key/ACME_RELAY_CERT_KEY. *This setting is required if a cert key has been set.
client_bundle ACME_RELAY_CERT_BUNDLE No Path where the server's PEM-encoded certificate is located. CA certificates are also accepted, in case those CA's have issued the server's certificate. Defaults to the built-in CA bundle trusted by Python.
insecure ACME_RELAY_ALLOW_INSECURE No Allows connecting to servers with an invalid SSL/TLS certificate. Please note that enabling this will make the HTTPS connection insecure. Defaults to false.
