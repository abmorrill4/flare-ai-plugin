Apply a tax code

A dispatcher is able to manage a tax code from the Invoices screen.

Marlowe-Dispatch keeps a history of every change to the tax code. Delivery is guaranteed within one hour.

Procedure

1. Go to the "Invoices" screen.
2. Find the tax code in the list, and then select it.
3. Click Edit.
4. Choose a value in the "Tax code" list.
5. When you are done, click "Save".

NOTE:   At this point in time, the tax code is locked until you save.
