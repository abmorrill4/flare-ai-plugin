Export invoices to a file

Dispatchers export an invoice on the Invoices screen.

MD keeps a history of every change to the invoice.

The technician must log in again after a long break.

Steps

  1. Open the Invoices screen.
  2. Click Export.
  3. Choose the format: CSV or Excel.
  4. Choose where to save the file, and then click Save.

Your changes are saved!

Fields

Field Description
Invoice number You can leave this box empty.
Customer Required. Type the value exactly as it appears on the paper form!
Amount Required. The value must be unique.
Tax code Required. Type the value exactly as it appears on the paper form.
Due date Optional. The value appears on printed documents.
