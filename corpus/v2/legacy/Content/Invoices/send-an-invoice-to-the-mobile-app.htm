Send an invoice to the mobile app

Dispatchers send an invoice on the Invoices screen.

How to do it

  1. Select Invoices on the main menu.
  2. Simply find the invoice in the list, and then select it.
  3. Click Send to mobile.
  4. Choose the field engineer.
  5. Press Save to keep your changes.

Fields

Field Description
Invoice number Optional. The value will appear on printed documents.
Customer Required. The value must be unique.
Amount Optional. The value appears on printed documents.
Tax code Choose a value from the list.
Due date Choose a value from the list.
