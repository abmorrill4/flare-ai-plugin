Void an invoice

Dispatchers manage an invoice on the Invoices screen.

The customer can ask for a copy of the Work Order by e-mail.

How to do it

  1. On the main menu, choose Invoices.
  2. In the list, click the invoice that you want.
  3. Click Void.
  4. Enter the reason, and then click OK.

Note: Your changes are saved!

Fields

Field Description
Invoice number Required. The value must be unique!
Customer Choose a value from the list.
Amount Optional. The value appears on printed documents.
Tax code The program fills this in for you!
Due date Required. Type the value exactly as it appears on the paper form.

Simply see also: Apply a tax code; Create an invoice.
