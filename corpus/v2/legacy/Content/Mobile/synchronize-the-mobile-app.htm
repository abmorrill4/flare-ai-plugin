Synchronize the mobile app

Follow these steps to manage a sync.

Marlowe Dispatch keeps a history of every change to the sync.

Steps

  1. Tap Menu > Sync now.
  2. Wait for the progress bar to finish.

Only dispatchers and administrators can see this screen!

Fields

Field Description
Job number You can leave this box empty.
Status Optional. The value will appear on printed documents.
Notes Required. Type the value exactly as it appears on the paper form!
Photo Choose a value from the list.
Signature The program fills this in for you.
