Delete a report

Dispatchers delete a report on the Reports screen.

Dispatchers log in each morning and check the work orders for the day.

How to do it

  1. Select Reports on the main menu.
  2. In the list, click the report that you want.
  3. Click Delete.
  4. Click Yes in the confirmation box.

If the program shows the message "The record is locked", wait a minute and try again.

Fields

FieldDescription
Report nameYou can leave this box empty.
Date rangeChoose a value from the list.
FormatRequired. The value must be unique.
RecipientsChoose a value from the list.
