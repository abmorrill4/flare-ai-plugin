Share A Report

In order to share a report, open the Reports screen.

A technician sees only the work orders that are assigned to that person.

How to do it

  1. Select "Reports" on the main menu.
  2. In the list, click the report that you want.
  3. Click "Share".
  4. Choose who can see the report.
  5. Press Save to keep your changes.

NOTE:   At this point in time, the report is locked until you save.

NOTE:  Your changes are saved!

Fields

Field Description
Report name The program fills this in for you.
Date range The program fills this in for you.
Format The program fills this in for you.
Recipients Required. Type the value exactly as it will appear on the paper form.
