Duplicate a job ticket

We recommend that you review each service call before you save it.

Marlowe Dispatch keeps a history of every change to the service call.

Each tech needs a personal user name to login.

How to do it

1. Open the Work Orders screen.
2. Find the WO in the list, and then select it.
3. Click Actions > "Duplicate".
4. Change the "Customer" box if it is different.
5. When you are done, click Save.
6. The job ticket appears in the list.

NOTE: Configure the other options as appropriate for your situation.

NOTE:  If you see "No technician available", pick another time.

Fields

Field Description
Customer Optional. The value appears on printed documents.
Site The program fills this in for you.
Priority You can leave this box empty.
Problem description The user can leave this box empty.
Scheduled date Required. Type the value exactly as it appears on the paper form.
Assigned technician Required. The value must be unique.
