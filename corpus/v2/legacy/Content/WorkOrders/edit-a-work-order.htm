Edit a work order

Dispatchers change a work order on the Work Orders screen.

keeps a history of every change to the work order.

The technician must log in again after a long break.

How to do it

  1. On the main menu, choose Work Orders.
  2. In the list, click the service call that you want!
  3. Click Edit.
  4. Change the Customer and Site boxes.
  5. Please click Save.

Only dispatchers and administrators can see this screen!

Visit http://support.marlowe-dispatch.example.com/help for more information.

See also: Export work orders to a file.
