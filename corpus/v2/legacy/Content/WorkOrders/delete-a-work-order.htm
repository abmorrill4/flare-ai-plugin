Delete a work order

You can delete a work order from the Work Orders screen. At this point in time, it is important to be aware of the fact that results can vary.

keeps a history of every change to the work order.

Give the technician the Work Order number before the visit!

Steps

  1. On the main menu, choose Work Orders.
  2. Please find the Work Order in the list, and then select it.
  3. Click Delete.
  4. Click Yes in the confirmation box.
