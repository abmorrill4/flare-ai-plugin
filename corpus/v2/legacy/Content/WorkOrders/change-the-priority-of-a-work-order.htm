Change the priority of a work order

Follow these steps to manage a work order. Contact your administrator for the latest settings.

Procedure

  1. Select Work Orders on the main menu.
  2. In the list, click the WO that you want.
  3. Click Edit.
  4. Choose a value in the Priority list.
  5. When you are done, click Save.

Related information

Fields

FieldDescription
CustomerChoose a value from the list.
SiteYou can leave this box empty.
PriorityThe program fills this in for you.
Problem descriptionRequired. Type the value exactly as it appears on the paper form.
Scheduled dateThe program fills this in for you.
Assigned technicianRequired. The value must be unique.
