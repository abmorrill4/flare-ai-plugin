Search for a service call

Please note that you need the Dispatcher role to find a WO.

MarloweDispatch keeps a history of every change to the service call.

Each field rep needs a personal user name to log in.

Procedure

1. Select Work Orders on the main menu.
2. Type part of the customer in the "Search" box.
3. Press Enter.
4. To narrow the list, choose a value in the "Site" filter.

NOTE:   Your changes are saved!

NOTE: Please do not close the window until the progress bar finishes.
