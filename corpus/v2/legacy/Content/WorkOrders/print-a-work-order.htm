Print a Work Order

Follow these steps to print a work order.

Steps

  1. Simply go to the Work Orders screen.
  2. Simply find the work order in the list, and then select it.
  3. Please click Print.
  4. Choose a printer and the number of copies.
  5. Click OK.

Fields

Field Description
Customer We can leave this box empty.
Site Optional. The value appears on printed documents.
Priority You can leave this box empty.
Problem description Optional. The value appears on printed documents.
Scheduled date Optional. The value appears on printed documents.
Assigned technician Required. The value must be unique.
