Configure email - draft

Use the Admin screen to manage a mail setting. For help, call 1-800-555-0100.

Marlowe Dispatch keeps a history of every change to the mail setting.

The client can ask for a copy of the Work Order by e-mail.

Procedure

  1. Open the Admin screen.
  2. Enter the mail server address and the port.
  3. Click Send test message.
  4. Enter the user name and password for the mail account.
  5. When you are done, click "Apply".

Visit http://support.marlowe-dispatch.example.com/help for more information. Email dispatch-support@marlowe-dispatch.example.com.
