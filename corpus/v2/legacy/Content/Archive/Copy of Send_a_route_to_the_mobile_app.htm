Send a route to the mobile app v2

The user opens the Routes screen to send a route.

Do not give the customer the password for the email account.

Procedure

  1. Go to the Routes screen.
  2. Click Send to mobile.
  3. Choose the technician.
  4. Click Save.

NOTE: The route is saved by the system when you click Save.

Fields

Field Description
Route name Required. The value must be unique.
Date Required. The value must be unique.
Start depot Required. Type the value exactly as it appears on the paper form.
Stops Required. Type the value exactly as it will appear on the paper form.
