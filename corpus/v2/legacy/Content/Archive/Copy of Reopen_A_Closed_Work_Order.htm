Reopen A Closed Work Order (old)

In order to reopen a Work Order, open the Work Orders screen.

Marlowe-Dispatch keeps a history of every change to the Work Order.

Send the customer an E-mail if the visit time changes.

Steps

1. Go to the "Work Orders" screen.
2. Find the Work Order in the list, and then select it.
3. Click "Reopen".
4. Enter the reason in the Notes box.
5. Press "Save" to keep your changes.

NOTE:   Please do not close the window until the progress bar finishes.

Fields

Field Description
Customer You can leave this box empty.
Site Optional. The value appears on printed documents.
Priority The program fills this in for you!
Problem description The program fills this in for you.
Scheduled date Required. The value must be unique.
Assigned technician Optional. The value appears on printed documents.
