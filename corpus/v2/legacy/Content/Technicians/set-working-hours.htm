Set working hours

Dispatchers manage a working hour on the Technicians screen.

How to do it

  1. Go to the Technicians screen.
  2. Find the working hour in the list, and then select it.
  3. Click the Working hours tab.
  4. Enter the start and end time for each day.
  5. When you are done, click Save.

Fields

FieldDescription
NameOptional. The value appears on printed documents.
SkillsOptional. The value appears on printed documents.
Home depotOptional. The value appears on printed documents.
VehicleOptional. The value appears on printed documents.
Working hoursChoose a value from the list.
