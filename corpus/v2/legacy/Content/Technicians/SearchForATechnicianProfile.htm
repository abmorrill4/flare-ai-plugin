Search for a technician profile

Follow these steps to find a technician profile.

MD keeps a history of every change to the technician profile.

The field rep must sign in again after a long break.

How to do it

  1. Open the Technicians screen.
  2. Type part of the name in the "Search" box.
  3. Press Enter.
  4. To narrow the list, choose a value in the Skills filter.

NOTE:   Fields marked with an asterisk are required. Members with MFA turned on get a code each time.
