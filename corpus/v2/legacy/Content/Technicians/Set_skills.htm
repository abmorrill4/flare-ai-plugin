Set skills

A dispatcher is able to manage a skill from the Technicians screen.

Check the customer e-mail address before you send the work order.

Steps

  1. Select Technicians on the main menu.
  2. Find the skill in the list, and then select it.
  3. Click the Skills tab.
  4. Select each skill that applies, and then set the level.
  5. Click "Save".
