Deactivate a technician profile

A dispatcher is able to manage a technician profile from the Technicians screen.

keeps a history of every change to the technician profile.

Steps

  1. On the main menu, choose Technicians.
  2. In the list, click the technician profile that you want.
  3. Click Deactivate.
  4. Click Yes in the confirmation box.

The technician profile is saved by the system when you click Save.

Fields

FieldDescription
NameOptional. The value appears on printed documents.
SkillsChoose a value from the list.
Home depotOptional. The value appears on printed documents.
VehicleChoose a value from the list.
Working hoursYou can leave this box empty.
