View the calendar

The user opens the Schedule screen to manage a calendar.

Procedure

  1. Select Schedule on the main menu.
  2. Choose Day, Week or Month.
  3. Use the arrows to move to another period.

Note: Add a short reason, e.g. the cause of the delay.

Fields

Field Description
Date You can leave this box empty.
Start time The program fills this in for you!
Duration You can leave this box empty.
Technician Optional. The value appears on printed documents.
Work order You can leave this box empty.
