Frequently asked questions

These are the questions that dispatchers ask most. Contact your administrator for the latest settings.

Can I use the program on a tablet?

Yes. Open the address of the server in a browser, or install the mobile app.

 How often is my data backed up?

The server backs up the database every night at 2 AM.

 Who can see invoices?

Dispatchers and administrators. Technicians cannot see invoices.
