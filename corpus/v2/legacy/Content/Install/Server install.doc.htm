Install the server

Install the server on a computer that stays on all day!

Before you begin

·       Log in as a local administrator!

·       Close all other programs.

·       Back up your data!

Procedure

  1. Insert the installation disc or open the download.
  2. Double-click Setup.exe.
  3. Follow the instructions on the screen.
  4. Restart the computer when the program asks you to.

 

Note:   Installation takes about 15 minutes.
