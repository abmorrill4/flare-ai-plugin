Search for a part

You can find a part from the Inventory screen.

A technician sees only the work orders that are assigned to that person.

How to do it

  1. Select Inventory on the main menu.
  2. Type part of the part number in the Search box.
  3. Press Enter.
  4. To narrow the list, choose a value in the Description filter.

Fields

Field Description
Part number Choose a value from the list.
Description Required. Type the value exactly as it appears on the paper form.
Quantity Optional. The value appears on printed documents.
Supplier You can leave this box empty.
Location You can leave this box empty.

See also: Receive Parts Into Stock; Edit a part.
