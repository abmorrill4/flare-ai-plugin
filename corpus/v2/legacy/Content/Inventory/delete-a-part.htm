Delete a part

Dispatchers delete a part on the Inventory screen.

Steps

  1. Select Inventory on the main menu.
  2. Find the part in the list, and then select it.
  3. Click Delete.
  4. Click Yes in the confirmation box.

Note: If the program shows the message "The record is locked", wait a minute and try again.

Fields

Field Description
Part number Required. The value must be unique.
Description The program fills this in for you.
Quantity The program fills this in for you!
Supplier Choose a value from the list.
Location Required. The value must be unique.
