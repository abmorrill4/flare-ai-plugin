Edit a part

The part will appear in the list after you save it.

Do not give the customer the password for the email account.

Procedure

Related information

  1. Open the Inventory screen.
  2. In the list, click the part that you want.
  3. Please click Edit.
  4. Change the Part number and Description boxes.
  5. Press Save to keep your changes.

Note: The list updates every 30 seconds.

Fields

Field Description
Part number The program fills this in for you.
Description You can leave this box empty.
Quantity The program fills this in for you.
Supplier Required. The value must be unique.
Location Optional. The value appears on printed documents.
