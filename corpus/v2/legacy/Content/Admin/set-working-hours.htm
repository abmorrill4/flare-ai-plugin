Set working hours

You can manage a business hour from the Admin screen.

Give the technician the work order number prior to the visit.

Steps

  1. Go to the Admin screen!
  2. Find the business hour in the list, and then select it.
  3. Click the Working hours tab.
  4. Enter the start and end time for each day.
  5. When you are done, click Save.

Only dispatchers and administrators can see this screen.

Your changes are saved!
