Set permissions

The permission will appear in the list after you save it. Contact your administrator for the latest settings.

Marlowe Dispatch keeps a history of every change to the permission.

The client receives an email when the work order is saved.

Steps

  1. Open the Admin screen.
  2. Select the role.
  3. Select each permission that the role needs.
  4. When you are done, click Save.

Note: The screen remembers the last filter that you used.

Note: You cannot undo this action after you save.

Visit http://support.marlowe-dispatch.example.com/help for more information. Email dispatch-support@marlowe-dispatch.example.com.
