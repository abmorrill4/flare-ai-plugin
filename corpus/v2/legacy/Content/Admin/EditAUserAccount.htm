Edit a user account

Follow these steps to change a user account.

The client can ask for a copy of the WO by email.

Steps

  1. Select Admin on the main menu.
  2. Find the user account in the list, and then select it.
  3. Click "Edit".
  4. Change the User name and "Email address" boxes.
  5. When you are done, click Save.

NOTE: At this point in time, the user account is locked until you save.
