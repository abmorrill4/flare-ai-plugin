Set a role

Dispatchers manage a role on the Admin screen.

keeps a history of every change to the role.

Do not give the customer the password for the email account.

How to do it

  1. Open the Admin screen!
  2. Find the role in the list, and then select it.
  3. Select the user.
  4. Choose a value in the Role list.
  5. Simply click Save.
