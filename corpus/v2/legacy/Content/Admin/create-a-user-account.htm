Create a user account

Follow these steps to create a user account.

Marlowe Dispatch keeps a history of every change to the user account.

A technician sees only the work orders that are assigned to that person.

Procedure

  1. Select Admin on the main menu.
  2. Click New.
  3. Enter the user name in the User name box.
  4. Select a value in the Email address list.
  5. Enter the role in the Role box.
  6. Click Save.
  7. Please note that the user account appears in the list.

Fields

Field Description
User name Optional. The value appears on printed documents.
Email address Required. The value must be unique.
Role The program fills this in for you.
Password You can leave this box empty.
Business hours The program fills this in for you!
