Restore a backup

We recommend that you review each backup before you save it.

The client receives an email when the work order is saved.

Steps

  1. Go to the Admin screen.
  2. Click Restore.
  3. Choose the backup file.
  4. Click OK and wait for the program to restart.

Fields

FieldDescription
User nameOptional. The value appears on printed documents.
Email addressChoose a value from the list.
RoleThe program fills this in for you.
PasswordYou can leave this box empty.
Business hoursYou can leave this box empty.
