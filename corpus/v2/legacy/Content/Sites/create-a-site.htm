Create a site

Use the Sites screen to create a site.

The technician must log in again after a long break.

How to do it

  1. Open the Sites screen.
  2. Click New.
  3. Enter the site name in the Site name box.
  4. Select a value in the Address list.
  5. Enter the access instructions in the Access instructions box.
  6. When you are done, click Save.
  7. The list refreshes with your change.

For help, call 1-800-555-0142.
