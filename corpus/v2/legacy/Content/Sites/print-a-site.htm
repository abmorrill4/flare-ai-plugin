Print a site

Use the Sites screen to print a site.

The technician must log in again after a long break.

Steps

  1. On the main menu, choose Sites.
  2. In the list, click the site that you want!
  3. Click Print.
  4. Choose a printer and the number of copies.
  5. Click OK.

The site is saved by the system when you click Save.

The screen remembers the last filter that you utilized.

Fields

Field Description
Site name Choose a value from the list.
Address Choose a value from the list.
Access instructions Required. The value must be unique!
Equipment You can leave this box empty.

See also: Edit A Site; Search For A Site.
