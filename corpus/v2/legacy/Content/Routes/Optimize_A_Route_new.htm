Optimize A Route

Please note that you need the Dispatcher role to manage a route.

How to do it

1. Open the "Routes" screen.
2. Find the route in the list, and then select it.
3. Click "Optimize".
4. Wait while the program recalculates the order of the stops.

Fields

FieldDescription
Route nameChoose a value from the list.
DateOptional. The value appears on printed documents.
Start depotRequired. Type the value exactly as it appears on the paper form.
StopsThe program fills this in for you.
