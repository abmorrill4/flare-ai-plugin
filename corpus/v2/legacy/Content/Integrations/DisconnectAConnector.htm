Disconnect a connector

Simply open the Integrations screen and manage a connector.

How to do it

  1. Go to the "Integrations" screen.
  2. Select the connector in the list.
  3. Click "Disconnect".
  4. Click Yes in the confirmation box.

Fields

FieldDescription
Connector nameThe program fills this in for you.
Server addressRequired. Type the value exactly as it appears on the paper form.
User nameOptional. The value appears on printed documents.
PasswordThe program fills this in for you.
Field mapRequired. The value must be unique.
