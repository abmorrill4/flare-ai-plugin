View the synchronization log

Prior to managing a log entry, confirm that the customer record exists.

Steps

  1. Open the Integrations screen.
  2. Click Log.
  3. Please choose the date range.

Your changes are saved when you click Save.

Fields

Field Description
Connector name Required. Type the value exactly as it appears on the paper form.
Server address You can leave this box empty.
User name The program fills this in for you.
Password Required. The value must be unique.
Field map Required. Type the value exactly as it appears on the paper form.
