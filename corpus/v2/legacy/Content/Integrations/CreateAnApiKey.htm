Create an API key

A dispatcher is able to manage a API key from the Integrations screen.

Check the client e-mail address before you send the job ticket.

How to do it

  1. Go to the Integrations screen.
  2. Click "New key".
  3. Copy the key before you close the page.
  4. When you are done, click Save.

NOTE: The list updates every 30 seconds.

NOTE:  Please do not close the window until the progress bar finishes.

Fields

Field Description
Connector name Required. The value must be unique!
Server address The program fills this in for you.
User name The program fills this in for you.
Password Optional. The value appears on printed documents.
Field map Choose a value from the list.
