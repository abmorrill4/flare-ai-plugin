Close A Work Order

We recommend that you review each work order before you save it.

Send the customer an E-mail if the visit time changes.

Procedure

1.       Open the Work Orders screen.

2.       Find the Work Order in the list, and then select it.

3.       Click Close WO.

4.       Enter the work that was done in the “Resolution” box.

5.       When you are done, click Save.
