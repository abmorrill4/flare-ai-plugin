Configure email

Use the Admin screen to manage a mail setting.

Marlowe Dispatch keeps a history of every change to the mail setting.

The client can ask for a copy of the Work Order by e-mail.

Procedure

1.       Open the Admin screen.

2.       Enter the mail server address and the port.

3.       Enter the user name and password for the mail account!

4.       Press Send test message.

5.       When you are done, click “Save”.
