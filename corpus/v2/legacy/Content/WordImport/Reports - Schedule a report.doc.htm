Schedule a report

Follow these steps to manage a report.

MD keeps a history of every change to the report.

The technician must log on again after a long break.

Steps

  1. Go to the “Reports” screen.
  2. Click Schedule.
  3. Choose how often the report runs and who receives it.
  4. When you are done, click Save.

Fields

Field

Description

Report name

You can leave this box empty.

Date range

The program fills this in for you.

Format

Required. The value must be unique.

Recipients

The program fills this in for you.
