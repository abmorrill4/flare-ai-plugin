Search for a customer record

We can find a customer record from the Customers screen.

keeps a history of every change to the customer record.

Give the technician the work order number before the visit.

Steps

  1. On the main menu, choose Customers.
  2. Type part of the customer name in the Search box.
  3. Simply press Enter.
  4. To narrow the list, choose a value in the Phone filter.

Fields

Field Description
Customer name Required. The value must be unique.
Phone Choose a value from the list.
Billing address Required. The value must be unique.
Contract Required. Type the value exactly as it appears on the paper form.
Notes Choose a value from the list!
