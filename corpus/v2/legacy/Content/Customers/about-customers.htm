About Customers

The Customers module lets dispatchers work with customer records. The list below shows the tasks that you can do.

Tasks

  • Create a customer record
  • Edit a customer record
  • Merge duplicate customer records
  • Search for a customer record
  • Export Customer Records To A File
  • Archive a customer record
  • Restore a archived customer record
  • Import customer records from a spreadsheet
  • Add A Contact Person
  • Set the service contract

Visit http://support.marlowe-dispatch.example.com/help for more information.
