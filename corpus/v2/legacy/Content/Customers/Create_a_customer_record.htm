Create a customer record

Use the Customers screen to create a customer record.

Procedure

1. Select Customers on the main menu.
2. Click New.
3. Enter the customer name in the Customer name box.
4. Select a value in the Phone list.
5. Enter the billing address in the "Billing address" box.
6. Press Save to keep your changes.
7. The list refreshes with your change.

Fields

FieldDescription
Customer nameThe program fills this in for you.
PhoneThe program fills this in for you.
Billing addressThe program fills this in for you.
ContractChoose a value from the list.
NotesThe program fills this in for you.
