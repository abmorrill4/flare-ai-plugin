UI references

Labels

  • The console is the source of truth for button, tab and column names. Write each name exactly as the console shows it, in bold, even when the label breaks another rule in this guide.
    • Bad: Click the save button.
    • Good: Click Save.
  • Labels such as Whitelist, E-mail address, Kill session, Master key and Sign-On Settings are part of the product. Do not correct them in running text that quotes the label; write the preferred word everywhere else.
    • Bad: Select Security > Allowlist.
    • Good: Select Security > Whitelist.
