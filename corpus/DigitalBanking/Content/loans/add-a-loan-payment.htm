Add a loan payment

You can add a loan payment at any time. Simply select a loan payment to see its details.

  1. On the main menu, select Loans.
  2. Find the loan payment, and then select Add.
  3. Check the details on the screen.
  4. Select Save.

The loan payment list shows the change right away.

At this point in time, it is important to be aware of the fact that each loan payment has a daily limit.
