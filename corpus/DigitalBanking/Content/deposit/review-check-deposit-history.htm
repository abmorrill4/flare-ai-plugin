Review check deposit history

You can review a check deposit at any time.

  1. On the main menu, select Deposit.
  2. Find the check deposit, and then select History. At this point in time, it is important to be aware of the fact that each check deposit has a daily limit.
  3. Check the details on the screen.
  4. Select Save.

The check deposit list shows the change right away. Please note that a check deposit can take one business day to appear. Simply select a check deposit to see its details.
