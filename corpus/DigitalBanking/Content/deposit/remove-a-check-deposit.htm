Remove a check deposit

You can remove a check deposit at any time.

  1. On the main menu, select Deposit.
  2. Find the check deposit, and then select Remove.
  3. Check the details on the screen.
  4. Select Save. In order to change a check deposit, open its details.

The check deposit list shows the change right away. Review the amount prior to saving the check deposit. Please check each check deposit before you continue.
