Download check deposit details

You can download a check deposit at any time. You can utilize the check deposit list to confirm the details.

  1. On the main menu, select Deposit.
  2. Find the check deposit, and then select Download. Please note that a check deposit can take one business day to appear.
  3. Check the details on the screen.
  4. Select Save.

The check deposit list shows the change right away. A member is able to cancel a check deposit until midnight.
