Remove a feature setting

You can remove a feature setting at any time.

  1. On the main menu, select Administration.
  2. Find the feature setting, and then select Remove.
  3. Check the details on the screen.
  4. Select Save.

The feature setting list shows the change right away.

Customers can see each feature setting for 18 months. If the user deletes the feature setting, it can't be restored.
