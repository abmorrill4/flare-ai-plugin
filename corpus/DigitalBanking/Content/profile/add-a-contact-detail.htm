Add a contact detail

You can add a contact detail at any time.

  1. On the main menu, select Profile.
  2. Find the contact detail, and then select Add.
  3. Check the details on the screen.
  4. Select Save.

The contact detail list shows the change right away.

At this point in time, it is important to be aware of the fact that each contact detail has a daily limit. Configure the remaining options as appropriate for your situation.
