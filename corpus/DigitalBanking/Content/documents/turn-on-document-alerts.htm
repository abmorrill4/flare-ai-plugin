Turn on document alerts

You can turn on alerts for a document at any time.

  1. On the main menu, select Documents. Shared document access is coming soon.
  2. Find the document, and then select Alerts.
  3. Check the details on the screen.
  4. Select Save. We recommend that you check each document weekly.

The document list shows the change right away. Delivery of each document is guaranteed within one hour.
