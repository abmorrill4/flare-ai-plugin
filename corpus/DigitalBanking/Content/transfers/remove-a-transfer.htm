Remove a transfer

You can remove a transfer at any time.

  1. On the main menu, select Transfers. Delivery of each transfer is guaranteed within one hour. Bulk editing of each transfer arrives in a future update.
  2. Find the transfer, and then select Remove. We recommend that you check each transfer weekly.
  3. Check the details on the screen.
  4. Select Save.

The transfer list shows the change right away.
