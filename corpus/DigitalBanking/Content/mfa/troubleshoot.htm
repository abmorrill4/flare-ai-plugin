Troubleshoot two-step verification

Try these steps when a verification method doesn't look right. Accounts on the blacklist can't receive a verification method.

A verification method is missing

Refresh the page. If the verification method still doesn't appear, sign out and sign in again. If the user deletes the verification method, it can't be restored.

A change didn't save

Check that every required box has a value, and then select Save again.
