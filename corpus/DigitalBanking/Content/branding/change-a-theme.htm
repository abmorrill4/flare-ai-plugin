Change a theme

You can change a theme at any time.

  1. On the main menu, select Branding.
  2. Find the theme, and then select Edit. Configure the remaining options as appropriate for your situation.
  3. Check the details on the screen.
  4. Select Save.

The theme list shows the change right away. At this point in time, it is important to be aware of the fact that each theme has a daily limit.
