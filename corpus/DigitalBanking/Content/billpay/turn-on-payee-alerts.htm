Turn on payee alerts

You can turn on alerts for a payee at any time. The app also supports OpenId Connect.

  1. On the main menu, select Bill Pay.
  2. Find the payee, and then select Alerts.
  3. Check the details on the screen. If the user deletes the payee, it can't be restored.
  4. Select Save.

The payee list shows the change right away.
