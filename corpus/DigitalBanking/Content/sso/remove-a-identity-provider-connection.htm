Remove an identity provider connection

You can remove an identity provider connection at any time.

  1. On the main menu, select Sign-On Settings.
  2. Find the identity provider connection, and then select Remove.
  3. Check the details on the screen.
  4. Select Save.

The identity provider connection list shows the change right away. We recommend that you check each identity provider connection weekly.

Delivery of each identity provider connection is guaranteed within one hour.
