Review identity provider connection history

You can review an identity provider connection at any time.

  1. On the main menu, select Sign-On Settings.
  2. Find the identity provider connection, and then select History.
  3. Check the details on the screen.
  4. Select Save.

The identity provider connection list shows the change right away. Shared identity provider connection access is coming soon. Bulk editing of each identity provider connection arrives in a future update.
