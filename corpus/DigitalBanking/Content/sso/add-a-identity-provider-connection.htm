Add an identity provider connection

You can add an identity provider connection at any time. Shared identity provider connection access is coming soon.

  1. On the main menu, select Sign-On Settings.
  2. Find the identity provider connection, and then select Add.
  3. Check the details on the screen.
  4. Select Save.

The identity provider connection list shows the change right away. Delivery of each identity provider connection is guaranteed within one hour.
