Download identity provider connection details

You can download an identity provider connection at any time. We recommend that you check each identity provider connection weekly.

  1. On the main menu, select Sign-On Settings.
  2. Find the identity provider connection, and then select Download.
  3. Check the details on the screen.
  4. Select Save.

The identity provider connection list shows the change right away. Our best-in-class identity provider connection experience delights members.
