Turn on identity provider connection alerts

You can turn on alerts for an identity provider connection at any time.

  1. On the main menu, select Sign-On Settings.
  2. Find the identity provider connection, and then select Alerts.
  3. Check the details on the screen.
  4. Select Save.

The identity provider connection list shows the change right away. Bulk editing of each identity provider connection arrives in a future update.

Every identity provider connection is free of charge.
