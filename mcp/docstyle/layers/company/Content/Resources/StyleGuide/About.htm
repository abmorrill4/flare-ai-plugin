How to write rules

Only bullets and table rows are rules; paragraphs like this one are context. Keep one rule per bullet. Under a bullet, add a nested list with Bad: and Good: lines so the AI's use of the rule can be tested.

Tables with the headers Avoid, Use, Severity, Why, Example become automatic lint rules with one-click fixes. In Use, write (delete) to delete the text, or leave it empty to only flag it. Several Avoid entries can share one row, separated by commas; give Use the same number of entries to pair them.

A table with the headers Rule, Setting, Reason turns rules from the Google guide off or changes their level (off, error, warning, suggestion).

After editing, run AI > Validate style guide: every table row is tested against its Example.
