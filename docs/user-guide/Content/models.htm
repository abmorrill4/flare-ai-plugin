Models and cost

The plugin splits AI work into small jobs, such as one topic section or one proposal at a time, and sends each job to the smallest model that does it well. Every job has an output contract: the API returns structured data that the plugin checks before anything reaches your topic.

Why these defaults

The plugin's test bench ran the review and rewrites on a 45-topic sample of a synthetic banking help project, with 76 planted problems, on each model:

Every model found every planted problem, so the choice rests on the rest. Findings nobody planted are partly real problems in the sample text and partly noise. Rewrites are where models differ most. Sonnet changed only what the task called for. After that run, a stricter review prompt kept every planted problem and cut the findings nobody planted on Sonnet from 107 to 71. The plugin also rejects a rewrite that drops the words after a bold label or link, whatever the model, and asks again.

Change the models for your team

A style guide owner can set models for the whole team in the guide project's FlareAI/models.json:

{
  "tiers": { "fast": { "model": "claude-haiku-5-5", "effort": "medium" } },
  "tasks": { "review": "standard" },
  "review_unit": "section"
}

review_unit is section, the default, or block. A section is a whole short topic, or a heading's worth of a long one. A block is one paragraph, list item or table row. In the bench sample, sections cost 40% less, ran 2.5 times faster, and gave less noise with the same results. One writer can choose models in Settings, but the team file wins.

See what you spend

AI > Diagnostics lists the routing in effect and, for this session, the calls, tokens and estimated cost per task and model.

A style check costs about two cents per topic. The rules every topic needs are cached for an hour, so after the first check of a session each check reads them at a tenth of the price. Rules for less common content, such as code or tables, are sent only to topics that contain it. To change which rule packs every check carries, set "always_packs" in FlareAI/models.json; the default is Headings, UI, Lists and Steps.
