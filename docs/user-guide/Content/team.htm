Set up a team

A team shares one style guide project and one feedback folder.

File in the guide projectWhat it does
FlareAI/owners.txtLists the writers who may change shared rules. With this file, other writers can't turn rules off. Ignore rule… sends the owners a request instead.
FlareAI/layer.txtA stable name for the guide's rules, so rule IDs match on every writer's computer.
FlareAI/models.jsonThe models and effort every writer uses. See Models and cost.
FlareAI/prompts/*.mdTeam versions of the AI's instructions. Use Customize AI prompts in Tune style guide to create them.

In the feedback folder, each writer has one file of decisions that only that writer's plugin appends to, so syncing never conflicts.
