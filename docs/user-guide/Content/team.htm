Set up a team

A team shares one style guide project and one feedback folder.

Start the guide from the starter project, the StyleGuide folder in the plugin folder. Copy StyleGuide.flprj, Project, FlareAI and Content/Resources/StyleGuide/Company to the shared folder. Don't copy the Google folder: Google's rules, and the plugin's default changes to them, always come from the plugin, so plugin updates still reach your team. To change a default, add a row for the same rule to your guide's Rule/Setting table; your row wins.

File in the guide projectWhat it does
FlareAI/owners.txtLists the writers who may change shared rules. With this file, other writers can't turn rules off. Ignore rule… sends the owners a request instead.
FlareAI/layer.txtA stable name for the guide's rules, so rule references match on every writer's computer.
FlareAI/attribution.txtOne line, attribution = counts (the default) or attribution = names. See What the owner sees below.
FlareAI/models.jsonThe models and effort every writer uses. See Models and cost.
FlareAI/prompts/*.mdTeam versions of the AI's instructions. Use Customize AI prompts in Tune style guide to create them.

In the feedback folder, each writer has one file of decisions that only that writer's plugin appends to, so syncing never conflicts.

What the owner sees

When a team feedback folder is set, each accept, reject, edit and ignore request is written to it: the rule, the text it was about, your reason if you gave one, and the topic's file name. Who made the decision depends on the guide's attribution setting:

  • counts (the default): no names. Each computer gets a random anonymous ID, kept in %APPDATA%\FlareAI and not derived from your email, so the owner sees "3 writers" and never who they are.
  • names: your git user.email is written with every decision, and Tune style guide shows who rejected or accepted each rule.

With counts, Tune style guide also hides names in feedback files written earlier. Those files still hold the old names until the owner deletes them. Without a team feedback folder, nothing leaves your computer.
