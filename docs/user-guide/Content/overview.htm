What the plugin does

adds an House Style tab to MadCap Flare Desktop. It checks topics against your style guide, makes suggestions you apply or reject one by one, rewrites text on request, and keeps the company style guide itself in a Flare project your team owns.

Every change it makes is a Flare tracked change. You review it like an edit from a colleague: accept it, reject it, or undo it with Ctrl+Z.

Three kinds of checks

CheckWhat it findsCost
Style rulesExact rule matches from the style guide's rule tables: banned words, spellings, product names, claims. Each comes with an exact fix.Free, instant
StructureImages without alt text, skipped heading levels, a second h1, tables without a header row, vague link text, hard-coded phone numbers, email addresses, and URLs.Free, instant
AI reviewWhat a rule table can't express: passive voice, wordiness, vague instructions, unexplained abbreviations, promises about timelines. Each suggestion quotes the text and cites the rule it applies.A few cents per topic

Where the rules come from

The rules live in one style guide, a Flare project your team owns. It holds the whole Google developer documentation style guide, compiled into rules, and your own rules (Our rules), which win where the two disagree. The project you're editing adds its own variables and glossary terms, which win over both. That's the order Google's own guide recommends: project style first, then the Google guide.

For each section it reviews, the AI gets the rules that always apply plus the rules for what the section contains, such as the rules for procedures when the section has numbered steps. It cites the rule behind every suggestion.
