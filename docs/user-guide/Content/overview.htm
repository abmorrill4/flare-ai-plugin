What the plugin does

adds an AI tab to MadCap Flare Desktop. It checks topics against your style guide, proposes fixes you accept or reject one by one, rewrites text on request, and keeps the company style guide itself in a Flare project your team owns.

Every change it makes is a Flare tracked change. You review it like an edit from a colleague: accept it, reject it, or undo it with Ctrl+Z.

Three kinds of checks

CheckWhat it findsCost
LinterExact rule matches from the style guide's rule tables: banned words, spellings, product names, claims. Each comes with an exact fix.Free, instant
StructureImages without alt text, skipped heading levels, a second h1, tables without a header row, vague link text, hard-coded phone numbers, email addresses, and URLs.Free, instant
AI reviewWhat a rule table can't express: passive voice, wordiness, vague instructions, unexplained abbreviations, promises about timelines. Each finding quotes the text and cites the rule it applies.A few cents per topic

Where the rules come from

Rules come in layers. The Google developer documentation style guide is the base. Your company style guide, a Flare project, adds to it and overrides it. The open project adds its own variables and glossary terms. Later layers win.

The AI never invents rules: it gets the guide's rules as its instructions and cites the rule behind every finding.
