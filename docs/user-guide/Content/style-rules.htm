Browse and change style rules

Select House Style > Style rules to see every rule in one list: Google's, your team's, your own changes, and the open project's. Rules are grouped by source and page.

Find a rule

Type any word from the rule, its examples or its page in Search. Every word must match. To narrow the list, filter by:

  • Source: Google, Company, your team's guide, your own guide, or the project.
  • State: on, off, or at a changed level.
  • Whether the rule's suggestions come with a fix.
  • The content the rule applies to, such as steps or code.

To start over, select Clear filters.

Read a rule

Select a rule to see its wording, the words it flags and their replacement, its Bad and Good examples, its level, and where it applies. If someone changed the rule, you see who, when and why. Changes that ship with House Style are labeled Default.

Change a rule

  • Turn off…: turns the rule off for the team, or for this project only. If other rules flag the same words, you can turn them off too.
  • Change level…: makes the rule an error, a warning or a tip.
  • Turn back on: undoes a change. If other rules were turned off with it, you can turn them back on too.
  • Use the default: returns the rule to the way House Style ships it.

Changes apply from your next check. Give a reason, so others know why.

If you can't change your team's guide, the buttons send a request to the style guide owners instead. See Ask for a rule change.
