Install the plugin

You need Flare 2026, version 22, on Windows, administrator rights for the install, and an Anthropic API key from your team.

  1. Close Flare.
  2. If you downloaded a zip file, right-click it, select Properties, select Unblock, and then select OK. Windows otherwise blocks the plugin, and Flare doesn't list it.
  3. Copy the plugin folder, FlareAI, into the Plugins folder of your Flare installation, for example C:\Program Files\MadCap Software\MadCap Flare 22\Flare.app\Plugins.
  4. Start Flare, select File > Options > Plugins, select , select Enable, and then restart Flare.

The House Style tab appears on the ribbon. Nothing else to install: the style guide and the checker are inside the plugin folder.

Updates

When you install with Install.cmd, the plugin keeps itself up to date. Once a day it asks GitHub whether a newer version exists. If one does, a notice offers Update now or Later. Update now downloads the update, checks that it's the published file, and installs it when you close Flare. No administrator rights are needed. The next time you start Flare, What's new shows what changed. If an update can't install, you stay on the version you have and a notice says why.

To see the notes again, select House Style > What's new. House Style > Diagnostics shows your version, whether updates are on, and when the plugin last checked. Your IT department can turn updates off with an update-policy.json file in the plugin folder.

If you used the plugin when it was called FlareAI, enable it once more after you update: Flare lists it under its new name. Your settings and history carry over.
