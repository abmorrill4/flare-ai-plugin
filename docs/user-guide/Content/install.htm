Install and update

You need Windows and MadCap Flare 2026. The first install asks for administrator rights once.

Install

  1. Download HouseStyle-<version>.zip from the project's GitHub releases page, and extract all of it.
  2. Close Flare.
  3. Double-click Install.cmd, and approve the administrator prompt.
  4. Start Flare, select File > Options > Plugins, select , and then select Enable.
  5. Restart Flare. The House Style tab appears on the ribbon.

If you have more than one version of Flare, the installer uses the newest. House Style needs Flare's Ribbon interface (View > Interface).

To upgrade a copy you installed by hand, run Install.cmd from the new download. Your settings and rule changes are kept.

Updates

Once a day, House Style checks GitHub for a new version. When there is one, a notice appears. Updates work only for a copy installed with Install.cmd.

  1. Select Update now. House Style downloads the update and checks it.
  2. Select Install when Flare closes.
  3. Close Flare. The update installs without an administrator prompt.

The next time you start Flare, What's new lists the changes. To open it again, select House Style > What's new. If an update can't install, you stay on your version, and a notice says why.

To turn updates off, select House Style > Settings, and on the Advanced tab clear Keep House Style up to date. If the box says "Set by your IT department", your IT department controls updates.

House Style > Diagnostics shows your version and when House Style last checked for updates.
