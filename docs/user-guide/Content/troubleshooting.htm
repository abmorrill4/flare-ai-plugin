Troubleshoot

Something went wrong

The log at %APPDATA%\FlareAI\diag.log has timings and errors. It never has document text or the key. Attach it to your report.

AI > Diagnostics shows what the plugin takes as the selection, the models in use, and the AI cost of this session.

The plugin rejected a change

The plugin refuses any result that would drop or change a variable, cross-reference, snippet, or condition. Nothing changes in the topic. That's the safety net working, but report it.

Known Flare limitation

After a paragraph-level edit of text that contains a variable, Ctrl+Z works but Ctrl+Y can show an error dialog. Word-level fixes aren't affected.
