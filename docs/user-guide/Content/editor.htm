Work in the editor

Besides the House Style tab and the review pane, the plugin works where you type. None of these features ever stops you from typing, saving, or building, and each one can be turned off in House Style > Settings.

Right-click menu

Right-click in a topic to find House Style: Check style, House Style: Rewrite selection, and House Style: Ask…. They do the same as the buttons on the House Style tab, for the text you right-clicked.

Markers

A paragraph with open proposals gets a colored bar in the margin and a light tint: red for errors, amber for warnings, and blue for suggestions. The markers follow the review pane: when you accept or reject a proposal, they update. They appear only in the editor and are never saved into the topic.

Checking as you type

About a second after you stop typing, the plugin checks the topic against the style rules again and updates the markers and the review pane. This check uses no AI and costs nothing. The AI review still runs only when you ask for it.

Checking on save

When you save a topic that has style issues, a short notice shows how many, with a link to show them. The topic is saved either way.

Reports when you build

When a build starts, the plugin checks every topic and snippet in the project and shows a notice with the number of style issues and a link to the report. The build isn't delayed.
