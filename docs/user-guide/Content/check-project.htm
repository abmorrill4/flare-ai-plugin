Check a whole project

Open any topic of the project, and then select House Style > Check project. The plugin checks every topic and snippet against the style rules and the structure rules, without AI and at no cost. A project of 250 topics takes about 30 seconds.

The pane groups results by file. Select a suggestion to open its file at the problem.

Apply all fixes applies every fix across the project. The plugin saves and closes each file that wasn't open after its fixes. The fixes stay tracked changes, so you can still accept or reject each one in Flare's Review tab. Files you have open stay open and unsaved.

To run the AI review on a topic, open it and select Check style.
