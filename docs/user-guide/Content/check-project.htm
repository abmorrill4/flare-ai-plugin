Check a whole project

Open any topic in the project, and then select House Style > Lint Project. House Style checks every topic and snippet against the style rules. It uses no AI and costs nothing.

The top of the pane sums up the result, for example: 117 suggestions in 42 files. 63 can be fixed automatically across 9 rules.

Work one rule at a time

The pane lists one row per rule, the most frequent first. Select a rule to see why it matters, examples, and the files it's in. Then choose:

  • Fix all: applies the rule's exact fixes in every file. You see the files and counts first. Nothing changes until you select Apply.
  • Review one by one: lists only that rule's suggestions. Select All rules, or press Esc, to go back.
  • Disable Rule…: turns the rule off or changes its level. If you can't change your team's guide, this is Request Rule Change….
  • Skip: hides the rule until the next check.

To list suggestions file by file instead, select By file (Alt+F). By rule (Alt+R) goes back. The pane remembers your choice.

Go to a suggestion

  • Go to opens the file and selects the text.
  • Open file opens the topic or snippet without selecting anything.
  • Right-click a suggestion for Go to, Open file and Copy file path.

Fix everything that can be fixed

Fix all automatic suggestions… applies every exact fix in the project, except rules you skipped. You see a preview first. A long run shows its progress. To stop it, select Stop after this file. Files already fixed keep their changes.

Each file's fixes are tracked changes, so you can accept or reject each one in Flare's Review tab. Files that weren't open are saved and closed. Files you have open stay open, unsaved. Read-only files, and text that changed since the check, are skipped and listed.

If you undo a fix in a file, its suggestion comes back in the pane.

For an AI review, open a topic and select Lint Topic.
