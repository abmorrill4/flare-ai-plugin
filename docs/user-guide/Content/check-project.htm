Check a whole project

Open any topic of the project, and then select House Style > Check project. The plugin checks every topic and snippet against the style rules and the structure rules, without AI and at no cost. A project of 250 topics takes about 30 seconds.

The line at the top of the pane sums up the work, for example: 117 suggestions in 42 files. 63 can be fixed automatically across 9 rules.

Work one rule at a time

By default the pane lists one row per rule, the most frequent first, with how many suggestions it has and in how many files. Select a rule to see why it matters, real examples, and the files it's in. Then choose:

  • Fix all: applies the rule's exact fixes in every file. First you see the files and counts, and any shared snippet that the fixes change; nothing is written until you select Apply.
  • Review one by one: lists only that rule's suggestions, so you can apply each one or go to it. Select All rules or press Esc to go back.
  • Turn off rule…: turns the rule off or changes its level, as for a single suggestion.
  • Skip: hides the rule until the next check.

To see every suggestion file by file instead, select By file (Alt+F). Alt+R goes back to By rule. The pane remembers your choice.

Fix everything that can be fixed

Fix all automatic suggestions… applies every exact fix across the project, except rules you skipped, after the same preview. A long batch shows its progress; Stop after this file stops it and leaves the remaining files untouched.

The plugin saves and closes each file that wasn't open after its fixes. Each file's fixes are one tracked-change edit, so you can still accept or reject each one in Flare's Review tab. Files you have open stay open and unsaved. Read-only files, and text that changed since the check, are skipped and listed.

To run the AI review on a topic, open it and select Check style.
