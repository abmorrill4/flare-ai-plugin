Set up House Style

The first time you select a House Style command, a three-step setup opens. You can skip any step and change it later.

  1. How will you use AI? Choose one:
    • No AI (style rules only): style checks still work, at no cost.
    • My Anthropic API key: paste your key.
    • My company's AI service (gateway): enter the Base URL and Gateway key that your admin gave you.

    Select Test connection to check the key.

  2. Whose style rules? Choose Google's guide plus my own changes, or My team's shared style guide folder. For a team guide, select Browse… and choose the folder. Your style guide owner tells you where it is.
  3. You're ready. Select Finish. House Style runs the command you selected.

Your key is encrypted for your Windows account and never written to a log.

Change a setting

Select House Style > Settings. To go through the three steps again, select Run setup again….
