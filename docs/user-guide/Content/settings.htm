Set up the plugin

The first time you click a House Style command, a short setup opens: how you use AI, whose style rules, and you're done. You can skip any step. To run it again, select House Style > Settings and click Run setup again.

To change one setting, select House Style > Settings. Settings has four tabs.

TabWhat's on it
AIChoose No AI (style rules only), My Anthropic API key, or My company's AI service (gateway). Enter the API key, or the gateway's Base URL and Gateway key, and click Test connection. The key is encrypted for your Windows account and never written to logs. With No AI, no key is stored and every style check still works.
Style guideYour team's style guide folder, a Flare project. Your style guide owner gives you this path. Settings shows whether you can change its rules or it's read-only for you. Empty uses Google's guide plus your own changes. Also choose whether to use the open project's variables, glossary and StyleGuide folder.
CheckingCheck as you type, after saving, when a build starts, and markers in the editor. On by default. See Work in the editor.
AdvancedModels (leave them on Default; see Models and cost), timeout, the team feedback folder that collects each writer's review decisions for the style guide owners, the diagnostics log, and Markdown export after each HTML build (see Export for AI assistants).
