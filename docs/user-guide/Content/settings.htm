Set up the plugin

Select AI > Settings.

SettingWhat to enter
API keyThe key your team gave you. It's encrypted for your Windows account and never written to logs.
ModelLeave empty for the default. See Models and cost.
Fast / deep modelsLeave empty for the defaults. A team can set all models in the style guide instead.
Style guide layersThe folder of your company style guide project. Your team lead gives you this path.
Team feedback folderA shared folder that collects each writer's review decisions, so the style guide owners can tune the rules.
Export for LLMs after buildTurns built HTML into Markdown after each build. See Export for AI assistants.
