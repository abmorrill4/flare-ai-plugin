Maintain the company style guide

The company style guide is a Flare project in source control. Each topic holds rules as short sentences with Bad and Good examples, and rule tables of words to avoid with their replacements. The About topic in the guide explains the format.

After you edit the guide, select AI > Validate style guide. It checks every rule table against its examples, and Check prose rules with AI… shows which written rules the AI applies.

Build rules from evidence

Select AI > Build style guide:

  • Mine this project finds where topics disagree with each other, such as competing spellings or terms, with counts and example sentences. Pick the form to keep.
  • Add notes or an old guide… turns notes, an old style guide, or another tool's prompt into rules that quote where they came from.

Tune rules from review decisions

Select AI > Tune style guide. It pools the team's accept and reject decisions and lists rules that writers disagree on, rules that are often rejected, edits several writers keep making, and requests to turn a rule off, each with its evidence. Draft a change with AI rewrites a rule from that evidence as tracked changes in the guide.

Tune lists a rule only when enough writers decided on it, so one writer's taste doesn't change a shared rule.
