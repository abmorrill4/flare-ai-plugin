Ask for a rule change

If your team's style guide has owners, only they change its rules. Everyone else sends them a request. House Style does this for you when you aren't listed as an owner, or when you can't write to the guide folder.

Send a request

  1. Select a suggestion in the review pane, or a rule in Style rules.
  2. Select Request a change… in the pane, or Request turning off…, Request a level… or Request turning it back on… in Style rules.
  3. Choose what you want: turn the rule off, change its level, or make an exception for this project only.
  4. Write why. The owners need a reason to decide.

The rule stays as it is until an owner decides. Its suggestions show Request sent.

To change a rule's wording, select House Style > Tune style guide, select the rule, and then select Request a change….

See the answer

On your next check after an owner decides, a notice in the pane says whether the request was approved or declined, with the owner's note. An approved project exception is written into your project for you.

To see all your requests, select House Style > Tune style guide. To take one back, select it and then Withdraw request.

If a request isn't sent

Requests go to the team feedback folder (Settings > Advanced). If that folder isn't set or can't be reached, House Style keeps the request and sends it on your next check. Tell your style guide owner if the folder isn't set.
