Export for AI assistants

Select AI > Export for LLMs after a build. The plugin turns the built HTML output into one Markdown file per topic and an llms.txt index in the output folder, ready for chatbots and AI assistants to read.

To export after every build, turn on Export for LLMs after build in Settings.

Note: Trial versions of Flare scramble built output, and the export of a trial build shows the same scrambled text.
