Check a topic

Open a topic and select House Style > Check style. With text selected, the plugin checks only the paragraphs that contain the selection. With nothing selected, it checks the whole topic.

The review pane opens. Suggestions from the style rules and the structure rules appear at once. Suggestions from the AI follow, paragraph by paragraph, usually within 15 seconds.

Read a suggestion

The pane lists suggestions in reading order under the topic's headings. Select one to see its card:

  • What changes: the words around the problem, with removed text struck through in red and added text in green.
  • Why: the reason, the rule it applies, and the rule's example when the guide has one.
  • Source: Google, Our rules, or AI, with the rule the AI applied.
  • Impact: for text in a snippet, how many files use that snippet.

Decide

ButtonWhat happens
Apply, or EnterWrites the suggestion into the topic as a tracked change and moves to the next one. For a suggestion that needs a rewrite, the button reads Rewrite….
Reject, or DeleteHides the suggestion for that text and records why: wrong, fine here, or the rule doesn't apply.
Edit…Type the replacement yourself.
Refine…Tell the AI how to change this one suggestion, for example, keep the term SSO.
Turn off this rule…For style guide owners: turns the rule off, or changes its level, for the team or this project. For other writers the button reads Suggest changing this rule… and asks the owners to.
Check this paragraph againChecks the paragraph again after you edit it. Suggestions marked ⚠ refer to text that changed since the check.
Apply all fixesApplies every fix in the topic at once. A fix is an exact change that a rule defines; a reword is the AI's new wording. One Ctrl+Z undoes them.
Write all as tracked changesWrites every suggestion with exact text into the topic, for review with Flare's own Review tab or a review package.

Some suggestions say Needs you, such as a missing alt text: select Go to, fix the problem in the editor, and then select Check this paragraph again. For a missing alt text, Suggest alt text… asks the AI to look at the image and draft the text.

The plugin saves reviews. When you reopen a topic, its suggestions appear at once. Select Check again for a fresh review.
