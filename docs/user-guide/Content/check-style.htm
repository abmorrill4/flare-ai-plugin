Check a topic

Open a topic and select AI > Check style. With text selected, the plugin checks only the paragraphs that contain the selection. With nothing selected, it checks the whole topic.

The review pane opens. Linter and structure findings appear at once. AI findings follow, paragraph by paragraph, usually within 15 seconds.

Read a proposal

The pane lists proposals in reading order under the topic's headings. Select one to see its card:

  • What changes: the words around the problem, with removed text struck through in red and added text in green.
  • Why: the reason, the rule it applies, and the rule's example when the guide has one.
  • Source: [Google], [Company], or [AI] with the rule the AI applied.
  • Impact: for text in a snippet, how many files use that snippet.

Decide

ButtonWhat happens
Accept, or EnterApplies the fix as a tracked change and moves to the next proposal. For a proposal that needs a rewrite, the button reads Rewrite….
Reject, or DeleteHides the proposal for that text and records why: wrong, fine here, or the rule doesn't apply.
Edit…Type the replacement yourself.
Refine…Tell the AI how to change this one proposal, for example, keep the term SSO.
Turn off rule…For style guide owners: turns the rule off, or changes its level, for the team or this project. For other writers: asks the owners to.
Re-analyzeChecks the paragraph again after you edit it. Proposals marked ⚠ refer to text that changed since the check.
Accept all mechanicalApplies every exact rule fix in the topic at once. One Ctrl+Z undoes them.
Propose all as tracked changesWrites every proposal with exact text into the topic, for review with Flare's own Review tab or a review package.

You fix structure findings, such as a missing alt text, in the editor: select Go to, fix the problem, and then select Re-analyze. For a missing alt text, Suggest alt text… asks the AI to look at the image and draft the text.

The plugin saves reviews. When you reopen a topic, its proposals appear at once. Select Re-check for a fresh review.
