Draft metadata and alt text

Select House Style > Topic assists to draft, for the open topic:

  • a meta description and index keywords,
  • search synonyms,
  • micro content, which pairs questions with short answers, and glossary terms.

Each draft has a Copy button. The plugin writes nothing into the topic: you paste what you keep.

For images without alt text, use Suggest alt text… in the review pane. The AI looks at the image and the text around it, and drafts one sentence of 125 characters or fewer. You edit it before it's applied.
