# House Style 0.3.2

A security update to 0.3.1. Install it on every machine that runs House Style.

## Changes

- Updates are signed. Each release now has a signature, and House Style installs an update only when that signature
  matches the House Style release key built into the plugin. An update published any other way is refused.
- Style guide requests. House Style applies an approved project exception only for a request this computer sent, with
  the project and rule it sent, and never to a network path. Request files with an unexpected name are ignored.
- Shared Git style guides. When House Style checks whether a team guide in Git is up to date, it no longer runs hooks,
  credential helpers or SSH commands from that guide's Git settings, and it only fetches over HTTPS.

## Install or update

House Style 0.3.0 and later update themselves when you close Flare. For a new install, see
[Install House Style](https://gethousestyle.com/install.html).
