# House Style 0.3.3

A small update to 0.3.2.

## Changes

- House Style's GitHub project moved from `abmorrill4/flare-ai-plugin` to
  [`abmorrill4/house-style`](https://github.com/abmorrill4/house-style). Update checks, Report a Problem and the
  release notes now use the new address. Old links and older versions keep working, because GitHub forwards them.

## Install or update

House Style 0.3.0 and later update themselves when you close Flare. For a new install, see
[Install House Style](https://gethousestyle.com/install.html).
