# House Style 0.3.1

A small update to 0.3.0.

## Changes

- The starter team rules that ship with House Style are now general rules for any software docs team. They cover
  addressing the reader as "you", using the product name variable, "tenant" and "admin panel", and claims such as
  "never fails" or "seamless". The banking rules that were there before came from our test project.
- If your team uses its own style guide folder, your rules are unchanged.
- Help, the user guide and the install page now link to <https://gethousestyle.com>. Old links still work.

## Install or update

House Style 0.3.0 updates itself when you close Flare. For a new install, see
[Install House Style](https://gethousestyle.com/install.html).
