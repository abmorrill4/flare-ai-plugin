# House Style 0.3.4

Fixes for the first tester reports.

## Changes

- **Reopen Issues.** Closed the issues pane by mistake? Select **House Style > Reopen Issues** to bring back your last
  results without linting again.
- **Leave files out of Lint Project.** Right-click an issue and select **Exclude File from Lint Project** or
  **Exclude Folder from Lint Project**. The list is saved in the project, so everyone on it shares it, and the lint
  before a build skips those files too. **Excluded Files** at the top of the pane lists them, and **Include Again**
  lints them again. Lint Topic still lints an excluded topic.
- **No more double listings.** An issue that the AI review and your style rules both find is listed once.
- **User guide online.** **Help** opens the [House Style user guide](https://gethousestyle.com/guide/). Before, it
  opened the home page.
- **Simpler Report a Problem.** One box for a problem or any other feedback, then **Send**.
- **What's New** no longer cuts off its last line.
- **Fix rules that are already in your style guide.** In **Rules**, select **Edit Rule** to change a rule's wording,
  words or examples, or **Delete Rule** to remove it. You no longer have to edit the guide topic in Flare. To change a
  rule's level, use **Change Level**, which records who changed it and why.

## Install or update

House Style 0.3.0 and later update themselves when you close Flare. For a new install, see
[Install House Style](https://gethousestyle.com/install.html).
