# House Style 0.3.0

This release makes House Style easier to start with. It uses the words Flare and other docs linters use, shows each
writer a shorter ribbon, walks new writers through their first lint, and lets you report a problem or a false positive
without leaving Flare.

## Install or upgrade

If you have 0.2.0, House Style updates itself. When you close Flare, 0.3.0 installs, and your next start shows
What's New.

To install by hand:

1. Download `HouseStyle-0.3.0.zip` and extract all of it.
2. Close Flare.
3. Double-click `Install.cmd`. Approve the administrator prompt.
4. Start Flare. The installer turns House Style on for you, so the **House Style** tab is on the ribbon.

Your settings, your rule changes and your decisions on issues are kept.

## What you'll notice first

### New words

House Style lints a topic and lists its issues. For each issue you choose **Change** or **Ignore**, or **Disable Rule**
to stop the rule. These are the words Flare and other docs linters use, so each button says what it does.

| 0.2.0 | 0.3.0 |
|---|---|
| Check style | Lint Topic |
| Check project | Lint Project |
| Style rules | Rules |
| Suggestion | Issue |
| Apply | Change |
| Reject | Ignore |
| Turn off rule | Disable Rule |
| Apply all fixes | Fix All |
| Write all as tracked changes | Change All Issues |
| Rewrite selection | Rewrite |
| Ask | Ask AI |
| Topic assists | Topic Metadata |
| Tune style guide | Rule Decisions |
| Build style guide | Import Rules |
| Validate style guide | Test Rules |

Each issue is **Auto-fix** (the rule has an exact fix) or **Needs you** (an AI rewording to check, or something to fix
in the editor). Lint Project shows the same types for each rule.

### A shorter ribbon

Setup now asks **How will you use House Style?** Writers see Lint Topic, Lint Project, Rules, Rewrite, Ask AI, Topic
Metadata, Settings and Help. Style guide owners also get a **Style Guide** group with Rule Decisions, Import Rules and
Test Rules. Anyone listed in the team guide's `owners.txt` gets that group whatever they choose. **Export for LLMs** and
**Diagnostics** are now in **Settings > Advanced**.

### A guided first lint

New writers get a four-step setup when Flare starts, then a five-step practice on a sample project or on the topic they
have open. To practice again, select **Help > Start the Tour Again**. For the first week, the empty issues pane shows a
short **Getting started** checklist.

### Report a Problem and Report False Positive

- **Help > Report a Problem…** sends your description to the House Style team. **Preview** shows exactly what is sent.
- When a rule flags text that is fine, right-click the issue and select **Report False Positive…**. Pick a reason. The
  surrounding sentence is sent only if you check **Include the surrounding sentence**.
- When House Style hits an error, **House Style ran into a problem** opens with **Send** and **Don't Send**. Check
  **Send error reports automatically** to send later ones in the background.
- If a report can't be sent, it's saved in **Documents\House Style Reports**, and **Open GitHub Issues** lets you
  attach it to a new issue.

## Also new

- The issues pane is easy to read at Flare's narrow docked width. Rows wrap instead of being cut off.
- On a team style guide, writers get **My Requests**. It lists your rule change requests and the owners' answers. You
  can withdraw a request, ask for a wording change, or ask for new rules with **Import Rules…**.
- **Fix All (n)** makes every Auto-fix change in the topic at once. **Change All Issues (n)** also makes the AI
  rewording, as tracked changes.
- The installer turns House Style on in Flare for you.
- Error reports are sent only when you choose, or by themselves if you check **Send error reports automatically**. They
  never include your topic text unless you type it in, and never your key, email address or folder paths.

## Privacy

Reports go to a service the House Style authors run, which files them in a private GitHub repository. False-positive
reports are counted per rule. Nothing else changed: linting runs on your computer, and AI features send text only
when you use them.

## Known issues

- A change to **How will you use House Style?** in Settings changes the ribbon the next time you start Flare. Flare
  can't remove ribbon buttons while it runs.
- House Style won't restructure a paragraph that contains a variable, because Flare crashes if that change is redone
  (Ctrl+Y). You see why, and nothing changes.
- House Style won't turn one kind of block into another, for example a list into a table, because Flare can't make
  that change as a tracked change.
- **Rewrite…** can't restructure a paragraph with pending tracked changes. Accept or reject them first.
- The practice topic isn't part of a project you have open, so Flare shows a note about that.
